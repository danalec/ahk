Türkçe

*AutoHotkey v2.0.31* · command · Ayrıştırıcı ve betiğin çalıştırılması

## Açıklama

Answers 0 and changes nothing. A script of this runtime runs from its first line to its last and has no message loop to stay alive for, so the setting has no meaning here.

## Sözdizimi

```ahk
Persistent …
```

## Parametreler

[OnOff]

## Dönüş değeri

the integer 0

## Hatalar

none.

## Örnek

```ahk
Persistent
```
