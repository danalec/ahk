## Açıklama

The other side of an if. Else if chains the conditions, and the first one that matches runs.

## Sözdizimi

```ahk
Else …
```

## Parametreler

a statement or a block

## Dönüş değeri

nothing

## Hatalar

none.

## Örnek

```ahk
if (0)
    MsgBox "no"
else
    MsgBox "yes"
```
