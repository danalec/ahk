## Açıklama

Sets the default file encoding (v1).

## Sözdizimi

```ahk
FileEncoding Encoding
```

## Parametreler

0..255.

## Dönüş değeri

Nothing.

## Örnek

```ahk
FileEncoding UTF-8
```
