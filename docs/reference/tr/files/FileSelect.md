*AutoHotkey v2.0.31* · command · Dosya ve dizin işlemleri

## Açıklama

Shows a file-selection dialog.

## Sözdizimi

```ahk
S := FileSelect(Options, RootDir, Prompt, Filter)
```

## Parametreler

0..4.

## Dönüş değeri

The path(s) or empty.

## Örnek

```ahk
p := FileSelect()
```
