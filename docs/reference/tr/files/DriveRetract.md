*AutoHotkey v2.0.31* · command · Dosya ve dizin işlemleri

## Açıklama

Retracts a CD/drive. (Windows).

## Sözdizimi

```ahk
DriveRetract Drive, Value
```

## Parametreler

0..1.

## Dönüş değeri

Nothing.

## Örnek

```ahk
DriveRetract "D:"
```
