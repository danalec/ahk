*AutoHotkey v1.1.37.02* · command · Ses

## Açıklama

Sets a sound component/control (v1 shape).

## Sözdizimi

```ahk
SoundSet NewValue, Component, Control, Device
```

## Parametreler

- **NewValue** — The value.
- **Component/Control/Device** — Selectors.

## Dönüş değeri

Nothing.

## Örnek

```ahk
SoundSet 50, , "Volume"
```
