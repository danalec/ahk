*AutoHotkey v2.0.31* · function · Ses

## Açıklama

Sets the volume of a device (0..100).

## Sözdizimi

```ahk
SoundSetVolume Volume, Device
```

## Parametreler

- **Volume** — 0..100.
- **Device** — The device.

## Dönüş değeri

Nothing.

## Örnek

```ahk
SoundSetVolume 50
```
