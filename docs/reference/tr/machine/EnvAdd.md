## Açıklama

Adds to a variable (v1).

## Sözdizimi

```ahk
EnvAdd Var, Value
```

## Parametreler

- **Var** — The variable.
- **Value** — The addend.

## Dönüş değeri

Nothing.

## Örnek

```ahk
EnvAdd x, 1
```
