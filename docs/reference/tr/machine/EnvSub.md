## Açıklama

Subtracts from a variable (v1).

## Sözdizimi

```ahk
EnvSub Var, Value
```

## Parametreler

- **Var** — The variable.
- **Value** — The subtrahend.

## Dönüş değeri

Nothing.

## Örnek

```ahk
EnvSub x, 1
```
