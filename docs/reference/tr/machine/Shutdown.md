*AutoHotkey v1.1.37.02* · command · Makine, süreçler ve ortam

## Açıklama

Shuts down / logs off / reboots the machine.

## Sözdizimi

```ahk
Shutdown Code
```

## Parametreler

- **Code** — The shutdown flags (1 logoff, 2 reboot, 8 power-down...).

## Dönüş değeri

Nothing.

## Örnek

```ahk
Shutdown 2
```
