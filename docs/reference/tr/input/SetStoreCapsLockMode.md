## Açıklama

Sets whether CapsLock mode is stored.

## Sözdizimi

```ahk
SetStoreCapsLockMode On|Off
```

## Parametreler

1..255.

## Dönüş değeri

Nothing.

## Örnek

```ahk
SetStoreCapsLockMode
```
