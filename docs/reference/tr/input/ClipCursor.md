*KeySharp* · function · Kısayollar, tetikleme dizeleri ve giriş

## Açıklama

Confines the pointer to a rect (ks).

## Sözdizimi

```ahk
ClipCursor(X1, Y1, X2, Y2)
```

## Parametreler

?.

## Dönüş değeri

Nothing; no rect frees.

## Örnek

```ahk
ClipCursor(0, 0, 100, 100)
```
