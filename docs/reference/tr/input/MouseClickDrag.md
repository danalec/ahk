*AutoHotkey v1.1.37.02* · command · Kısayollar, tetikleme dizeleri ve giriş

## Açıklama

Drags the mouse from one point to another.

## Sözdizimi

```ahk
MouseClickDrag Button, X1, Y1, X2, Y2, Speed
```

## Parametreler

1..255.

## Dönüş değeri

Nothing.

## Örnek

```ahk
MouseClickDrag "L", 0, 0, 100, 100
```
