*AutoHotkey v1.1.37.02* · command · GUI pencereleri ve pencere otomasyonu

## Açıklama

Shows a splash text window (v1).

## Sözdizimi

```ahk
SplashTextOn W, H, Title, Text
```

## Parametreler

0..255.

## Dönüş değeri

Nothing.

## Örnek

```ahk
SplashTextOn 200, 100, "t", "x"
```
