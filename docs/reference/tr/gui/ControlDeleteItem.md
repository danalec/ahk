*AutoHotkey v2.0.31* · command · GUI pencereleri ve pencere otomasyonu

## Açıklama

Deletes an item by index.

## Sözdizimi

```ahk
ControlDeleteItem N, Control, WinTitle
```

## Parametreler

2..6.

## Dönüş değeri

Nothing.

## Örnek

```ahk
ControlDeleteItem 1, "ListBox1"
```
