*AutoHotkey v2.0.31* · command · GUI pencereleri ve pencere otomasyonu

## Açıklama

Reads whether a control is enabled.

## Sözdizimi

```ahk
B := ControlGetEnabled(Control, WinTitle)
```

## Parametreler

1..5.

## Dönüş değeri

1/0.

## Örnek

```ahk
ControlGetEnabled("Edit1")
```
