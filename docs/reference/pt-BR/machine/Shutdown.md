*AutoHotkey v1.1.37.02* · command · A máquina, os processos e o ambiente

## Descrição

Shuts down / logs off / reboots the machine.

## Sintaxe

```ahk
Shutdown Code
```

## Parâmetros

- **Code** — The shutdown flags (1 logoff, 2 reboot, 8 power-down...).

## Valor de retorno

Nothing.

## Exemplo

```ahk
Shutdown 2
```
