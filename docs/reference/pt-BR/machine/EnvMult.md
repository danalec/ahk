## Descrição

Multiplies a variable (v1).

## Sintaxe

```ahk
EnvMult Var, Value
```

## Parâmetros

- **Var** — The variable.
- **Value** — The factor.

## Valor de retorno

Nothing.

## Exemplo

```ahk
EnvMult x, 2
```
