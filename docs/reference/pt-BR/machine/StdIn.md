## Descrição

Writes to the standard input of a ScriptProcess.

## Sintaxe

```ahk
Proc.StdIn(Text)
```

## Parâmetros

- **Text** — The text.

## Valor de retorno

Nothing.

## Exemplo

```ahk
p.StdIn("hi")
```
