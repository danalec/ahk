*AutoHotkey v2.0.31* · variable · APIs do registro

## Descrição

Sets the registry view (32/64-bit) for the thread.

## Sintaxe

```ahk
RegView View
```

## Parâmetros

- **View** — 32/64/Default.

## Valor de retorno

Nothing.

## Exemplo

```ahk
RegView 64
```
