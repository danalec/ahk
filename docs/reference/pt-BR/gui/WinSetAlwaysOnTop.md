*AutoHotkey v2.0.31* · command · Janelas da GUI e automação de janelas

## Descrição

Sets a window always-on-top.

## Sintaxe

```ahk
WinSetAlwaysOnTop On|Off|Toggle, WinTitle
```

## Parâmetros

0..5.

## Valor de retorno

Nothing.

## Exemplo

```ahk
WinSetAlwaysOnTop 1, "A"
```
