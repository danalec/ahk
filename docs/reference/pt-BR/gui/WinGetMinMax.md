## Descrição

The min/max state of a window.

## Sintaxe

```ahk
N := WinGetMinMax(WinTitle)
```

## Parâmetros

0..4.

## Valor de retorno

-1/0/1.

## Exemplo

```ahk
WinGetMinMax("A")
```
