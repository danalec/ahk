*AutoHotkey v1.1.37.02* · command · Janelas da GUI e automação de janelas

## Descrição

Forces a window to close.

## Sintaxe

```ahk
WinKill WinTitle, SecondsToWait
```

## Parâmetros

0..255.

## Valor de retorno

Nothing.

## Exemplo

```ahk
WinKill "A"
```
