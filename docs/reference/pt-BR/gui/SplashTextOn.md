*AutoHotkey v1.1.37.02* · command · Janelas da GUI e automação de janelas

## Descrição

Shows a splash text window (v1).

## Sintaxe

```ahk
SplashTextOn W, H, Title, Text
```

## Parâmetros

0..255.

## Valor de retorno

Nothing.

## Exemplo

```ahk
SplashTextOn 200, 100, "t", "x"
```
