*AutoHotkey v1.1.37.02* · command · Janelas da GUI e automação de janelas

## Descrição

Abre o arquivo do script no programa que a máquina usa para abrir um arquivo desse tipo — o editor de um script.

## Sintaxe

```ahk
Edit …
```

## Parâmetros

none

## Valor de retorno

o texto vazio

## Erros

the call fails when the script has no file: a script that comes from the standard input has none, and the reason is "the script of this runtime is read from the standard input, so it has no file for an editor to open".

## Exemplo

```ahk
Edit()
```
