*AutoHotkey v2.0.31* · command · Janelas da GUI e automação de janelas

## Descrição

Pastes text at the caret of an edit.

## Sintaxe

```ahk
EditPaste Text, Control, WinTitle
```

## Parâmetros

2..6.

## Valor de retorno

Nothing.

## Exemplo

```ahk
EditPaste "x", "Edit1"
```
