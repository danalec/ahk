*AutoHotkey v2.0.31* · command · Janelas da GUI e automação de janelas

## Descrição

Enables/disables a window.

## Sintaxe

```ahk
WinSetEnabled B, WinTitle
```

## Parâmetros

1..5.

## Valor de retorno

Nothing.

## Exemplo

```ahk
WinSetEnabled 0, "A"
```
