## Descrição

Chooses an item by text.

## Sintaxe

```ahk
ControlChooseString Text, Control, WinTitle
```

## Parâmetros

2..6.

## Valor de retorno

Nothing.

## Exemplo

```ahk
ControlChooseString "x", "ListBox1"
```
