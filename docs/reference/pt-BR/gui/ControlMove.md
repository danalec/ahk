*AutoHotkey v1.1.37.02* · command · Janelas da GUI e automação de janelas

## Descrição

Moves/resizes a control.

## Sintaxe

```ahk
ControlMove X, Y, W, H, Control, WinTitle
```

## Parâmetros

0..255.

## Valor de retorno

Nothing.

## Exemplo

```ahk
ControlMove 0, 0, 100, 20, "Edit1"
```
