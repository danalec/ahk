## Descrição

Reads a line of an edit.

## Sintaxe

```ahk
S := EditGetLine(N, Control, WinTitle)
```

## Parâmetros

2..6.

## Valor de retorno

The line.

## Exemplo

```ahk
EditGetLine(1, "Edit1")
```
