*KeySharp* · function · Hotkeys, hotstrings e entrada

## Descrição

Confines the pointer to a rect (ks).

## Sintaxe

```ahk
ClipCursor(X1, Y1, X2, Y2)
```

## Parâmetros

?.

## Valor de retorno

Nothing; no rect frees.

## Exemplo

```ahk
ClipCursor(0, 0, 100, 100)
```
