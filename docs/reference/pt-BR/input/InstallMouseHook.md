*AutoHotkey v2.0.31* · command · Hotkeys, hotstrings e entrada

## Descrição

Responde que o hook está lá. O mouse não é vigiado de jeito nenhum: o backend vigia o teclado, e o ponteiro é um dispositivo que escreve e nunca é lido.

## Sintaxe

```ahk
InstallMouseHook …
```

## Parâmetros

[OnOff] [HookName]

## Valor de retorno

nada

## Erros

none; the command never fails.

## Exemplo

```ahk
InstallMouseHook
```
