*AutoHotkey v1.1.37.02* · command · Hotkeys, hotstrings e entrada

## Descrição

Só consegue desligar a entrada da máquina inteira. Bloquear a entrada da máquina toda é um privilégio que este compositor não dá a um cliente, e a árvore não vai fingir que deu.

## Sintaxe

```ahk
BlockInput …
```

## Parâmetros

Mode

## Valor de retorno

nada para 'Off'

## Erros

any other mode fails with 'blocking the input of the whole machine is a privilege this compositor does not give a client'.

## Exemplo

```ahk
BlockInput "Off"
```
