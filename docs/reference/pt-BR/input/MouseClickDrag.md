*AutoHotkey v1.1.37.02* · command · Hotkeys, hotstrings e entrada

## Descrição

Drags the mouse from one point to another.

## Sintaxe

```ahk
MouseClickDrag Button, X1, Y1, X2, Y2, Speed
```

## Parâmetros

1..255.

## Valor de retorno

Nothing.

## Exemplo

```ahk
MouseClickDrag "L", 0, 0, 100, 100
```
