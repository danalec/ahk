## Descrição

The status of a CD drive (open/ready/playing).

## Sintaxe

```ahk
S := DriveGetStatusCD(Drive)
```

## Parâmetros

0..1.

## Valor de retorno

The status.

## Exemplo

```ahk
DriveGetStatusCD("D:")
```
