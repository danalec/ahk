Português (Brasil)

*AutoHotkey v1.1.37.02* · command · O analisador e a execução do script

## Descrição

Desliga ou liga as hotkeys do script. Sem parâmetro, inverte o estado. O estado aparece em A_IsSuspended e na flag habilitada da tabela de hotkeys.

## Sintaxe

```ahk
Suspend …
```

## Parâmetros

[OnOff]

## Valor de retorno

texto vazio

## Erros

a parameter that is not 0, 1 or -1 is an invalid parameter.

## Exemplo

```ahk
Suspend true
```
