*AutoHotkey v1.1.37.02* · command · O analisador e a execução do script

## Descrição

O outro lado de um if. Else if encadeia condições, e a primeira que casar roda.

## Sintaxe

```ahk
Else …
```

## Parâmetros

a statement or a block

## Valor de retorno

nada

## Erros

none.

## Exemplo

```ahk
if (0)
    MsgBox "no"
else
    MsgBox "yes"
```
