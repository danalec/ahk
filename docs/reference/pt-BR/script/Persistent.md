Português (Brasil)

*AutoHotkey v2.0.31* · command · O analisador e a execução do script

## Descrição

Devolve 0 e não muda nada. Um script deste runtime roda da primeira à última linha e não tem laço de mensagens para se manter vivo, então a opção não tem significado aqui.

## Sintaxe

```ahk
Persistent …
```

## Parâmetros

[OnOff]

## Valor de retorno

o inteiro 0

## Erros

none.

## Exemplo

```ahk
Persistent
```
