## Descrição

Sets the wave volume (v1).

## Sintaxe

```ahk
SoundSetWaveVolume Volume, Device
```

## Parâmetros

- **Volume** — 0..100.
- **Device** — The device.

## Valor de retorno

Nothing.

## Exemplo

```ahk
SoundSetWaveVolume 50
```
