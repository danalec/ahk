## Descrição

Converts a value to a float.

## Sintaxe

```ahk
N := Float(Value)
```

## Parâmetros

- **Value** — A number or numeric text.

## Valor de retorno

The float.

## Exemplo

```ahk
Float("3.5")  ; 3.5
```
