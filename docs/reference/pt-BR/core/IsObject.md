## Descrição

Se um valor é um objeto. Tudo que não é número nem texto é objeto: um array, um map, uma instância de classe e uma referência.

## Sintaxe

```ahk
IsObject …
```

## Parâmetros

Value

## Valor de retorno

1 quando é objeto, 0 quando não é

## Erros

none.

## Exemplo

```ahk
IsObject([])
```
