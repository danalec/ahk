## Descrição

O número inteiro abaixo de um número.

## Sintaxe

```ahk
N := Floor(Number)
```

## Parâmetros

- **Number** — The value.

## Valor de retorno

o inteiro, um float quando o número não era inteiro

## Erros

a value that is not a number is refused.

## Exemplo

```ahk
Floor(1.8)
```
