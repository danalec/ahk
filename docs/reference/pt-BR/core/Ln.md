*AutoHotkey v1.1.37.02* · function · O núcleo da linguagem: texto, matemática e padrões

## Descrição

O logaritmo natural de um número.

## Sintaxe

```ahk
Ln …
```

## Parâmetros

Number

## Valor de retorno

um float

## Erros

a negative number is an invalid parameter; a value that is not a number is refused.

## Exemplo

```ahk
Ln(1)
```
