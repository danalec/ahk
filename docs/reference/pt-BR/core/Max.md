## Descrição

O maior dos números.

## Sintaxe

```ahk
N := Max(Numbers...)
```

## Parâmetros

- **Numbers** — One or more.

## Valor de retorno

o maior deles

## Erros

a value that is not a number is refused.

## Exemplo

```ahk
Max(3, 7, 5)
```
