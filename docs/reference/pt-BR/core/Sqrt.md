## Descrição

A raiz quadrada de um número.

## Sintaxe

```ahk
N := Sqrt(Number)
```

## Parâmetros

- **Number** — Non-negative.

## Valor de retorno

um float, mesmo quando o resultado é inteiro

## Erros

a negative number is an invalid parameter.

## Exemplo

```ahk
Sqrt(9)
```
