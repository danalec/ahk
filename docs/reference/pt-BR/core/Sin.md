## Descrição

O seno de um ângulo, em radianos.

## Sintaxe

```ahk
N := Sin(Number)
```

## Parâmetros

- **Number** — Radians.

## Valor de retorno

um float, qualquer que tenha sido a entrada

## Erros

a value that is not a number is refused.

## Exemplo

```ahk
Sin(0)
```
