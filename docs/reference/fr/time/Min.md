## Description

The smallest of the numbers.

## Syntaxe

```ahk
Min
```

## Paramètres

Number, [Number2], ...

## Valeur de retour

the smallest of them

## Erreurs

a value that is not a number is refused.

## Exemple

```ahk
Min(3, 7, 5)
```
