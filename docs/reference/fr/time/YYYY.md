## Description

The four-digit year of a timestamp (FormatTime token / A_YYYY).

## Syntaxe

```ahk
YYYY
```

## Paramètres

?.

## Valeur de retour

The year.

## Exemple

```ahk
FormatTime(, "yyyy")
```
