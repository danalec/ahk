*AutoHotkey v2.0.31* · function · Le son

## Description

Mutes/unmutes a device.

## Syntaxe

```ahk
SoundSetMute Mute, Device
```

## Paramètres

- **Mute** — 1/0.
- **Device** — The device.

## Valeur de retour

Nothing.

## Exemple

```ahk
SoundSetMute 1
```
