*AutoHotkey v1.1.37.02* · command · Le son

## Description

Sets a sound component/control (v1 shape).

## Syntaxe

```ahk
SoundSet NewValue, Component, Control, Device
```

## Paramètres

- **NewValue** — The value.
- **Component/Control/Device** — Selectors.

## Valeur de retour

Nothing.

## Exemple

```ahk
SoundSet 50, , "Volume"
```
