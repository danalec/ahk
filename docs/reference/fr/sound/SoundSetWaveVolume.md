## Description

Sets the wave volume (v1).

## Syntaxe

```ahk
SoundSetWaveVolume Volume, Device
```

## Paramètres

- **Volume** — 0..100.
- **Device** — The device.

## Valeur de retour

Nothing.

## Exemple

```ahk
SoundSetWaveVolume 50
```
