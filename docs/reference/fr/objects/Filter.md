## Description

Filters a collection by a predicate (ks).

## Syntaxe

```ahk
A := Arr.Filter(Pred)
```

## Paramètres

?.

## Valeur de retour

The filtered Array.

## Exemple

```ahk
a.Filter((x) => x > 1)
```
