## Description

The index of the first item matching a predicate (ks).

## Syntaxe

```ahk
N := Arr.FindIndex(Pred)
```

## Paramètres

?.

## Valeur de retour

The index or 0.

## Exemple

```ahk
a.FindIndex((x) => x = 2)
```
