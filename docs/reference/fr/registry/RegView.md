*AutoHotkey v2.0.31* · variable · Les API du registre

## Description

Sets the registry view (32/64-bit) for the thread.

## Syntaxe

```ahk
RegView View
```

## Paramètres

- **View** — 32/64/Default.

## Valeur de retour

Nothing.

## Exemple

```ahk
RegView 64
```
