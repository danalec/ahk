*AutoHotkey v2.0.31* · command · Les opérations sur les fichiers et les répertoires

## Description

Shows a folder-selection dialog.

## Syntaxe

```ahk
S := DirSelect(StartingFolder, Options, Prompt)
```

## Paramètres

0..3.

## Valeur de retour

The path or empty.

## Exemple

```ahk
p := DirSelect()
```
