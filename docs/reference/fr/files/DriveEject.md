*AutoHotkey v2.0.31* · command · Les opérations sur les fichiers et les répertoires

## Description

Ejects a CD/drive. (Windows).

## Syntaxe

```ahk
DriveEject Drive, Value
```

## Paramètres

0..1.

## Valeur de retour

Nothing.

## Exemple

```ahk
DriveEject "D:"
```
