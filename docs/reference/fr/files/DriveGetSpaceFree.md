## Description

The free space of a drive in MB.

## Syntaxe

```ahk
N := DriveGetSpaceFree(Path)
```

## Paramètres

1.

## Valeur de retour

The free space.

## Exemple

```ahk
DriveGetSpaceFree("C:\")
```
