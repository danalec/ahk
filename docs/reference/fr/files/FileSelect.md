*AutoHotkey v2.0.31* · command · Les opérations sur les fichiers et les répertoires

## Description

Shows a file-selection dialog.

## Syntaxe

```ahk
S := FileSelect(Options, RootDir, Prompt, Filter)
```

## Paramètres

0..4.

## Valeur de retour

The path(s) or empty.

## Exemple

```ahk
p := FileSelect()
```
