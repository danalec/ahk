## Description

Writes a signed 16-bit number to the file at the current position.

## Syntaxe

```ahk
File.WriteShort(N)
```

## Paramètres

?.

## Valeur de retour

The bytes written.

## Exemple

```ahk
f.WriteShort(1)
```
