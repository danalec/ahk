*AutoHotkey v1.1.37.02* · command · Les opérations sur les fichiers et les répertoires

## Description

Sets the default file encoding (v1).

## Syntaxe

```ahk
FileEncoding Encoding
```

## Paramètres

0..255.

## Valeur de retour

Nothing.

## Exemple

```ahk
FileEncoding UTF-8
```
