## Description

The filesystem of a drive (NTFS/FAT32).

## Syntaxe

```ahk
S := DriveGetFilesystem(Path)
```

## Paramètres

1.

## Valeur de retour

The name.

## Exemple

```ahk
DriveGetFilesystem("C:\")
```
