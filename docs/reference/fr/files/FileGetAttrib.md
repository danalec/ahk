## Description

The attributes of a file (v1).

## Syntaxe

```ahk
FileGetAttrib Out, Filename
```

## Paramètres

1..255.

## Valeur de retour

Nothing.

## Exemple

```ahk
FileGetAttrib a, "a.txt"
```
