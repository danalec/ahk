Français

*AutoHotkey v2.0.31* · command · Raccourcis, chaînes de déclenchement et saisie

## Description

Answers that the hook is there. The hooks of v2 are installed when a hotkey needs them, and the box watches the keyboard from the first hotkey, so the command says that the hook is already there.

## Syntaxe

```ahk
InstallKeybdHook …
```

## Paramètres

[OnOff] [HookName]

## Valeur de retour

nothing

## Erreurs

none; the command never fails.

## Exemple

```ahk
InstallKeybdHook
```
