Français

*AutoHotkey v2.0.31* · command · Raccourcis, chaînes de déclenchement et saisie

## Description

Answers that the hook is there. The mouse is not watched at all: the box watches the keyboard, and the pointer is a device that writes and is never read.

## Syntaxe

```ahk
InstallMouseHook …
```

## Paramètres

[OnOff] [HookName]

## Valeur de retour

nothing

## Erreurs

none; the command never fails.

## Exemple

```ahk
InstallMouseHook
```
