Français

*KeySharp* · function · Raccourcis, chaînes de déclenchement et saisie

## Description

Confines the pointer to a rect (ks).

## Syntaxe

```ahk
ClipCursor(X1, Y1, X2, Y2)
```

## Paramètres

?.

## Valeur de retour

Nothing; no rect frees.

## Exemple

```ahk
ClipCursor(0, 0, 100, 100)
```
