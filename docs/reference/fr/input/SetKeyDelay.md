*AutoHotkey v1.1.37.02* · command · Raccourcis, chaînes de déclenchement et saisie

## Description

Sets the delay/duration of Send keys.

## Syntaxe

```ahk
SetKeyDelay Delay, Duration, Play
```

## Paramètres

0..255.

## Valeur de retour

Nothing.

## Exemple

```ahk
SetKeyDelay
```
