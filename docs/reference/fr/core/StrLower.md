## Description

The text in the lower case.

## Syntaxe

```ahk
S := StrLower(String)
```

## Paramètres

- **String** — The text.

## Valeur de retour

the text, with the capital letters turned into small ones

## Erreurs

none.

## Exemple

```ahk
StrLower("Hello")
```
