## Description

Trim left N chars (v1).

## Syntaxe

```ahk
StringTrimLeft Out, String, N
```

## Paramètres

3..255.

## Valeur de retour

Nothing.

## Exemple

```ahk
StringTrimLeft o, s, 2
```
