## Description

The sine of an angle, in radians.

## Syntaxe

```ahk
N := Sin(Number)
```

## Paramètres

- **Number** — Radians.

## Valeur de retour

a float, whatever went in

## Erreurs

a value that is not a number is refused.

## Exemple

```ahk
Sin(0)
```
