## Description

Converts a value to a float.

## Syntaxe

```ahk
N := Float(Value)
```

## Paramètres

- **Value** — A number or numeric text.

## Valeur de retour

The float.

## Exemple

```ahk
Float("3.5")  ; 3.5
```
