## Description

Whether a string ends with a suffix (ks).

## Syntaxe

```ahk
B := Str.EndsWith(Suffix)
```

## Paramètres

?.

## Valeur de retour

1/0.

## Exemple

```ahk
s.EndsWith("x")
```
