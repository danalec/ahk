## Description

The largest of the numbers.

## Syntaxe

```ahk
N := Max(Numbers...)
```

## Paramètres

- **Numbers** — One or more.

## Valeur de retour

the largest of them

## Erreurs

a value that is not a number is refused.

## Exemple

```ahk
Max(3, 7, 5)
```
