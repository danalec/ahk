## Description

The name of the type of a value.

## Syntaxe

```ahk
Type 
```

## Paramètres

Value

## Valeur de retour

the name: Integer, Float, String, Number, Object, VarRef, Class, or the name of the class of the object

## Erreurs

none.

## Exemple

```ahk
Type(1)
```
