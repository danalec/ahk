## Description

The square root of a number.

## Syntaxe

```ahk
N := Sqrt(Number)
```

## Paramètres

- **Number** — Non-negative.

## Valeur de retour

a float, even for a square

## Erreurs

a negative number is an invalid parameter.

## Exemple

```ahk
Sqrt(9)
```
