## Description

Sets a variable's buffer capacity (v1).

## Syntaxe

```ahk
VarSetCapacity Var, Bytes
```

## Paramètres

1..3.

## Valeur de retour

Nothing.

## Exemple

```ahk
VarSetCapacity v, 16
```
