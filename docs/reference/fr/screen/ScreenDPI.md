*AutoHotkey v2.0.31* · variable · Capture d'écran et fonctions de pixel

## Description

The DPI of the screen (the system DPI).

## Syntaxe

```ahk
N := ScreenDPI
```

## Paramètres

?.

## Valeur de retour

The DPI (96 at 100%).

## Exemple

```ahk
d := ScreenDPI
```
