## Description

Adds to a variable (v1).

## Syntaxe

```ahk
EnvAdd Var, Value
```

## Paramètres

- **Var** — The variable.
- **Value** — The addend.

## Valeur de retour

Nothing.

## Exemple

```ahk
EnvAdd x, 1
```
