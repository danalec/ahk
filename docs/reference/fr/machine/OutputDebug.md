## Description

Writes to the debugger log (OutputDebugString).

## Syntaxe

```ahk
OutputDebug Text
```

## Paramètres

- **Text** — The text.

## Valeur de retour

Nothing.

## Exemple

```ahk
OutputDebug "trace"
```
