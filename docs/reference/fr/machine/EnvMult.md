## Description

Multiplies a variable (v1).

## Syntaxe

```ahk
EnvMult Var, Value
```

## Paramètres

- **Var** — The variable.
- **Value** — The factor.

## Valeur de retour

Nothing.

## Exemple

```ahk
EnvMult x, 2
```
