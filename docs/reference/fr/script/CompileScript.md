*KeySharp* · function · L'analyseur et l'exécution du script

## Description

Compiles a script to a string/bytes (ks).

## Syntaxe

```ahk
B := CompileScript(Path)
```

## Paramètres

?.

## Valeur de retour

The compiled form.

## Exemple

```ahk
CompileScript("a.ahk")
```
