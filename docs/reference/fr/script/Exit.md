*KeySharp* · method · `Thread` · L'analyseur et l'exécution du script

## Description

Stops the script. The code is kept, and the script stops at the end of the statement it was asked in.

## Syntaxe

```ahk
Exit 
```

## Paramètres

[Code]

## Valeur de retour

the code

## Erreurs

none.

## Exemple

```ahk
Exit 0
```
