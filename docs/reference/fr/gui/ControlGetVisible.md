*AutoHotkey v2.0.31* · command · Fenêtres d'interface et automatisation des fenêtres

## Description

Reads whether a control is visible.

## Syntaxe

```ahk
B := ControlGetVisible(Control, WinTitle)
```

## Paramètres

1..5.

## Valeur de retour

1/0.

## Exemple

```ahk
ControlGetVisible("Edit1")
```
