*KeySharp* · function · Fenêtres d'interface et automatisation des fenêtres

## Description

Whether a window is enabled.

## Syntaxe

```ahk
B := WinGetEnabled(WinTitle)
```

## Paramètres

?.

## Valeur de retour

1/0.

## Exemple

```ahk
WinGetEnabled("A")
```
