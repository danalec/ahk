*AutoHotkey v2.0.31* · command · Fenêtres d'interface et automatisation des fenêtres

## Description

Adds an item to a list control.

## Syntaxe

```ahk
ControlAddItem Text, Control, WinTitle
```

## Paramètres

2..6.

## Valeur de retour

The index.

## Exemple

```ahk
ControlAddItem "x", "ListBox1"
```
