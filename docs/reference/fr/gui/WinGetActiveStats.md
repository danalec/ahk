## Description

Reads the active window's title/pos.

## Syntaxe

```ahk
WinGetActiveStats &T, &X, &Y, &W, &H
```

## Paramètres

5..255.

## Valeur de retour

Nothing.

## Exemple

```ahk
WinGetActiveStats &t, &x, &y, &w, &h
```
