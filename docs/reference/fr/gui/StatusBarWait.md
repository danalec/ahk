*AutoHotkey v1.1.37.02* · command · Fenêtres d'interface et automatisation des fenêtres

## Description

Waits for a status bar text.

## Syntaxe

```ahk
StatusBarWait Text, Timeout, Part, WinTitle
```

## Paramètres

0..255.

## Valeur de retour

Nothing.

## Exemple

```ahk
StatusBarWait "ready"
```
