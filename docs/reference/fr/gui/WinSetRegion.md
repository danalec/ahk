*AutoHotkey v2.0.31* · command · Fenêtres d'interface et automatisation des fenêtres

## Description

Sets a window's region.

## Syntaxe

```ahk
WinSetRegion Options, WinTitle
```

## Paramètres

0..5.

## Valeur de retour

Nothing.

## Exemple

```ahk
WinSetRegion "0-0 W100 H100"
```
