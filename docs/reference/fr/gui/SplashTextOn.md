*AutoHotkey v1.1.37.02* · command · Fenêtres d'interface et automatisation des fenêtres

## Description

Shows a splash text window (v1).

## Syntaxe

```ahk
SplashTextOn W, H, Title, Text
```

## Paramètres

0..255.

## Valeur de retour

Nothing.

## Exemple

```ahk
SplashTextOn 200, 100, "t", "x"
```
