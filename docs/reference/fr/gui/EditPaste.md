*AutoHotkey v2.0.31* · command · Fenêtres d'interface et automatisation des fenêtres

## Description

Pastes text at the caret of an edit.

## Syntaxe

```ahk
EditPaste Text, Control, WinTitle
```

## Paramètres

2..6.

## Valeur de retour

Nothing.

## Exemple

```ahk
EditPaste "x", "Edit1"
```
