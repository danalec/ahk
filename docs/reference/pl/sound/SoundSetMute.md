## Opis

Mutes/unmutes a device.

## Składnia

```ahk
SoundSetMute Mute, Device
```

## Parametry

- **Mute** — 1/0.
- **Device** — The device.

## Wartość zwracana

Nothing.

## Przykład

```ahk
SoundSetMute 1
```
