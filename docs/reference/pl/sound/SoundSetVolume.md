## Opis

Sets the volume of a device (0..100).

## Składnia

```ahk
SoundSetVolume Volume, Device
```

## Parametry

- **Volume** — 0..100.
- **Device** — The device.

## Wartość zwracana

Nothing.

## Przykład

```ahk
SoundSetVolume 50
```
