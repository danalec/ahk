## Opis

Reads the wave volume (v1).

## Składnia

```ahk
V := SoundGetWaveVolume(Device)
```

## Parametry

- **Device** — The device.

## Wartość zwracana

The volume.

## Przykład

```ahk
v := SoundGetWaveVolume()
```
