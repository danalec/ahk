*AutoHotkey v1.1.37.02* · command · Dźwięk

## Opis

Sets a sound component/control (v1 shape).

## Składnia

```ahk
SoundSet NewValue, Component, Control, Device
```

## Parametry

- **NewValue** — The value.
- **Component/Control/Device** — Selectors.

## Wartość zwracana

Nothing.

## Przykład

```ahk
SoundSet 50, , "Volume"
```
