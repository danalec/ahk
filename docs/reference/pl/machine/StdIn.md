*KeySharp* · method · `ScriptProcess` · Maszyna, procesy i środowisko

## Opis

Writes to the standard input of a ScriptProcess.

## Składnia

```ahk
Proc.StdIn(Text)
```

## Parametry

- **Text** — The text.

## Wartość zwracana

Nothing.

## Przykład

```ahk
p.StdIn("hi")
```
