## Opis

Subtracts from a variable (v1).

## Składnia

```ahk
EnvSub Var, Value
```

## Parametry

- **Var** — The variable.
- **Value** — The subtrahend.

## Wartość zwracana

Nothing.

## Przykład

```ahk
EnvSub x, 1
```
