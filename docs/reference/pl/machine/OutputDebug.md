## Opis

Writes to the debugger log (OutputDebugString).

## Składnia

```ahk
OutputDebug Text
```

## Parametry

- **Text** — The text.

## Wartość zwracana

Nothing.

## Przykład

```ahk
OutputDebug "trace"
```
