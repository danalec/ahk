*AutoHotkey v2.0.31* · variable · Interfejsy API rejestru

## Opis

Sets the registry view (32/64-bit) for the thread.

## Składnia

```ahk
RegView View
```

## Parametry

- **View** — 32/64/Default.

## Wartość zwracana

Nothing.

## Przykład

```ahk
RegView 64
```
