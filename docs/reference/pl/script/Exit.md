*KeySharp* · method · `Thread` · Parser i wykonanie skryptu

## Opis

Stops the script. The code is kept, and the script stops at the end of the statement it was asked in.

## Składnia

```ahk
Exit 
```

## Parametry

[Code]

## Wartość zwracana

the code

## Błędy

none.

## Przykład

```ahk
Exit 0
```
