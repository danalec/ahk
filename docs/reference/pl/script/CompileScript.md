*KeySharp* · function · Parser i wykonanie skryptu

## Opis

Compiles a script to a string/bytes (ks).

## Składnia

```ahk
B := CompileScript(Path)
```

## Parametry

?.

## Wartość zwracana

The compiled form.

## Przykład

```ahk
CompileScript("a.ahk")
```
