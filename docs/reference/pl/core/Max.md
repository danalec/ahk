## Opis

The largest of the numbers.

## Składnia

```ahk
N := Max(Numbers...)
```

## Parametry

- **Numbers** — One or more.

## Wartość zwracana

the largest of them

## Błędy

a value that is not a number is refused.

## Przykład

```ahk
Max(3, 7, 5)
```
