## Opis

Sets a variable's buffer capacity (v1).

## Składnia

```ahk
VarSetCapacity Var, Bytes
```

## Parametry

1..3.

## Wartość zwracana

Nothing.

## Przykład

```ahk
VarSetCapacity v, 16
```
