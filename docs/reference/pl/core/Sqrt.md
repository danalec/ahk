## Opis

The square root of a number.

## Składnia

```ahk
N := Sqrt(Number)
```

## Parametry

- **Number** — Non-negative.

## Wartość zwracana

a float, even for a square

## Błędy

a negative number is an invalid parameter.

## Przykład

```ahk
Sqrt(9)
```
