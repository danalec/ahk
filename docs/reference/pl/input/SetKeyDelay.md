## Opis

Sets the delay/duration of Send keys.

## Składnia

```ahk
SetKeyDelay Delay, Duration, Play
```

## Parametry

0..255.

## Wartość zwracana

Nothing.

## Przykład

```ahk
SetKeyDelay
```

## Powiązane

[`Sleep`](Sleep.md), [`Send`](Send.md)
