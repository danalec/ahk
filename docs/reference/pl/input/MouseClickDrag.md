*AutoHotkey v1.1.37.02* · command · Skróty, ciągi wyzwalające i wprowadzanie

## Opis

Drags the mouse from one point to another.

## Składnia

```ahk
MouseClickDrag Button, X1, Y1, X2, Y2, Speed
```

## Parametry

1..255.

## Wartość zwracana

Nothing.

## Przykład

```ahk
MouseClickDrag "L", 0, 0, 100, 100
```

[`Click`](Click.md), [`MouseMove`](MouseMove.md)
