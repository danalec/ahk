*KeySharp* · function · Skróty, ciągi wyzwalające i wprowadzanie

## Opis

Confines the pointer to a rect (ks).

## Składnia

```ahk
ClipCursor(X1, Y1, X2, Y2)
```

## Parametry

?.

## Wartość zwracana

Nothing; no rect frees.

## Przykład

```ahk
ClipCursor(0, 0, 100, 100)
```
