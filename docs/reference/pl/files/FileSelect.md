*AutoHotkey v2.0.31* · command · Operacje na plikach i katalogach

## Opis

Shows a file-selection dialog.

## Składnia

```ahk
S := FileSelect(Options, RootDir, Prompt, Filter)
```

## Parametry

0..4.

## Wartość zwracana

The path(s) or empty.

## Przykład

```ahk
p := FileSelect()
```
