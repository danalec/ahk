*AutoHotkey v2.0.31* · command · Operacje na plikach i katalogach

## Opis

The free space of a drive in MB.

## Składnia

```ahk
N := DriveGetSpaceFree(Path)
```

## Parametry

1.

## Wartość zwracana

The free space.

## Przykład

```ahk
DriveGetSpaceFree("C:\")
```
