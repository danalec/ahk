*AutoHotkey v1.1.37.02* · command · Operacje na plikach i katalogach

## Opis

Removes a directory (v1).

## Składnia

```ahk
FileRemoveDir Path, Recurse
```

## Parametry

1..255.

## Wartość zwracana

Nothing.

## Przykład

```ahk
FileRemoveDir "a", 1
```
