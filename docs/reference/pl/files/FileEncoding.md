*AutoHotkey v1.1.37.02* · command · Operacje na plikach i katalogach

## Opis

Sets the default file encoding (v1).

## Składnia

```ahk
FileEncoding Encoding
```

## Parametry

0..255.

## Wartość zwracana

Nothing.

## Przykład

```ahk
FileEncoding UTF-8
```

## Powiązane

[`FileRead`](FileRead.md), [`FileAppend`](FileAppend.md)
