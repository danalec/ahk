*AutoHotkey v1.1.37.02* · command · Okna GUI i automatyzacja okien

## Opis

Reads a window property (v1).

## Składnia

```ahk
WinGet Out, Cmd, WinTitle
```

## Parametry

1..255.

## Wartość zwracana

Nothing.

## Przykład

```ahk
WinGet t, "Text"
```
