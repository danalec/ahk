*AutoHotkey v2.0.31* · command · Okna GUI i automatyzacja okien

## Opis

The transparency of a window.

## Składnia

```ahk
N := WinGetTransparent(WinTitle)
```

## Parametry

0..4.

## Wartość zwracana

0..255 or empty.

## Przykład

```ahk
WinGetTransparent("A")
```
