*AutoHotkey v2.0.31* · command · Okna GUI i automatyzacja okien

## Opis

Sets the tray icon.

## Składnia

```ahk
TraySetIcon Filename, Number, Freeze
```

## Parametry

0..3.

## Wartość zwracana

Nothing.

## Przykład

```ahk
TraySetIcon "a.ico"
```
