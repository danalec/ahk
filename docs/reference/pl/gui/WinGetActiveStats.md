## Opis

Reads the active window's title/pos.

## Składnia

```ahk
WinGetActiveStats &T, &X, &Y, &W, &H
```

## Parametry

5..255.

## Wartość zwracana

Nothing.

## Przykład

```ahk
WinGetActiveStats &t, &x, &y, &w, &h
```
