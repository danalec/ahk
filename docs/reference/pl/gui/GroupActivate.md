*AutoHotkey v1.1.37.02* · command · Okna GUI i automatyzacja okien

## Opis

Activates the next window of a group.

## Składnia

```ahk
GroupActivate Group
```

## Parametry

1..255.

## Wartość zwracana

Nothing.

## Przykład

```ahk
GroupActivate "g"
```
