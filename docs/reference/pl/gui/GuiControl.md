## Opis

Operates on a control (v1).

## Składnia

```ahk
GuiControl Cmd, ControlID, Value
```

## Parametry

2..255.

## Wartość zwracana

Nothing.

## Przykład

```ahk
GuiControl "", "Edit1", "x"
```
