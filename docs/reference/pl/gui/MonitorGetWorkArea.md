## Opis

Reads the work area of a monitor.

## Składnia

```ahk
MonitorGetWorkArea N, &L, &T, &R, &B
```

## Parametry

0..5.

## Wartość zwracana

Nothing.

## Przykład

```ahk
MonitorGetWorkArea(1, &l, &t, &r, &b)
```
