## Opis

The index of the first item matching a predicate (ks).

## Składnia

```ahk
N := Arr.FindIndex(Pred)
```

## Parametry

?.

## Wartość zwracana

The index or 0.

## Przykład

```ahk
a.FindIndex((x) => x = 2)
```
