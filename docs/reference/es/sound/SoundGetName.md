## Descripción

Reads the name of a sound device.

## Sintaxis

```ahk
S := SoundGetName(Device)
```

## Parámetros

- **Device** — The device index.

## Valor de retorno

The name.

## Ejemplo

```ahk
n := SoundGetName()
```
