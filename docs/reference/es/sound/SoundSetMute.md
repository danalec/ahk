## Descripción

Mutes/unmutes a device.

## Sintaxis

```ahk
SoundSetMute Mute, Device
```

## Parámetros

- **Mute** — 1/0.
- **Device** — The device.

## Valor de retorno

Nothing.

## Ejemplo

```ahk
SoundSetMute 1
```
