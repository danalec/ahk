## Descripción

Sets the wave volume (v1).

## Sintaxis

```ahk
SoundSetWaveVolume Volume, Device
```

## Parámetros

- **Volume** — 0..100.
- **Device** — The device.

## Valor de retorno

Nothing.

## Ejemplo

```ahk
SoundSetWaveVolume 50
```
