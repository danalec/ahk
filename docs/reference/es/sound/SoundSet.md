*AutoHotkey v1.1.37.02* · command · El sonido

## Descripción

Sets a sound component/control (v1 shape).

## Sintaxis

```ahk
SoundSet NewValue, Component, Control, Device
```

## Parámetros

- **NewValue** — The value.
- **Component/Control/Device** — Selectors.

## Valor de retorno

Nothing.

## Ejemplo

```ahk
SoundSet 50, , "Volume"
```
