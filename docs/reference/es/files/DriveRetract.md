*AutoHotkey v2.0.31* · command · Operaciones de archivos y directorios

## Descripción

Retracts a CD/drive. (Windows).

## Sintaxis

```ahk
DriveRetract Drive, Value
```

## Parámetros

0..1.

## Valor de retorno

Nothing.

## Ejemplo

```ahk
DriveRetract "D:"
```
