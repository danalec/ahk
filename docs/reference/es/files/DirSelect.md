*AutoHotkey v2.0.31* · command · Operaciones de archivos y directorios

## Descripción

Shows a folder-selection dialog.

## Sintaxis

```ahk
S := DirSelect(StartingFolder, Options, Prompt)
```

## Parámetros

0..3.

## Valor de retorno

The path or empty.

## Ejemplo

```ahk
p := DirSelect()
```
