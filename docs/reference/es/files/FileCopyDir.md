## Descripción

Copies a directory (v1).

## Sintaxis

```ahk
FileCopyDir Source, Dest, Overwrite
```

## Parámetros

2..255.

## Valor de retorno

Nothing.

## Ejemplo

```ahk
FileCopyDir "a", "b", 1
```
