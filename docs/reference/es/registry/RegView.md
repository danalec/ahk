*AutoHotkey v2.0.31* · variable · API del registro

## Descripción

Sets the registry view (32/64-bit) for the thread.

## Sintaxis

```ahk
RegView View
```

## Parámetros

- **View** — 32/64/Default.

## Valor de retorno

Nothing.

## Ejemplo

```ahk
RegView 64
```
