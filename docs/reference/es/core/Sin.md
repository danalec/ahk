## Descripción

The sine of an angle, in radians.

## Sintaxis

```ahk
N := Sin(Number)
```

## Parámetros

- **Number** — Radians.

## Valor de retorno

a float, whatever went in

## Errores

a value that is not a number is refused.

## Ejemplo

```ahk
Sin(0)
```
