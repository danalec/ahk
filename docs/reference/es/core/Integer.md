## Descripción

Converts a value to an integer.

## Sintaxis

```ahk
N := Integer(Value)
```

## Parámetros

- **Value** — A number or numeric text.

## Valor de retorno

The integer; throws TypeError if not convertible.

## Ejemplo

```ahk
Integer("42")  ; 42
```
