## Descripción

The text in the upper case.

## Sintaxis

```ahk
S := StrUpper(String)
```

## Parámetros

- **String** — The text.

## Valor de retorno

the text, with the small letters turned into capital ones

## Errores

none.

## Ejemplo

```ahk
StrUpper("hello")
```
