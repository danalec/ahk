## Descripción

Converts a value to a number (integer or float).

## Sintaxis

```ahk
N := Number(Value)
```

## Parámetros

?.

## Valor de retorno

The number; throws TypeError if not convertible.

## Ejemplo

```ahk
Number("3.5")
```
