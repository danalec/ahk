## Descripción

The square root of a number.

## Sintaxis

```ahk
N := Sqrt(Number)
```

## Parámetros

- **Number** — Non-negative.

## Valor de retorno

a float, even for a square

## Errores

a negative number is an invalid parameter.

## Ejemplo

```ahk
Sqrt(9)
```
