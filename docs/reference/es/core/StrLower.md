## Descripción

The text in the lower case.

## Sintaxis

```ahk
S := StrLower(String)
```

## Parámetros

- **String** — The text.

## Valor de retorno

the text, with the capital letters turned into small ones

## Errores

none.

## Ejemplo

```ahk
StrLower("Hello")
```
