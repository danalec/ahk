## Descripción

Converts a value to a float.

## Sintaxis

```ahk
N := Float(Value)
```

## Parámetros

- **Value** — A number or numeric text.

## Valor de retorno

The float.

## Ejemplo

```ahk
Float("3.5")  ; 3.5
```
