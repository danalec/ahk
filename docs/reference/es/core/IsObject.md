## Descripción

Whether a value is an object. Everything that is not a number and not a text is an object: an array, a map, a class instance and a reference.

## Sintaxis

```ahk
IsObject …
```

## Parámetros

Value

## Valor de retorno

1 when it is an object, 0 when it is not

## Errores

none.

## Ejemplo

```ahk
IsObject([])
```
