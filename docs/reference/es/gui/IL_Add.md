## Descripción

Adds an image to an image list.

## Sintaxis

```ahk
N := IL_Add(IL, Filename, Icon, Resize)
```

## Parámetros

2..4.

## Valor de retorno

The index.

## Ejemplo

```ahk
IL_Add(h, "a.ico")
```
