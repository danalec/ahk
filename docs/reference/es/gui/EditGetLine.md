## Descripción

Reads a line of an edit.

## Sintaxis

```ahk
S := EditGetLine(N, Control, WinTitle)
```

## Parámetros

2..6.

## Valor de retorno

The line.

## Ejemplo

```ahk
EditGetLine(1, "Edit1")
```
