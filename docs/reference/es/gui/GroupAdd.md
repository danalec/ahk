## Descripción

Adds a window to a group.

## Sintaxis

```ahk
GroupAdd Group, WinTitle
```

## Parámetros

1..255.

## Valor de retorno

Nothing.

## Ejemplo

```ahk
GroupAdd "g", "ahk_class X"
```
