## Descripción

Sets the tray icon.

## Sintaxis

```ahk
TraySetIcon Filename, Number, Freeze
```

## Parámetros

0..3.

## Valor de retorno

Nothing.

## Ejemplo

```ahk
TraySetIcon "a.ico"
```
