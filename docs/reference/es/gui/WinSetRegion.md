*AutoHotkey v2.0.31* · command · Ventanas de la GUI y automatización de ventanas

## Descripción

Sets a window's region.

## Sintaxis

```ahk
WinSetRegion Options, WinTitle
```

## Parámetros

0..5.

## Valor de retorno

Nothing.

## Ejemplo

```ahk
WinSetRegion "0-0 W100 H100"
```
