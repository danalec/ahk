## Descripción

Reads the bounds of a monitor.

## Sintaxis

```ahk
MonitorGet N, &L, &T, &R, &B
```

## Parámetros

0..5.

## Valor de retorno

Nothing.

## Ejemplo

```ahk
MonitorGet(1, &l, &t, &r, &b)
```
