*AutoHotkey v1.1.37.02* · command · Ventanas de la GUI y automatización de ventanas

## Descripción

Shows a splash text window (v1).

## Sintaxis

```ahk
SplashTextOn W, H, Title, Text
```

## Parámetros

0..255.

## Valor de retorno

Nothing.

## Ejemplo

```ahk
SplashTextOn 200, 100, "t", "x"
```
