*AutoHotkey v1.1.37.02* · command · Ventanas de la GUI y automatización de ventanas

## Descripción

Forces a window to close.

## Sintaxis

```ahk
WinKill WinTitle, SecondsToWait
```

## Parámetros

0..255.

## Valor de retorno

Nothing.

## Ejemplo

```ahk
WinKill "A"
```
