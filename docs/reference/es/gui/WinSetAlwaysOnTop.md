*AutoHotkey v2.0.31* · command · Ventanas de la GUI y automatización de ventanas

## Descripción

Sets a window always-on-top.

## Sintaxis

```ahk
WinSetAlwaysOnTop On|Off|Toggle, WinTitle
```

## Parámetros

0..5.

## Valor de retorno

Nothing.

## Ejemplo

```ahk
WinSetAlwaysOnTop 1, "A"
```
