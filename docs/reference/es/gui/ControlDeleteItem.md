*AutoHotkey v2.0.31* · command · Ventanas de la GUI y automatización de ventanas

## Descripción

Deletes an item by index.

## Sintaxis

```ahk
ControlDeleteItem N, Control, WinTitle
```

## Parámetros

2..6.

## Valor de retorno

Nothing.

## Ejemplo

```ahk
ControlDeleteItem 1, "ListBox1"
```
