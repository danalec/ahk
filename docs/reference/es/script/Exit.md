*KeySharp* · method · `Thread` · El analizador y la ejecución del script

## Descripción

Stops the script. The code is kept, and the script stops at the end of the statement it was asked in.

## Sintaxis

```ahk
Exit 
```

## Parámetros

[Code]

## Valor de retorno

the code

## Errores

none.

## Ejemplo

```ahk
Exit 0
```
