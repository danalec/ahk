Español

*AutoHotkey v2.0.31* · command · El analizador y la ejecución del script

## Descripción

Answers 0 and changes nothing. A script of this runtime runs from its first line to its last and has no message loop to stay alive for, so the setting has no meaning here.

## Sintaxis

```ahk
Persistent …
```

## Parámetros

[OnOff]

## Valor de retorno

the integer 0

## Errores

none.

## Ejemplo

```ahk
Persistent
```
