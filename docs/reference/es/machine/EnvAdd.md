## Descripción

Adds to a variable (v1).

## Sintaxis

```ahk
EnvAdd Var, Value
```

## Parámetros

- **Var** — The variable.
- **Value** — The addend.

## Valor de retorno

Nothing.

## Ejemplo

```ahk
EnvAdd x, 1
```
