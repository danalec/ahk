## Descripción

Writes to the standard input of a ScriptProcess.

## Sintaxis

```ahk
Proc.StdIn(Text)
```

## Parámetros

- **Text** — The text.

## Valor de retorno

Nothing.

## Ejemplo

```ahk

```
