## Descripción

Subtracts from a variable (v1).

## Sintaxis

```ahk
EnvSub Var, Value
```

## Parámetros

- **Var** — The variable.
- **Value** — The subtrahend.

## Valor de retorno

Nothing.

## Ejemplo

```ahk
EnvSub x, 1
```
