*AutoHotkey v1.1.37.02* · command · La máquina, los procesos y el entorno

## Descripción

Shuts down / logs off / reboots the machine.

## Sintaxis

```ahk
Shutdown Code
```

## Parámetros

- **Code** — The shutdown flags (1 logoff, 2 reboot, 8 power-down...).

## Valor de retorno

Nothing.

## Ejemplo

```ahk
Shutdown 2
```
