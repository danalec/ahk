English

*KeySharp* · function · Hotkeys, hotstrings, and input

## Description

Confines the pointer to a rect (ks).

## Syntax

```ahk
ClipCursor(X1, Y1, X2, Y2)
```

## Parameters

?.

## Return value

Nothing; no rect frees.

## Example

```ahk
ClipCursor(0, 0, 100, 100)
```
