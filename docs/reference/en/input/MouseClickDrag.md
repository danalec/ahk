English

*AutoHotkey v1.1.37.02* · command · Hotkeys, hotstrings, and input

## Description

Drags the mouse from one point to another.

## Syntax

```ahk
MouseClickDrag Button, X1, Y1, X2, Y2, Speed
```

## Parameters

1..255.

## Return value

Nothing.

## Example

```ahk
MouseClickDrag "L", 0, 0, 100, 100
```
