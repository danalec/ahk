*AutoHotkey v1.1.37.02* · command · The machine, the processes and the environment

## Description

v1: free space of a drive.

## Syntax

```ahk
DriveSpaceFree Out, Path
```

## Parameters

2..255.

## Return value

Nothing.

## Example

```ahk
DriveSpaceFree f, "C:\"
```
