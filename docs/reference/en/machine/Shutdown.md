English

*AutoHotkey v1.1.37.02* · command · The machine, the processes and the environment

## Description

Shuts down / logs off / reboots the machine.

## Syntax

```ahk
Shutdown Code
```

## Parameters

- **Code** — The shutdown flags (1 logoff, 2 reboot, 8 power-down...).

## Return value

Nothing.

## Example

```ahk
Shutdown 2
```
