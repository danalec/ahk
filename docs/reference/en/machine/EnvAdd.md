*AutoHotkey v1.1.37.02* · command · The machine, the processes and the environment

## Description

Adds to a variable (v1).

## Syntax

```ahk
EnvAdd Var, Value
```

## Parameters

- **Var** — The variable.
- **Value** — The addend.

## Return value

Nothing.

## Example

```ahk
EnvAdd x, 1
```
