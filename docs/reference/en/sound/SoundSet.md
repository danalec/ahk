English

*AutoHotkey v1.1.37.02* · command · Sound

## Description

Sets a sound component/control (v1 shape).

## Syntax

```ahk
SoundSet NewValue, Component, Control, Device
```

## Parameters

- **NewValue** — The value.
- **Component/Control/Device** — Selectors.

## Return value

Nothing.

## Example

```ahk
SoundSet 50, , "Volume"
```
