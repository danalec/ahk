English

*AutoHotkey v1.1.37.02* · command · Sound

## Description

Sets the wave volume (v1).

## Syntax

```ahk
SoundSetWaveVolume Volume, Device
```

## Parameters

- **Volume** — 0..100.
- **Device** — The device.

## Return value

Nothing.

## Example

```ahk
SoundSetWaveVolume 50
```
