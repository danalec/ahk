*AutoHotkey v1.1.37.02* · command · The core of the language: text, math and patterns

## Description

Sets the default string case sense (v1).

## Syntax

```ahk
StringCaseSense On|Off|Locale
```

## Parameters

1..255.

## Return value

Nothing.

## Example

```ahk
StringCaseSense On
```
