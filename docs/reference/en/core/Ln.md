*AutoHotkey v1.1.37.02* · function · The core of the language: text, math and patterns

## Description

The natural logarithm of a number.

## Syntax

```ahk
Ln …
```

## Parameters

Number

## Return value

a float

## Errors

a negative number is an invalid parameter; a value that is not a number is refused.

## Example

```ahk
Ln(1)
```
