English

*AutoHotkey v2.0.31* · command · GUI windows and window automation

## Description

Adds an image to an image list.

## Syntax

```ahk
N := IL_Add(IL, Filename, Icon, Resize)
```

## Parameters

2..4.

## Return value

The index.

## Example

```ahk
IL_Add(h, "a.ico")
```
