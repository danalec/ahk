English

*AutoHotkey v1.1.37.02* · command · GUI windows and window automation

## Description

Reads a window property (v1).

## Syntax

```ahk
WinGet Out, Cmd, WinTitle
```

## Parameters

1..255.

## Return value

Nothing.

## Example

```ahk
WinGet t, "Text"
```
