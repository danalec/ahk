*AutoHotkey v2.0.31* · command · GUI windows and window automation

## Description

The transparency of a window.

## Syntax

```ahk
N := WinGetTransparent(WinTitle)
```

## Parameters

0..4.

## Return value

0..255 or empty.

## Example

```ahk
WinGetTransparent("A")
```
