English

*AutoHotkey v1.1.37.02* · command · GUI windows and window automation

## Description

Shows a splash text window (v1).

## Syntax

```ahk
SplashTextOn W, H, Title, Text
```

## Parameters

0..255.

## Return value

Nothing.

## Example

```ahk
SplashTextOn 200, 100, "t", "x"
```
