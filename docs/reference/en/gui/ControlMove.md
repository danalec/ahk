English

*AutoHotkey v1.1.37.02* · command · GUI windows and window automation

## Description

Moves/resizes a control.

## Syntax

```ahk
ControlMove X, Y, W, H, Control, WinTitle
```

## Parameters

0..255.

## Return value

Nothing.

## Example

```ahk
ControlMove 0, 0, 100, 20, "Edit1"
```
