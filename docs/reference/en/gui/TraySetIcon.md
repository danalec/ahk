*AutoHotkey v2.0.31* · command · GUI windows and window automation

## Description

Sets the tray icon.

## Syntax

```ahk
TraySetIcon Filename, Number, Freeze
```

## Parameters

0..3.

## Return value

Nothing.

## Example

```ahk
TraySetIcon "a.ico"
```
