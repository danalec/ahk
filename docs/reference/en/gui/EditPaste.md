English

*AutoHotkey v2.0.31* · command · GUI windows and window automation

## Description

Pastes text at the caret of an edit.

## Syntax

```ahk
EditPaste Text, Control, WinTitle
```

## Parameters

2..6.

## Return value

Nothing.

## Example

```ahk
EditPaste "x", "Edit1"
```
