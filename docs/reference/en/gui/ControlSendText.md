English

*AutoHotkey v2.0.31* · command · GUI windows and window automation

## Description

Sends text to a control.

## Syntax

```ahk
ControlSendText Text, Control, WinTitle
```

## Parameters

1..6.

## Return value

Nothing.

## Example

```ahk
ControlSendText "x", "Edit1"
```
