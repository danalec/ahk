*AutoHotkey v1.1.37.02* · command · GUI windows and window automation

## Description

Waits for a status bar text.

## Syntax

```ahk
StatusBarWait Text, Timeout, Part, WinTitle
```

## Parameters

0..255.

## Return value

Nothing.

## Example

```ahk
StatusBarWait "ready"
```
