*AutoHotkey v1.1.37.02* · variable · Parser and script execution

## Description

The full path of the runner (the interpreter) of the script.

## Syntax

```ahk
N := A_AhkPath
```

## Parameters

?.

## Return value

The path; empty when not compiled and the host does not say.

## Example

