English

*AutoHotkey v2.0.31* · variable · Registry APIs

## Description

Sets the registry view (32/64-bit) for the thread.

## Syntax

```ahk
RegView View
```

## Parameters

- **View** — 32/64/Default.

## Return value

Nothing.

## Example

```ahk
RegView 64
```
