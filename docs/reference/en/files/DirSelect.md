*AutoHotkey v2.0.31* · command · File and directory operations

## Description

Shows a folder-selection dialog.

## Syntax

```ahk
S := DirSelect(StartingFolder, Options, Prompt)
```

## Parameters

0..3.

## Return value

The path or empty.

## Example

