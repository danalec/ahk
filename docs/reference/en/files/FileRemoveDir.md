*AutoHotkey v1.1.37.02* · command · File and directory operations

## Description

Removes a directory (v1).

## Syntax

```ahk
FileRemoveDir Path, Recurse
```

## Parameters

1..255.

## Return value

Nothing.

## Example

```ahk
FileRemoveDir "a", 1
```
