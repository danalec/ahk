*AutoHotkey v1.1.37.02* · command · File and directory operations

## Description

Sets the default file encoding (v1).

## Syntax

```ahk
FileEncoding Encoding
```

## Parameters

0..255.

## Return value

Nothing.

## Example

```ahk
FileEncoding UTF-8
```
