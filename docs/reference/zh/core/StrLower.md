## 描述

转为小写的文本。

## 语法

```ahk
S := StrLower(String)
```

## 参数

- **String** — The text.

## 返回值

大写字母变成小写之后的文本

## 错误

none.

## 示例

```ahk
StrLower("Hello")
```
