## 描述

这些数字中最大的一个。

## 语法

```ahk
N := Max(Numbers...)
```

## 参数

- **Numbers** — One or more.

## 返回值

其中最大的数字

## 错误

a value that is not a number is refused.

## 示例

```ahk
Max(3, 7, 5)
```
