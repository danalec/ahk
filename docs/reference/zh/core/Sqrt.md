## 描述

一个数的平方根。

## 语法

```ahk
N := Sqrt(Number)
```

## 参数

- **Number** — Non-negative.

## 返回值

浮点数，即使结果是整数也是浮点数

## 错误

a negative number is an invalid parameter.

## 示例

```ahk
Sqrt(9)
```
