## 描述

一个角度（弧度）的余弦。

## 语法

```ahk
N := Cos(Number)
```

## 参数

- **Number** — Radians.

## 返回值

浮点数，无论输入是什么

## 错误

a value that is not a number is refused.

## 示例

```ahk
Cos(0)
```
