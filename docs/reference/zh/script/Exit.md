*KeySharp* · method · `Thread` · 解析器与脚本执行

## 描述

停止脚本。退出码被保留，脚本在调用它的那条语句结束时停止。

## 语法

```ahk
Exit 
```

## 参数

[Code]

## 返回值

退出码

## 错误

none.

## 示例

```ahk
Exit 0
```
