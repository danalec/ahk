中文（简体）

*AutoHotkey v2.0.31* · command · 解析器与脚本执行

## 描述

返回 0，并且不改变任何东西。这个运行时的脚本从第一行跑到最后一行，没有消息循环可以让它存活，因此这个设置在这里没有意义。

## 语法

```ahk
Persistent …
```

## 参数

[OnOff]

## 返回值

整数 0

## 错误

none.

## 示例

```ahk
Persistent
```
