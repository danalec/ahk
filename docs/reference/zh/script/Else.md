*AutoHotkey v1.1.37.02* · command · 解析器与脚本执行

## 描述

if 的另一分支。else if 可以串联多个条件，第一个匹配的条件会执行。

## 语法

```ahk
Else …
```

## 参数

a statement or a block

## 返回值

无返回值

## 错误

none.

## 示例

```ahk
if (0)
    MsgBox "no"
else
    MsgBox "yes"
```
