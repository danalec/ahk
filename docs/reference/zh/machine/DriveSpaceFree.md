*AutoHotkey v1.1.37.02* · command · 机器、进程与环境

## 描述

v1: free space of a drive.

## 语法

```ahk
DriveSpaceFree Out, Path
```

## 参数

2..255.

## 返回值

Nothing.

## 示例

```ahk
DriveSpaceFree f, "C:\"
```
