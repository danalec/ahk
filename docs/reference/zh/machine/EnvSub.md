## 描述

Subtracts from a variable (v1).

## 语法

```ahk
EnvSub Var, Value
```

## 参数

- **Var** — The variable.
- **Value** — The subtrahend.

## 返回值

Nothing.

## 示例

```ahk
EnvSub x, 1
```
