*AutoHotkey v2.0.31* · command · GUI 窗口与窗口自动化

## 描述

The transparency of a window.

## 语法

```ahk
N := WinGetTransparent(WinTitle)
```

## 参数

0..4.

## 返回值

0..255 or empty.

## 示例

```ahk
WinGetTransparent("A")
```
