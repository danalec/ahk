*AutoHotkey v2.0.31* · command · GUI 窗口与窗口自动化

## 描述

Deletes an item by index.

## 语法

```ahk
ControlDeleteItem N, Control, WinTitle
```

## 参数

2..6.

## 返回值

Nothing.

## 示例

```ahk
ControlDeleteItem 1, "ListBox1"
```
