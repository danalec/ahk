*AutoHotkey v2.0.31* · function · 声音

## 描述

Mutes/unmutes a device.

## 语法

```ahk
SoundSetMute Mute, Device
```

## 参数

- **Mute** — 1/0.
- **Device** — The device.

## 返回值

Nothing.

## 示例

```ahk
SoundSetMute 1
```
