*AutoHotkey v1.1.37.02* · command · 声音

## 描述

Sets the wave volume (v1).

## 语法

```ahk
SoundSetWaveVolume Volume, Device
```

## 参数

- **Volume** — 0..100.
- **Device** — The device.

## 返回值

Nothing.

## 示例

```ahk
SoundSetWaveVolume 50
```
