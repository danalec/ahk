*AutoHotkey v2.0.31* · function · 声音

## 描述

Sets the volume of a device (0..100).

## 语法

```ahk
SoundSetVolume Volume, Device
```

## 参数

- **Volume** — 0..100.
- **Device** — The device.

## 返回值

Nothing.

## 示例

```ahk
SoundSetVolume 50
```
