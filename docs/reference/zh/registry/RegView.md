*AutoHotkey v2.0.31* · variable · 注册表 API

## 描述

Sets the registry view (32/64-bit) for the thread.

## 语法

```ahk
RegView View
```

## 参数

- **View** — 32/64/Default.

## 返回值

Nothing.

## 示例

```ahk
RegView 64
```
