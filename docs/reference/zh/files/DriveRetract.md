*AutoHotkey v2.0.31* · command · 文件与目录操作

## 描述

Retracts a CD/drive. (Windows).

## 语法

```ahk
DriveRetract Drive, Value
```

## 参数

0..1.

## 返回值

Nothing.

## 示例

```ahk
DriveRetract "D:"
```
