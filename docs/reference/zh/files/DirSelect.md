*AutoHotkey v2.0.31* · command · 文件与目录操作

## 描述

Shows a folder-selection dialog.

## 语法

```ahk
S := DirSelect(StartingFolder, Options, Prompt)
```

## 参数

0..3.

## 返回值

The path or empty.

## 示例

```ahk
p := DirSelect()
```
