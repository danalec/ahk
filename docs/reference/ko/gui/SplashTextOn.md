*AutoHotkey v1.1.37.02* · command · GUI 창과 창 자동화

## 설명

Shows a splash text window (v1).

## 구문

```ahk
SplashTextOn W, H, Title, Text
```

## 매개변수

0..255.

## 반환 값

Nothing.

## 예제

```ahk
SplashTextOn 200, 100, "t", "x"
```
