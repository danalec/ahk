*AutoHotkey v2.0.31* · command · GUI 창과 창 자동화

## 설명

Reads the ClassNN of a control.

## 구문

```ahk
S := ControlGetClassNN(Control, WinTitle)
```

## 매개변수

1..5.

## 반환 값

The ClassNN.

## 예제

```ahk
ControlGetClassNN(h)
```
