*AutoHotkey v1.1.37.02* · command · GUI 창과 창 자동화

## 설명

Activates the next window of a group.

## 구문

```ahk
GroupActivate Group
```

## 매개변수

1..255.

## 반환 값

Nothing.

## 예제

```ahk
GroupActivate "g"
```
