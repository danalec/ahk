*AutoHotkey v1.1.37.02* · command · GUI 창과 창 자동화

## 설명

Sets a window property (v1).

## 구문

```ahk
WinSet Cmd, Value, WinTitle
```

## 매개변수

1..255.

## 반환 값

Nothing.

## 예제

```ahk
WinSet "Transparent", 128
```
