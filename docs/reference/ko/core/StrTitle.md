## 설명

Title-cases a string (each word capitalised).

## 구문

```ahk
S := StrTitle(String)
```

## 매개변수

- **String** — The text.

## 반환 값

The title-cased text.

## 예제

```ahk
StrTitle("hello world")  ; "Hello World"
```
