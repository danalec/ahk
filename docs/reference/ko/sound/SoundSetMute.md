## 설명

Mutes/unmutes a device.

## 구문

```ahk
SoundSetMute Mute, Device
```

## 매개변수

- **Mute** — 1/0.
- **Device** — The device.

## 반환 값

Nothing.

## 예제

```ahk
SoundSetMute 1
```
