## 설명

Sets the volume of a device (0..100).

## 구문

```ahk
SoundSetVolume Volume, Device
```

## 매개변수

- **Volume** — 0..100.
- **Device** — The device.

## 반환 값

Nothing.

## 예제

```ahk
SoundSetVolume 50
```
