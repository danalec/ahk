*AutoHotkey v1.1.37.02* · command · 머신, 프로세스, 환경

## 설명

v1: free space of a drive.

## 구문

```ahk
DriveSpaceFree Out, Path
```

## 매개변수

2..255.

## 반환 값

Nothing.

## 예제

```ahk
DriveSpaceFree f, "C:\"
```
