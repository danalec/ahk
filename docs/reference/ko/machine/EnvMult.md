## 설명

Multiplies a variable (v1).

## 구문

```ahk
EnvMult Var, Value
```

## 매개변수

- **Var** — The variable.
- **Value** — The factor.

## 반환 값

Nothing.

## 예제

```ahk
EnvMult x, 2
```
