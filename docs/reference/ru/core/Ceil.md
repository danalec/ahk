## Описание

The whole number above a number.

## Синтаксис

```ahk
N := Ceil(Number)
```

## Параметры

- **Number** — The value.

## Возвращаемое значение

the whole number, a float when the number was not whole

## Ошибки

a value that is not a number is refused.

## Пример

```ahk
Ceil(1.2)
```
