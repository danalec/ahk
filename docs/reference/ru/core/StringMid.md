## Описание

A substring (v1, 1-based).

## Синтаксис

```ahk
StringMid Out, String, Start, N
```

## Параметры

3..255.

## Возвращаемое значение

Nothing.

## Пример

```ahk
StringMid o, s, 2, 3
```
