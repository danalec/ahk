## Описание

The cosine of an angle, in radians.

## Синтаксис

```ahk
N := Cos(Number)
```

## Параметры

- **Number** — Radians.

## Возвращаемое значение

a float, whatever went in

## Ошибки

a value that is not a number is refused.

## Пример

```ahk
Cos(0)
```
