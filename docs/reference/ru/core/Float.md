## Описание

Converts a value to a float.

## Синтаксис

```ahk
N := Float(Value)
```

## Параметры

- **Value** — A number or numeric text.

## Возвращаемое значение

The float.

## Пример

```ahk
Float("3.5")  ; 3.5
```
