## Описание

Normalizes the line endings of a string (ks).

## Синтаксис

```ahk
S := ReplaceLineEndings(Text, Ending)
```

## Параметры

?.

## Возвращаемое значение

The text.

## Пример

```ahk
ReplaceLineEndings(s, "`n")
```
