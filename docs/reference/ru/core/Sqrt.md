## Описание

The square root of a number.

## Синтаксис

```ahk
N := Sqrt(Number)
```

## Параметры

- **Number** — Non-negative.

## Возвращаемое значение

a float, even for a square

## Ошибки

a negative number is an invalid parameter.

## Пример

```ahk
Sqrt(9)
```
