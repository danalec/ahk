## Описание

The largest of the numbers.

## Синтаксис

```ahk
N := Max(Numbers...)
```

## Параметры

- **Numbers** — One or more.

## Возвращаемое значение

the largest of them

## Ошибки

a value that is not a number is refused.

## Пример

```ahk
Max(3, 7, 5)
```
