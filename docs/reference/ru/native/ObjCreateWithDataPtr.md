*KeySharp* · function · Вызовы нативных функций (DllCall)

## Описание

Creates an object over a data pointer (ks).

## Синтаксис

```ahk
O := ObjCreateWithDataPtr(Ptr, Size)
```

## Параметры

?.

## Возвращаемое значение

The object.

## Пример

```ahk
o := ObjCreateWithDataPtr(p, n)
```
