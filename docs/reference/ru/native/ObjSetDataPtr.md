## Описание

Sets the data pointer of an object (ks).

## Синтаксис

```ahk
ObjSetDataPtr Obj, Ptr, Size
```

## Параметры

?.

## Возвращаемое значение

Nothing.

## Пример

```ahk
ObjSetDataPtr o, p, n
```
