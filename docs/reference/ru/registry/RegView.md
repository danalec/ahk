Русский

*AutoHotkey v2.0.31* · variable · API реестра

## Описание

Sets the registry view (32/64-bit) for the thread.

## Синтаксис

```ahk
RegView View
```

## Параметры

- **View** — 32/64/Default.

## Возвращаемое значение

Nothing.

## Пример

```ahk
RegView 64
```
