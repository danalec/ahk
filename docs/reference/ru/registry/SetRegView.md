*AutoHotkey v1.1.37.02* · command · API реестра

## Описание

Sets the registry view (function form).

## Синтаксис

```ahk
SetRegView View
```

## Параметры

- **View** — 32/64/Default.

## Возвращаемое значение

The previous view.

## Пример

```ahk
SetRegView 64
```
