*KeySharp* · method · `Thread` · Разбор и выполнение скрипта

## Описание

Stops the script. The code is kept, and the script stops at the end of the statement it was asked in.

## Синтаксис

```ahk
Exit 
```

## Параметры

[Code]

## Возвращаемое значение

the code

## Ошибки

none.

## Пример

```ahk
Exit 0
```
