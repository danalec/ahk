*AutoHotkey v1.1.37.02* · command · Разбор и выполнение скрипта

## Описание

v1: if the last MsgBox answered a button.

## Синтаксис

```ahk
IfMsgBox Button
```

## Параметры

1..255.

## Возвращаемое значение

A conditional.

## Пример

```ahk
IfMsgBox Yes
```
