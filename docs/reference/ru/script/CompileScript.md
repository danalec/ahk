Русский

*KeySharp* · function · Разбор и выполнение скрипта

## Описание

Compiles a script to a string/bytes (ks).

## Синтаксис

```ahk
B := CompileScript(Path)
```

## Параметры

?.

## Возвращаемое значение

The compiled form.

## Пример

```ahk
CompileScript("a.ahk")
```
