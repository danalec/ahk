*KeySharp* · function · Разбор и выполнение скрипта

## Описание

Validates a script's syntax (ks).

## Синтаксис

```ahk
B := ValidateScript(Path)
```

## Параметры

?.

## Возвращаемое значение

1/0 or the errors.

## Пример

```ahk
ValidateScript("a.ahk")
```
