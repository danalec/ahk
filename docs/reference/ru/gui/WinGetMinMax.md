*AutoHotkey v2.0.31* · command · Окна интерфейса и автоматизация окон

## Описание

The min/max state of a window.

## Синтаксис

```ahk
N := WinGetMinMax(WinTitle)
```

## Параметры

0..4.

## Возвращаемое значение

-1/0/1.

## Пример

```ahk
WinGetMinMax("A")
```
