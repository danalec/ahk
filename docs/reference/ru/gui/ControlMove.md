*AutoHotkey v1.1.37.02* · command · Окна интерфейса и автоматизация окон

## Описание

Moves/resizes a control.

## Синтаксис

```ahk
ControlMove X, Y, W, H, Control, WinTitle
```

## Параметры

0..255.

## Возвращаемое значение

Nothing.

## Пример

```ahk
ControlMove 0, 0, 100, 20, "Edit1"
```
