*AutoHotkey v1.1.37.02* · command · Окна интерфейса и автоматизация окон

## Описание

Operates on a control (v1).

## Синтаксис

```ahk
GuiControl Cmd, ControlID, Value
```

## Параметры

2..255.

## Возвращаемое значение

Nothing.

## Пример

```ahk
GuiControl "", "Edit1", "x"
```
