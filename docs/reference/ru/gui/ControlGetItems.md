*AutoHotkey v2.0.31* · command · Окна интерфейса и автоматизация окон

## Описание

Reads the items of a list.

## Синтаксис

```ahk
A := ControlGetItems(Control, WinTitle)
```

## Параметры

1..5.

## Возвращаемое значение

The Array.

## Пример

```ahk
ControlGetItems("ListBox1")
```
