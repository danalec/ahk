## Описание

Reads the active window's title/pos.

## Синтаксис

```ahk
WinGetActiveStats &T, &X, &Y, &W, &H
```

## Параметры

5..255.

## Возвращаемое значение

Nothing.

## Пример

```ahk
WinGetActiveStats &t, &x, &y, &w, &h
```
