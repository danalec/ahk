*AutoHotkey v2.0.31* · command · Окна интерфейса и автоматизация окон

## Описание

Pastes text at the caret of an edit.

## Синтаксис

```ahk
EditPaste Text, Control, WinTitle
```

## Параметры

2..6.

## Возвращаемое значение

Nothing.

## Пример

```ahk
EditPaste "x", "Edit1"
```
