*AutoHotkey v2.0.31* · command · Окна интерфейса и автоматизация окон

## Описание

Reads the ClassNN of a control.

## Синтаксис

```ahk
S := ControlGetClassNN(Control, WinTitle)
```

## Параметры

1..5.

## Возвращаемое значение

The ClassNN.

## Пример

```ahk
ControlGetClassNN(h)
```
