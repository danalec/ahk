*AutoHotkey v2.0.31* · command · Окна интерфейса и автоматизация окон

## Описание

Reads the bounds of a monitor.

## Синтаксис

```ahk
MonitorGet N, &L, &T, &R, &B
```

## Параметры

0..5.

## Возвращаемое значение

Nothing.

## Пример

```ahk
MonitorGet(1, &l, &t, &r, &b)
```
