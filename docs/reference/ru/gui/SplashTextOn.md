Русский

*AutoHotkey v1.1.37.02* · command · Окна интерфейса и автоматизация окон

## Описание

Shows a splash text window (v1).

## Синтаксис

```ahk
SplashTextOn W, H, Title, Text
```

## Параметры

0..255.

## Возвращаемое значение

Nothing.

## Пример

```ahk
SplashTextOn 200, 100, "t", "x"
```
