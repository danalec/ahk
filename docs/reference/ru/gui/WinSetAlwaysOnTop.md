Русский

*AutoHotkey v2.0.31* · command · Окна интерфейса и автоматизация окон

## Описание

Sets a window always-on-top.

## Синтаксис

```ahk
WinSetAlwaysOnTop On|Off|Toggle, WinTitle
```

## Параметры

0..5.

## Возвращаемое значение

Nothing.

## Пример

```ahk
WinSetAlwaysOnTop 1, "A"
```
