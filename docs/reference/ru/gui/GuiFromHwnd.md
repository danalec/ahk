## Описание

The GUI object of a window handle.

## Синтаксис

```ahk
G := GuiFromHwnd(Hwnd)
```

## Параметры

1..2.

## Возвращаемое значение

The GUI.

## Пример

```ahk
GuiFromHwnd(h)
```
