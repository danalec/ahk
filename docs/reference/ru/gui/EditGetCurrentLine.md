## Описание

The current line of an edit.

## Синтаксис

```ahk
N := EditGetCurrentLine(Control, WinTitle)
```

## Параметры

1..5.

## Возвращаемое значение

The line.

## Пример

```ahk
EditGetCurrentLine("Edit1")
```
