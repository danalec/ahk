*AutoHotkey v2.0.31* · command · Окна интерфейса и автоматизация окон

## Описание

Sets the tray icon.

## Синтаксис

```ahk
TraySetIcon Filename, Number, Freeze
```

## Параметры

0..3.

## Возвращаемое значение

Nothing.

## Пример

```ahk
TraySetIcon "a.ico"
```
