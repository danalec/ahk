## Описание

Adds a Tab2 control to the GUI and answers it.

## Синтаксис

```ahk
C := Gui.AddTab2(Options, Text)
```

## Параметры

## Возвращаемое значение

## Пример

```ahk
g.AddTab2(, "x")
```
