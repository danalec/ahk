*AutoHotkey v2.0.31* · command · Окна интерфейса и автоматизация окон

## Описание

Adds an image to an image list.

## Синтаксис

```ahk
N := IL_Add(IL, Filename, Icon, Resize)
```

## Параметры

2..4.

## Возвращаемое значение

The index.

## Пример

```ahk
IL_Add(h, "a.ico")
```
