## Описание

The smallest of the numbers.

## Синтаксис

```ahk
Min
```

## Параметры

Number, [Number2], ...

## Возвращаемое значение

the smallest of them

## Ошибки

a value that is not a number is refused.

## Пример

```ahk
Min(3, 7, 5)
```
