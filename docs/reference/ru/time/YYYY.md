*AutoHotkey v2.0.31* · variable · Даты и время

## Описание

The four-digit year of a timestamp (FormatTime token / A_YYYY).

## Синтаксис

```ahk
YYYY
```

## Параметры

?.

## Возвращаемое значение

The year.

## Пример

```ahk
FormatTime(, "yyyy")
```
