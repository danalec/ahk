## Описание

The current local date/time as a YYYYMMDDHH24MISS timestamp.

## Синтаксис

```ahk
S := A_Now
```

## Параметры

?.

## Возвращаемое значение

The timestamp.

## Пример

```ahk
t := A_Now
```
