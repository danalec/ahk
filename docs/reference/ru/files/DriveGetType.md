## Описание

The type of a drive (Fixed/Removable/CDROM/...).

## Синтаксис

```ahk
S := DriveGetType(Path)
```

## Параметры

1.

## Возвращаемое значение

The type.

## Пример

```ahk
DriveGetType("C:\")
```
