*AutoHotkey v1.1.37.02* · command · Операции с файлами и каталогами

## Описание

Copies a directory (v1).

## Синтаксис

```ahk
FileCopyDir Source, Dest, Overwrite
```

## Параметры

2..255.

## Возвращаемое значение

Nothing.

## Пример

```ahk
FileCopyDir "a", "b", 1
```
