*AutoHotkey v1.1.37.02* · command · Операции с файлами и каталогами

## Описание

Sets the default file encoding (v1).

## Синтаксис

```ahk
FileEncoding Encoding
```

## Параметры

0..255.

## Возвращаемое значение

Nothing.

## Пример

```ahk
FileEncoding UTF-8
```
