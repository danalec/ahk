## Описание

Reads a 64-bit float number from the file at the current position.

## Синтаксис

```ahk
N := File.ReadDouble()
```

## Параметры

?.

## Возвращаемое значение

The number.

## Пример

```ahk
n := f.ReadDouble()
```
