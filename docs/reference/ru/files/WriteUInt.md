## Описание

Writes an unsigned 32-bit number to the file at the current position.

## Синтаксис

```ahk
File.WriteUInt(N)
```

## Параметры

?.

## Возвращаемое значение

The bytes written.

## Пример

```ahk
f.WriteUInt(1)
```
