## Описание

Creates a temporary file and answers its path.

## Синтаксис

```ahk
S := FileCreateTemp(Prefix)
```

## Параметры

?.

## Возвращаемое значение

The path.

## Пример

```ahk
t := FileCreateTemp()
```
