## Описание

Sets an object's buffer capacity (v1).

## Синтаксис

```ahk
ObjSetCapacity Obj, Bytes
```

## Параметры

2.

## Возвращаемое значение

Nothing.

## Пример

```ahk
ObjSetCapacity o, 16
```
