## Описание

The index of the first item matching a predicate (ks).

## Синтаксис

```ahk
N := Arr.FindIndex(Pred)
```

## Параметры

?.

## Возвращаемое значение

The index or 0.

## Пример

```ahk
a.FindIndex((x) => x = 2)
```
