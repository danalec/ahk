## Описание

Filters a collection by a predicate (ks).

## Синтаксис

```ahk
A := Arr.Filter(Pred)
```

## Параметры

?.

## Возвращаемое значение

The filtered Array.

## Пример

```ahk
a.Filter((x) => x > 1)
```
