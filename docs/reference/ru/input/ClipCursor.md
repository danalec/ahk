Русский

*KeySharp* · function · Горячие клавиши, горячие строки и ввод

## Описание

Confines the pointer to a rect (ks).

## Синтаксис

```ahk
ClipCursor(X1, Y1, X2, Y2)
```

## Параметры

?.

## Возвращаемое значение

Nothing; no rect frees.

## Пример

```ahk
ClipCursor(0, 0, 100, 100)
```
