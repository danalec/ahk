## Описание

Sets the NumLock state.

## Синтаксис

```ahk
SetNumLockState On|Off|AlwaysOn|AlwaysOff
```

## Параметры

0..1.

## Возвращаемое значение

Nothing.

## Пример

```ahk
SetNumLockState
```
