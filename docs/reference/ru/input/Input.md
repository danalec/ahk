*AutoHotkey v1.1.37.02* · command · Горячие клавиши, горячие строки и ввод

## Описание

Reads input from the keyboard (v1).

## Синтаксис

```ahk
Input OutputVar, Options, EndKeys, MatchList
```

## Параметры

0..255.

## Возвращаемое значение

Nothing; the var is filled.

## Пример

```ahk
Input v, L5
```
