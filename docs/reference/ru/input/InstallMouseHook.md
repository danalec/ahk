## Описание

Answers that the hook is there. The mouse is not watched at all: the box watches the keyboard, and the pointer is a device that writes and is never read.

## Синтаксис

```ahk
InstallMouseHook …
```

## Параметры

[OnOff] [HookName]

## Возвращаемое значение

nothing

## Ошибки

none; the command never fails.

## Пример

```ahk
InstallMouseHook
```
