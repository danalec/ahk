## Описание

Writes to the standard input of a ScriptProcess.

## Синтаксис

```ahk
Proc.StdIn(Text)
```

## Параметры

- **Text** — The text.

## Возвращаемое значение

Nothing.

## Пример

```ahk
p.StdIn("hi")
```
