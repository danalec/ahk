## Описание

Writes to the debugger log (OutputDebugString).

## Синтаксис

```ahk
OutputDebug Text
```

## Параметры

- **Text** — The text.

## Возвращаемое значение

Nothing.

## Пример

```ahk
OutputDebug "trace"
```
