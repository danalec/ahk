## Описание

Adds to a variable (v1).

## Синтаксис

```ahk
EnvAdd Var, Value
```

## Параметры

- **Var** — The variable.
- **Value** — The addend.

## Возвращаемое значение

Nothing.

## Пример

```ahk
EnvAdd x, 1
```
