Русский

*AutoHotkey v1.1.37.02* · command · Машина, процессы и окружение

## Описание

Shuts down / logs off / reboots the machine.

## Синтаксис

```ahk
Shutdown Code
```

## Параметры

- **Code** — The shutdown flags (1 logoff, 2 reboot, 8 power-down...).

## Возвращаемое значение

Nothing.

## Пример

```ahk
Shutdown 2
```
