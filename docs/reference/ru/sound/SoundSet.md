*AutoHotkey v1.1.37.02* · command · Звук

## Описание

Sets a sound component/control (v1 shape).

## Синтаксис

```ahk
SoundSet NewValue, Component, Control, Device
```

## Параметры

- **NewValue** — The value.
- **Component/Control/Device** — Selectors.

## Возвращаемое значение

Nothing.

## Пример

```ahk
SoundSet 50, , "Volume"
```
