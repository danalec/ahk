*AutoHotkey v1.1.37.02* · command · Звук

## Описание

Sets the wave volume (v1).

## Синтаксис

```ahk
SoundSetWaveVolume Volume, Device
```

## Параметры

- **Volume** — 0..100.
- **Device** — The device.

## Возвращаемое значение

Nothing.

## Пример

```ahk
SoundSetWaveVolume 50
```
