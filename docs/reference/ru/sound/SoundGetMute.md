## Описание

Reads whether a device is muted.

## Синтаксис

```ahk
B := SoundGetMute(Device)
```

## Параметры

- **Device** — The device.

## Возвращаемое значение

1/0.

## Пример

```ahk
m := SoundGetMute()
```
