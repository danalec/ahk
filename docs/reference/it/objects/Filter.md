## Descrizione

Filters a collection by a predicate (ks).

## Sintassi

```ahk
A := Arr.Filter(Pred)
```

## Parametri

?.

## Valore di ritorno

The filtered Array.

## Esempio

```ahk
a.Filter((x) => x > 1)
```
