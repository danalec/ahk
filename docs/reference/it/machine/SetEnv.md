## Descrizione

Sets a variable (v1).

## Sintassi

```ahk
SetEnv Var, Value
```

## Parametri

- **Var** — The variable.
- **Value** — The value.

## Valore di ritorno

Nothing.

## Esempio

```ahk
SetEnv x, 1
```
