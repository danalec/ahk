## Descrizione

Shuts down / logs off / reboots the machine.

## Sintassi

```ahk
Shutdown Code
```

## Parametri

- **Code** — The shutdown flags (1 logoff, 2 reboot, 8 power-down...).

## Valore di ritorno

Nothing.

## Esempio

```ahk
Shutdown 2
```
