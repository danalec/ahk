## Descrizione

Writes to the standard input of a ScriptProcess.

## Sintassi

```ahk
Proc.StdIn(Text)
```

## Parametri

- **Text** — The text.

## Valore di ritorno

Nothing.

## Esempio

```ahk
p.StdIn("hi")
```
