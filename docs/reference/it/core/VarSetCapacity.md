## Descrizione

Sets a variable's buffer capacity (v1).

## Sintassi

```ahk
VarSetCapacity Var, Bytes
```

## Parametri

1..3.

## Valore di ritorno

Nothing.

## Esempio

```ahk
VarSetCapacity v, 16
```
