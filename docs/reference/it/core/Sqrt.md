## Descrizione

The square root of a number.

## Sintassi

```ahk
N := Sqrt(Number)
```

## Parametri

- **Number** — Non-negative.

## Valore di ritorno

a float, even for a square

## Errori

a negative number is an invalid parameter.

## Esempio

```ahk
Sqrt(9)
```
