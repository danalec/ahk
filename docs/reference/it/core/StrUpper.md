## Descrizione

The text in the upper case.

## Sintassi

```ahk
S := StrUpper(String)
```

## Parametri

- **String** — The text.

## Valore di ritorno

the text, with the small letters turned into capital ones

## Errori

none.

## Esempio

```ahk
StrUpper("hello")
```
