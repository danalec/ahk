## Descrizione

Sets the default string case sense (v1).

## Sintassi

```ahk
StringCaseSense On|Off|Locale
```

## Parametri

1..255.

## Valore di ritorno

Nothing.

## Esempio

```ahk
StringCaseSense On
```
