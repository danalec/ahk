*AutoHotkey v2.0.31* · command · Tasti rapidi, stringhe di attivazione e input

## Descrizione

Answers that the hook is there. The mouse is not watched at all: the box watches the keyboard, and the pointer is a device that writes and is never read.

## Sintassi

```ahk
InstallMouseHook …
```

## Parametri

[OnOff] [HookName]

## Valore di ritorno

nothing

## Errori

none; the command never fails.

## Esempio

```ahk
InstallMouseHook
```
