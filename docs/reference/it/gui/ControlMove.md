## Descrizione

Moves/resizes a control.

## Sintassi

```ahk
ControlMove X, Y, W, H, Control, WinTitle
```

## Parametri

0..255.

## Valore di ritorno

Nothing.

## Esempio

```ahk
ControlMove 0, 0, 100, 20, "Edit1"
```
