## Descrizione

Reads a line of an edit.

## Sintassi

```ahk
S := EditGetLine(N, Control, WinTitle)
```

## Parametri

2..6.

## Valore di ritorno

The line.

## Esempio

```ahk
EditGetLine(1, "Edit1")
```
