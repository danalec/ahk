## Descrizione

Sets a window always-on-top.

## Sintassi

```ahk
WinSetAlwaysOnTop On|Off|Toggle, WinTitle
```

## Parametri

0..5.

## Valore di ritorno

Nothing.

## Esempio

```ahk
WinSetAlwaysOnTop 1, "A"
```
