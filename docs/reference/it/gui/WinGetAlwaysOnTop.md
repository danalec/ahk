## Descrizione

Whether a window is always-on-top.

## Sintassi

```ahk
B := WinGetAlwaysOnTop(WinTitle)
```

## Parametri

?.

## Valore di ritorno

1/0.

## Esempio

```ahk
WinGetAlwaysOnTop("A")
```
