## Descrizione

Compiles a script to a string/bytes (ks).

## Sintassi

```ahk
B := CompileScript(Path)
```

## Parametri

?.

## Valore di ritorno

The compiled form.

## Esempio

```ahk
CompileScript("a.ahk")
```
