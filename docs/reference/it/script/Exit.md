*KeySharp* · method · `Thread` · L'analizzatore e l'esecuzione dello script

## Descrizione

Stops the script. The code is kept, and the script stops at the end of the statement it was asked in.

## Sintassi

```ahk
Exit 
```

## Parametri

[Code]

## Valore di ritorno

the code

## Errori

none.

## Esempio

```ahk
Exit 0
```
