## Descrizione

Reads the name of a sound device.

## Sintassi

```ahk
S := SoundGetName(Device)
```

## Parametri

- **Device** — The device index.

## Valore di ritorno

The name.

## Esempio

```ahk
n := SoundGetName()
```
