## Descrizione

Sets the volume of a device (0..100).

## Sintassi

```ahk
SoundSetVolume Volume, Device
```

## Parametri

- **Volume** — 0..100.
- **Device** — The device.

## Valore di ritorno

Nothing.

## Esempio

```ahk
SoundSetVolume 50
```
