## Descrizione

Sets the wave volume (v1).

## Sintassi

```ahk
SoundSetWaveVolume Volume, Device
```

## Parametri

- **Volume** — 0..100.
- **Device** — The device.

## Valore di ritorno

Nothing.

## Esempio

```ahk
SoundSetWaveVolume 50
```
