## Descrizione

Reads whether a device is muted.

## Sintassi

```ahk
B := SoundGetMute(Device)
```

## Parametri

- **Device** — The device.

## Valore di ritorno

1/0.

## Esempio

```ahk
m := SoundGetMute()
```
