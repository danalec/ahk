## Descrizione

Removes a directory (v1).

## Sintassi

```ahk
FileRemoveDir Path, Recurse
```

## Parametri

1..255.

## Valore di ritorno

Nothing.

## Esempio

```ahk
FileRemoveDir "a", 1
```
