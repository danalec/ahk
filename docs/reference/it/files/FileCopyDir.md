*AutoHotkey v1.1.37.02* · command · Operazioni su file e directory

## Descrizione

Copies a directory (v1).

## Sintassi

```ahk
FileCopyDir Source, Dest, Overwrite
```

## Parametri

2..255.

## Valore di ritorno

Nothing.

## Esempio

```ahk
FileCopyDir "a", "b", 1
```
