*AutoHotkey v2.0.31* · command · Operazioni su file e directory

## Descrizione

Retracts a CD/drive. (Windows).

## Sintassi

```ahk
DriveRetract Drive, Value
```

## Parametri

0..1.

## Valore di ritorno

Nothing.

## Esempio

```ahk
DriveRetract "D:"
```
