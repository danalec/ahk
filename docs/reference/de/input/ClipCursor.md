*KeySharp* · function · Hotkeys, Hotstrings und Eingabe

## Beschreibung

Confines the pointer to a rect (ks).

## Syntax

```ahk
ClipCursor(X1, Y1, X2, Y2)
```

## Parameter

?.

## Rückgabewert

Nothing; no rect frees.

## Beispiel

```ahk
ClipCursor(0, 0, 100, 100)
```
