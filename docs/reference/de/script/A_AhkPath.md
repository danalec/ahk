## Beschreibung

The full path of the runner (the interpreter) of the script.

## Syntax

```ahk
N := A_AhkPath
```

## Parameter

?.

## Rückgabewert

The path; empty when not compiled and the host does not say.

## Beispiel

```ahk

```
