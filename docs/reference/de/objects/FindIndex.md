## Beschreibung

The index of the first item matching a predicate (ks).

## Syntax

```ahk
N := Arr.FindIndex(Pred)
```

## Parameter

?.

## Rückgabewert

The index or 0.

## Beispiel

```ahk
a.FindIndex((x) => x = 2)
```
