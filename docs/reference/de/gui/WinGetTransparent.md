*AutoHotkey v2.0.31* · command · GUI-Fenster und Fensterautomatisierung

## Beschreibung

The transparency of a window.

## Syntax

```ahk
N := WinGetTransparent(WinTitle)
```

## Parameter

0..4.

## Rückgabewert

0..255 or empty.

## Beispiel

```ahk
WinGetTransparent("A")
```

## Verwandt

[`WinActivate`](WinActivate.md), [`WinExist`](WinExist.md)
