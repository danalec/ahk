*AutoHotkey v2.0.31* · command · GUI-Fenster und Fensterautomatisierung

## Beschreibung

Pastes text at the caret of an edit.

## Syntax

```ahk
EditPaste Text, Control, WinTitle
```

## Parameter

2..6.

## Rückgabewert

Nothing.

## Beispiel

```ahk
EditPaste "x", "Edit1"
```

## Verwandt

[`Gui`](Gui.md), [`ControlGetText`](ControlGetText.md)
