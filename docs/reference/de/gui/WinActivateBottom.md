*AutoHotkey v1.1.37.02* · command · GUI-Fenster und Fensterautomatisierung

## Beschreibung

Activates the bottom-most matching window.

## Syntax

```ahk
WinActivateBottom WinTitle
```

## Parameter

0..255.

## Rückgabewert

Nothing.

## Beispiel

```ahk
WinActivateBottom "ahk_class X"
```

## Verwandt

[`WinActivate`](WinActivate.md), [`WinExist`](WinExist.md)
