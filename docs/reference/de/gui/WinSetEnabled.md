Deutsch

*AutoHotkey v2.0.31* · command · GUI-Fenster und Fensterautomatisierung

## Beschreibung

Enables/disables a window.

## Syntax

```ahk
WinSetEnabled B, WinTitle
```

## Parameter

1..5.

## Rückgabewert

Nothing.

## Beispiel

```ahk
WinSetEnabled 0, "A"
```

## Verwandt

[`WinActivate`](WinActivate.md), [`WinExist`](WinExist.md)
