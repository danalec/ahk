*AutoHotkey v1.1.37.02* · command · GUI-Fenster und Fensterautomatisierung

## Beschreibung

Clicks a control.

## Syntax

```ahk
ControlClick Control, WinTitle, Button, Count
```

## Parameter

0..255.

## Rückgabewert

Nothing.

## Beispiel

```ahk
ControlClick "Button1"
```
