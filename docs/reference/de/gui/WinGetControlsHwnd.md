## Beschreibung

The handles of a window's controls.

## Syntax

```ahk
A := WinGetControlsHwnd(WinTitle)
```

## Parameter

0..4.

## Rückgabewert

The Array.

## Beispiel

```ahk
WinGetControlsHwnd("A")
```
