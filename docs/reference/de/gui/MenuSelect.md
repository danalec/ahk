*AutoHotkey v2.0.31* · command · GUI-Fenster und Fensterautomatisierung

## Beschreibung

Selects a menu item (v1).

## Syntax

```ahk
MenuSelect WinTitle, Menu, Items...
```

## Parameter

0..11.

## Rückgabewert

Nothing.

## Beispiel

```ahk
MenuSelect "A", , "File"
```

## Verwandt

[`Menu`](Menu.md), [`Gui`](Gui.md), [`OnMessage`](OnMessage.md)
