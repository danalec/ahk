## Beschreibung

The number of lines of an edit.

## Syntax

```ahk
N := EditGetLineCount(Control, WinTitle)
```

## Parameter

1..5.

## Rückgabewert

The count.

## Beispiel

```ahk
EditGetLineCount("Edit1")
```

## Verwandt

[`Gui`](Gui.md), [`ControlGetText`](ControlGetText.md)
