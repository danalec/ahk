*AutoHotkey v1.1.37.02* · command · GUI-Fenster und Fensterautomatisierung

## Beschreibung

Activates the next window of a group.

## Syntax

```ahk
GroupActivate Group
```

## Parameter

1..255.

## Rückgabewert

Nothing.

## Beispiel

```ahk
GroupActivate "g"
```
