## Beschreibung

The current line of an edit.

## Syntax

```ahk
N := EditGetCurrentLine(Control, WinTitle)
```

## Parameter

1..5.

## Rückgabewert

The line.

## Beispiel

```ahk
EditGetCurrentLine("Edit1")
```

[`Gui`](Gui.md), [`ControlGetText`](ControlGetText.md)
