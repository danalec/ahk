## Beschreibung

Sets the volume of a device (0..100).

## Syntax

```ahk
SoundSetVolume Volume, Device
```

## Parameter

- **Volume** — 0..100.
- **Device** — The device.

## Rückgabewert

Nothing.

## Beispiel

```ahk
SoundSetVolume 50
```

[`SoundGetVolume`](SoundGetVolume.md), [`SoundSetMute`](SoundSetMute.md)
