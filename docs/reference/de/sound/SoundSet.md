## Beschreibung

Sets a sound component/control (v1 shape).

## Syntax

```ahk
SoundSet NewValue, Component, Control, Device
```

## Parameter

- **NewValue** — The value.
- **Component/Control/Device** — Selectors.

## Rückgabewert

Nothing.

## Beispiel

```ahk
SoundSet 50, , "Volume"
```

## Verwandt

[`SoundGet`](SoundGet.md), [`SoundSetVolume`](SoundSetVolume.md)
