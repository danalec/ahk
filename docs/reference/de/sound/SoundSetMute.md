## Beschreibung

Mutes/unmutes a device.

## Syntax

```ahk
SoundSetMute Mute, Device
```

## Parameter

- **Mute** — 1/0.
- **Device** — The device.

## Rückgabewert

Nothing.

## Beispiel

```ahk
SoundSetMute 1
```
