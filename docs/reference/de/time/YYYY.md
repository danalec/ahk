## Beschreibung

The four-digit year of a timestamp (FormatTime token / A_YYYY).

## Syntax

```ahk
YYYY
```

## Parameter

?.

## Rückgabewert

The year.

## Beispiel

```ahk
FormatTime(, "yyyy")
```
