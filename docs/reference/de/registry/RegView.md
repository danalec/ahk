*AutoHotkey v2.0.31* · variable · Die Registry-APIs

## Beschreibung

Sets the registry view (32/64-bit) for the thread.

## Syntax

```ahk
RegView View
```

## Parameter

- **View** — 32/64/Default.

## Rückgabewert

Nothing.

## Beispiel

```ahk
RegView 64
```

## Verwandt

[`SetRegView`](SetRegView.md), [`RegRead`](RegRead.md)
