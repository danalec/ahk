## Beschreibung

Adds to a variable (v1).

## Syntax

```ahk
EnvAdd Var, Value
```

## Parameter

- **Var** — The variable.
- **Value** — The addend.

## Rückgabewert

Nothing.

## Beispiel

```ahk
EnvAdd x, 1
```
