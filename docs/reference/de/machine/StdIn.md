## Beschreibung

Writes to the standard input of a ScriptProcess.

## Syntax

```ahk
Proc.StdIn(Text)
```

## Parameter

- **Text** — The text.

## Rückgabewert

Nothing.

## Beispiel

```ahk
p.StdIn("hi")
```
