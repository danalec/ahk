## Beschreibung

Writes to the debugger log (OutputDebugString).

## Syntax

```ahk
OutputDebug Text
```

## Parameter

- **Text** — The text.

## Rückgabewert

Nothing.

## Beispiel

```ahk
OutputDebug "trace"
```
