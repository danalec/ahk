## Beschreibung

Shuts down / logs off / reboots the machine.

## Syntax

```ahk
Shutdown Code
```

## Parameter

- **Code** — The shutdown flags (1 logoff, 2 reboot, 8 power-down...).

## Rückgabewert

Nothing.

## Beispiel

```ahk
Shutdown 2
```

## Verwandt

[`ExitApp`](ExitApp.md)
