## Beschreibung

Converts a value to a float.

## Syntax

```ahk
N := Float(Value)
```

## Parameter

- **Value** — A number or numeric text.

## Rückgabewert

The float.

## Beispiel

```ahk
Float("3.5")  ; 3.5
```
