## Beschreibung

The whole number below a number.

## Syntax

```ahk
N := Floor(Number)
```

## Parameter

- **Number** — The value.

## Rückgabewert

the whole number, a float when the number was not whole

## Fehler

a value that is not a number is refused.

## Beispiel

```ahk
Floor(1.8)
```
