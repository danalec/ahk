## Beschreibung

Trim left N chars (v1).

## Syntax

```ahk
StringTrimLeft Out, String, N
```

## Parameter

3..255.

## Rückgabewert

Nothing.

## Beispiel

```ahk
StringTrimLeft o, s, 2
```
