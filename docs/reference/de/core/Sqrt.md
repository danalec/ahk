## Beschreibung

The square root of a number.

## Syntax

```ahk
N := Sqrt(Number)
```

## Parameter

- **Number** — Non-negative.

## Rückgabewert

a float, even for a square

## Fehler

a negative number is an invalid parameter.

## Beispiel

```ahk
Sqrt(9)
```
