## Beschreibung

The largest of the numbers.

## Syntax

```ahk
N := Max(Numbers...)
```

## Parameter

- **Numbers** — One or more.

## Rückgabewert

the largest of them

## Fehler

a value that is not a number is refused.

## Beispiel

```ahk
Max(3, 7, 5)
```
