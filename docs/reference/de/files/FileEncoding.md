## Beschreibung

Sets the default file encoding (v1).

## Syntax

```ahk
FileEncoding Encoding
```

## Parameter

0..255.

## Rückgabewert

Nothing.

## Beispiel

```ahk
FileEncoding UTF-8
```

## Verwandt

[`FileRead`](FileRead.md), [`FileAppend`](FileAppend.md)
