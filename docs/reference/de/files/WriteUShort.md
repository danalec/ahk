## Beschreibung

Writes an unsigned 16-bit number to the file at the current position.

## Syntax

```ahk
File.WriteUShort(N)
```

## Parameter

?.

## Rückgabewert

The bytes written.

## Beispiel

```ahk
f.WriteUShort(1)
```
