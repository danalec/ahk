## Beschreibung

Removes a directory (v1).

## Syntax

```ahk
FileRemoveDir Path, Recurse
```

## Parameter

1..255.

## Rückgabewert

Nothing.

## Beispiel

```ahk
FileRemoveDir "a", 1
```
