*AutoHotkey v2.0.31* · command · Datei- und Verzeichnisoperationen

## Beschreibung

Shows a file-selection dialog.

## Syntax

```ahk
S := FileSelect(Options, RootDir, Prompt, Filter)
```

## Parameter

0..4.

## Rückgabewert

The path(s) or empty.

## Beispiel

```ahk
p := FileSelect()
```

[`DirSelect`](DirSelect.md), [`InputBox`](InputBox.md)
