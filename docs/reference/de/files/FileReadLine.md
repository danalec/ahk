## Beschreibung

Reads a line by number (v1).

## Syntax

```ahk
FileReadLine Out, Filename, LineNum
```

## Parameter

3..255.

## Rückgabewert

Nothing.

## Beispiel

```ahk
FileReadLine s, "a.txt", 2
```
