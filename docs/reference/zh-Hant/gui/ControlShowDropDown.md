*AutoHotkey v2.0.31* · command · GUI 視窗與視窗自動化

## 描述

Shows the drop-down of a combo.

## 語法

```ahk
ControlShowDropDown Control, WinTitle
```

## 參數

1..5.

## 傳回值

Nothing.

## 範例

```ahk
ControlShowDropDown "ComboBox1"
```
