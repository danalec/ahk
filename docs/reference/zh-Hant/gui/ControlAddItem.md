*AutoHotkey v2.0.31* · command · GUI 視窗與視窗自動化

## 描述

Adds an item to a list control.

## 語法

```ahk
ControlAddItem Text, Control, WinTitle
```

## 參數

2..6.

## 傳回值

The index.

## 範例

```ahk
ControlAddItem "x", "ListBox1"
```
