*AutoHotkey v2.0.31* · command · GUI 視窗與視窗自動化

## 描述

Enables/disables a window.

## 語法

```ahk
WinSetEnabled B, WinTitle
```

## 參數

1..5.

## 傳回值

Nothing.

## 範例

```ahk
WinSetEnabled 0, "A"
```
