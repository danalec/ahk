*AutoHotkey v1.1.37.02* · command · GUI 視窗與視窗自動化

## 描述

Sets a window property (v1).

## 語法

```ahk
WinSet Cmd, Value, WinTitle
```

## 參數

1..255.

## 傳回值

Nothing.

## 範例

```ahk
WinSet "Transparent", 128
```
