*AutoHotkey v1.1.37.02* · command · GUI 視窗與視窗自動化

## 描述

Activates the bottom-most matching window.

## 語法

```ahk
WinActivateBottom WinTitle
```

## 參數

0..255.

## 傳回值

Nothing.

## 範例

```ahk
WinActivateBottom "ahk_class X"
```
