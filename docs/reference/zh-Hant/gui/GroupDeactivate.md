*AutoHotkey v1.1.37.02* · command · GUI 視窗與視窗自動化

## 描述

Activates the next non-group window.

## 語法

```ahk
GroupDeactivate Group
```

## 參數

1..255.

## 傳回值

Nothing.

## 範例

```ahk
GroupDeactivate "g"
```
