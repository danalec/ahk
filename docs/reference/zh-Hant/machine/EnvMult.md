*AutoHotkey v1.1.37.02* · command · 機器、行程與環境

## 描述

Multiplies a variable (v1).

## 語法

```ahk
EnvMult Var, Value
```

## 參數

- **Var** — The variable.
- **Value** — The factor.

## 傳回值

Nothing.

## 範例

```ahk
EnvMult x, 2
```
