## 描述

Writes to the standard input of a ScriptProcess.

## 語法

```ahk
Proc.StdIn(Text)
```

## 參數

- **Text** — The text.

## 傳回值

Nothing.

## 範例

```ahk
p.StdIn("hi")
```
