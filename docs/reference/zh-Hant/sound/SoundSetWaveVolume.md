*AutoHotkey v1.1.37.02* · command · 聲音

## 描述

Sets the wave volume (v1).

## 語法

```ahk
SoundSetWaveVolume Volume, Device
```

## 參數

- **Volume** — 0..100.
- **Device** — The device.

## 傳回值

Nothing.

## 範例

```ahk
SoundSetWaveVolume 50
```
