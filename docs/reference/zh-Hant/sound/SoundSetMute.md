## 描述

Mutes/unmutes a device.

## 語法

```ahk
SoundSetMute Mute, Device
```

## 參數

- **Mute** — 1/0.
- **Device** — The device.

## 傳回值

Nothing.

## 範例

```ahk
SoundSetMute 1
```
