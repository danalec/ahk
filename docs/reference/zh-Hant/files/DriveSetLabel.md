*AutoHotkey v2.0.31* · command · 檔案與目錄操作

## 描述

Sets a drive's label. (Windows).

## 語法

```ahk
DriveSetLabel Drive, Value
```

## 參數

1..2.

## 傳回值

Nothing.

## 範例

```ahk
DriveSetLabel "D:"
```
