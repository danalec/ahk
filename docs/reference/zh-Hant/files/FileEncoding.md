*AutoHotkey v1.1.37.02* · command · 檔案與目錄操作

## 描述

Sets the default file encoding (v1).

## 語法

```ahk
FileEncoding Encoding
```

## 參數

0..255.

## 傳回值

Nothing.

## 範例

```ahk
FileEncoding UTF-8
```
