*AutoHotkey v2.0.31* · command · 檔案與目錄操作

## 描述

Shows a folder-selection dialog.

## 語法

```ahk
S := DirSelect(StartingFolder, Options, Prompt)
```

## 參數

0..3.

## 傳回值

The path or empty.

## 範例

```ahk
p := DirSelect()
```
