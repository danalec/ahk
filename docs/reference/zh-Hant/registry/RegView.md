繁體中文

*AutoHotkey v2.0.31* · variable · 登錄檔 API

## 描述

Sets the registry view (32/64-bit) for the thread.

## 語法

```ahk
RegView View
```

## 參數

- **View** — 32/64/Default.

## 傳回值

Nothing.

## 範例

```ahk
RegView 64
```
