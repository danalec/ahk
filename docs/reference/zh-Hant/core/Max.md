## 描述

The largest of the numbers.

## 語法

```ahk
N := Max(Numbers...)
```

## 參數

- **Numbers** — One or more.

## 傳回值

the largest of them

## 錯誤

a value that is not a number is refused.

## 範例

```ahk
Max(3, 7, 5)
```
