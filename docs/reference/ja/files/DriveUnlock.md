*AutoHotkey v2.0.31* · command · ファイルとディレクトリの操作

## 説明

Unlocks a drive. (Windows).

## 構文

```ahk
DriveUnlock Drive, Value
```

## パラメータ

1.

## 戻り値

Nothing.

## 例

```ahk
DriveUnlock "D:"
```
