日本語

*AutoHotkey v1.1.37.02* · command · GUIウィンドウとウィンドウの自動化

## 説明

Shows a splash text window (v1).

## 構文

```ahk
SplashTextOn W, H, Title, Text
```

## パラメータ

0..255.

## 戻り値

Nothing.

## 例

```ahk
SplashTextOn 200, 100, "t", "x"
```
