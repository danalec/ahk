*AutoHotkey v2.0.31* · command · GUIウィンドウとウィンドウの自動化

## 説明

The current column of an edit.

## 構文

```ahk
N := EditGetCurrentCol(Control, WinTitle)
```

## パラメータ

1..5.

## 戻り値

The column.

## 例

```ahk
EditGetCurrentCol("Edit1")
```
