*AutoHotkey v2.0.31* · command · GUIウィンドウとウィンドウの自動化

## 説明

The min/max state of a window.

## 構文

```ahk
N := WinGetMinMax(WinTitle)
```

## パラメータ

0..4.

## 戻り値

-1/0/1.

## 例

```ahk
WinGetMinMax("A")
```
