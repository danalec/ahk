*AutoHotkey v2.0.31* · command · GUIウィンドウとウィンドウの自動化

## 説明

Reads the bounds of a monitor.

## 構文

```ahk
MonitorGet N, &L, &T, &R, &B
```

## パラメータ

0..5.

## 戻り値

Nothing.

## 例

```ahk
MonitorGet(1, &l, &t, &r, &b)
```
