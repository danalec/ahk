*AutoHotkey v1.1.37.02* · command · GUIウィンドウとウィンドウの自動化

## 説明

Waits for a status bar text.

## 構文

```ahk
StatusBarWait Text, Timeout, Part, WinTitle
```

## パラメータ

0..255.

## 戻り値

Nothing.

## 例

```ahk
StatusBarWait "ready"
```
