## 説明

Reads input from the keyboard (v1).

## 構文

```ahk
Input OutputVar, Options, EndKeys, MatchList
```

## パラメータ

0..255.

## 戻り値

Nothing; the var is filled.

## 例

```ahk
Input v, L5
```
