*AutoHotkey v2.0.31* · command · ホットキー、ホット文字列、入力

## 説明

Makes hotkeys context-sensitive by a function/expression.

## 構文

```ahk
HotIf Criteria
```

## パラメータ

0..1.

## 戻り値

Nothing (a directive-like function).

## 例

```ahk
HotIf "ahk_class X"
```
