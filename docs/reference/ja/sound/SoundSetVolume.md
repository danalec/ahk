*AutoHotkey v2.0.31* · function · サウンド

## 説明

Sets the volume of a device (0..100).

## 構文

```ahk
SoundSetVolume Volume, Device
```

## パラメータ

- **Volume** — 0..100.
- **Device** — The device.

## 戻り値

Nothing.

## 例

```ahk
SoundSetVolume 50
```
