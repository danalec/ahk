*AutoHotkey v2.0.31* · function · サウンド

## 説明

Mutes/unmutes a device.

## 構文

```ahk
SoundSetMute Mute, Device
```

## パラメータ

- **Mute** — 1/0.
- **Device** — The device.

## 戻り値

Nothing.

## 例

```ahk
SoundSetMute 1
```
