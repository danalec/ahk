日本語

*AutoHotkey v2.0.31* · variable · レジストリの API

## 説明

Sets the registry view (32/64-bit) for the thread.

## 構文

```ahk
RegView View
```

## パラメータ

- **View** — 32/64/Default.

## 戻り値

Nothing.

## 例

```ahk
RegView 64
```
