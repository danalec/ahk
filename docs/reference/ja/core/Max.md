## 説明

The largest of the numbers.

## 構文

```ahk
N := Max(Numbers...)
```

## パラメータ

- **Numbers** — One or more.

## 戻り値

the largest of them

## エラー

a value that is not a number is refused.

## 例

```ahk
Max(3, 7, 5)
```
