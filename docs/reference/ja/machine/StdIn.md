## 説明

Writes to the standard input of a ScriptProcess.

## 構文

```ahk
Proc.StdIn(Text)
```

## パラメータ

- **Text** — The text.

## 戻り値

Nothing.

## 例

```ahk
p.StdIn("hi")
```
