Sprache: Deutsch

Derselbe Name in den drei Dialekten und der Name, den nur einer von ihnen hat. Ein Name des v1, den der v2 anders schreibt, steht in der Tabelle „nur v1“, mit dem v2-Namen, der ihn ersetzt hat.

| Die drei | Namen |
|---|---|
| v1 and v2 | 181 |
| v1 only | 226 |
| KeySharp only | 130 |
