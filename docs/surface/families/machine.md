## What the tree does with it

### A_AppData

The folder of the data of the user. On a Linux box it is `$XDG_DATA_HOME`, and `$HOME/.local/share` when the variable is not there.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the path of the folder, as a text
- **Errors:** the read fails with "the machine has no such folder." when the machine has no such folder; the write is refused.

```ahk
FileAppend A_AppData, "*"
```

### A_ComputerName

The name of the computer, as the network sees it: the kernel, and the `HOSTNAME` of the environment when the kernel has no name.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the name, as a text
- **Errors:** the read fails when neither the kernel nor the session carries the name; the write is refused.

```ahk
FileAppend A_ComputerName, "*"
```

### A_Desktop

The folder of the desktop of the user: the folder the machine knows, and `$HOME/Desktop` when it knows none.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the path of the folder, as a text
- **Errors:** the read fails with "the machine has no such folder." when the machine has no such folder; the write is refused.

```ahk
FileAppend A_Desktop, "*"
```

### A_MM

The month of the local time of the machine, in two digits.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the month, as a text of two digits
- **Errors:** the read fails when the clock of the runtime does not know the date of the machine; the write is refused.

```ahk
FileAppend A_MM, "*"
```

### A_Temp

The folder of the temporary files of the machine: `TMPDIR`, and `/tmp` when the variable is not there.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the path of the folder, as a text
- **Errors:** the read fails with "the machine has no such folder." when the machine has no such folder; the write is refused.

```ahk
FileAppend A_Temp, "*"
```

### A_TickCount

The number of milliseconds the runtime has counted since an arbitrary origin. The count never goes backwards.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the number of milliseconds, as a number
- **Errors:** the write is refused; the name is a built-in variable that the dialect does not let a script write.

```ahk
FileAppend A_TickCount, "*"
```

### A_UserName

The name of the user of the session: the `USER` of the environment.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the name, as a text
- **Errors:** the read fails when the session carries no such name: "the session does not carry the name of the user: the environment has no USER."; the write is refused.

```ahk
FileAppend A_UserName, "*"
```

### ProcessClose

Closes a process; the box sends SIGTERM, the polite signal that asks the process to end.

- **Parameters:** ProcessNameOrPID
- **Answers:** the pid of the process that was closed, 0 when it was not there or could not be closed
- **Errors:** a process of another user is a process the script cannot open, and the answer is zero and not a failure.

```ahk
ProcessClose "firefox"
```

### ProcessExist

Answers whether a process is there, and with which pid; the processes of the machine are read out of /proc.

- **Parameters:** [ProcessNameOrPID]
- **Answers:** the pid of the process, or 0 when there is none
- **Errors:** a machine without /proc answers "the processes of this machine are read out of /proc, and this machine has none"; a process that is not there is zero and not a failure.

```ahk
if ProcessExist("firefox")
```

### ProcessGetName

Answers the name of the executable of a process; the name is the file name of /proc/<pid>/exe, and the name the kernel gives is the fallback.

- **Parameters:** [ProcessNameOrPID]
- **Answers:** the name of the executable, as text
- **Errors:** "Target process not found." when the process is not there; a machine without /proc answers "the processes of this machine are read out of /proc, and this machine has none".

```ahk
name := ProcessGetName(1234)
```

### ProcessGetPath

Answers the whole path of the executable of a process; the path is the target of the link /proc/<pid>/exe, and the " (deleted)" the kernel adds is cut.

- **Parameters:** [ProcessNameOrPID]
- **Answers:** the path of the executable, as text
- **Errors:** "Target process not found." when the process is not there; a machine without /proc answers "the processes of this machine are read out of /proc, and this machine has none".

```ahk
path := ProcessGetPath(1234)
```

### ProcessWait

Waits for a process to be there; the box checks every hundred milliseconds, the way the binary of v2 does.

- **Parameters:** ProcessNameOrPID, [Timeout]
- **Answers:** the pid of the process when it appears, 0 at the timeout
- **Errors:** a call without a timeout waits for ever; a machine without /proc answers "the processes of this machine are read out of /proc, and this machine has none".

```ahk
ProcessWait "firefox", 10
```

### ProcessWaitClose

Waits for a process that is there to close; a process that never existed is gone, and the wait is over at once.

- **Parameters:** ProcessNameOrPID, [Timeout]
- **Answers:** 0 when the process is gone, the pid of the process that is still there at the timeout
- **Errors:** a call without a timeout waits for ever; a machine without /proc answers "the processes of this machine are read out of /proc, and this machine has none".

```ahk
ProcessWaitClose "firefox", 10
```

### Run

Runs a command and waits for it. What the command wrote on its output goes into the output of the report.

- **Parameters:** Command, [WorkingDir]
- **Answers:** the exit code of the command
- **Errors:** more than two parameters are refused with "the options of the window and the pid of the process are not carried yet."

```ahk
Run "ls"
```

### RunWait

Runs a command and waits for it, the same way Run does. The name is the function form of the same handler.

- **Parameters:** Command, [WorkingDir]
- **Answers:** the exit code of the command
- **Errors:** more than two parameters are refused with "the options of the window and the pid of the process are not carried yet."

```ahk
RunWait "ls"
```

### SysGet

Answers a metric of the system; the numbers are the ones of GetSystemMetrics, and only the ones about the screen are carried.

- **Parameters:** Metric
- **Answers:** the metric as an integer
- **Errors:** a metric of the window manager of Windows is refused with "SysGet(n) is a metric of the window manager of Windows, and this desktop does not have one."; a compositor that published no monitor answers "the compositor published no monitor, so the metric n of SysGet is not known."; a number that is not a metric at all is zero.

```ahk
w := SysGet(0)
```
