## What the tree does with it

### Array

The class of a row of values. `Array(...)` makes one with the values it is given, and the literal `[1, 2, 3]` makes one too.

- **Parameters:** the values of the array, any number of them
- **Answers:** the object of the class `Array`
- **Errors:** nothing to make the array; the places count from one, and an index that is not there is refused with "Invalid index.".

```ahk
a := Array(1, 2, 3)
FileAppend a.Length, "*"
```

### Map.Delete

Takes a key out of the map and answers the value that was under it.

- **Parameters:** the key
- **Answers:** the value that was under the key
- **Errors:** a key that is not there is refused with "Item has no value.", and the key is named in the `Extra` of the failure.

```ahk
m := Map("x", 1)
FileAppend m.Delete("x"), "*"
```

### Enumerator

The class of the walker of a loop: an enumerator hands out the pieces of a sequence, one turn at a time. The class is not made; the `__Enum` of a value makes one, and the call of it is the turn of the enumeration.

- **Parameters:** nothing that makes it
- **Answers:** the class of an enumerator, as a text
- **Errors:** the call of the class is refused with "Invalid base.".

```ahk
for item in [1, 2]
    FileAppend Type(item), "*"
```

### Func

The class of a function: a function of the script, a method, a lambda or a built-in. The class is not made: `Func(...)` answers "Invalid base."; the class of a function value is `Func`.

- **Parameters:** nothing that makes it
- **Answers:** the class of a function value, as a text
- **Errors:** the call of the class is refused with "Invalid base.".

```ahk
FileAppend Abs.__Class, "*"
```

### Func

The class of a function: a function of the script, a method, a lambda or a built-in. The class is not made: `Func(...)` answers "Invalid base."; the class of a function value is `Func`.

- **Parameters:** nothing that makes it
- **Answers:** the class of a function value, as a text
- **Errors:** the call of the class is refused with "Invalid base.".

```ahk
FileAppend Abs.__Class, "*"
```

### Map.Get

The value that is under a key of the map.

- **Parameters:** the key, and the value to answer when the key is not there
- **Answers:** the value under the key
- **Errors:** a key that is not there is refused with "Item has no value.", and the key is named in the `Extra` of the failure; the second argument is the default of the call, and the `Default` of the map is the last word.

```ahk
m := Map("x", 1)
FileAppend m.Get("x"), "*"
```

### Map.Has

Whether the map has a key.

- **Parameters:** the key
- **Answers:** 1 when the key is there, 0 when it is not
- **Errors:** nothing; a key that is not there is not a failure, the question is answered.

```ahk
m := Map("x", 1)
FileAppend m.Has("x"), "*"
```

### Array.Length

The number of places of the array. It is a property and not a method: `a.Length`, and not `a.Length()`.

- **Parameters:** nothing; it is a property, not a call
- **Answers:** the number of the places, as a number
- **Errors:** the write of a negative number is refused with "Invalid value."; a longer array gets places that have no value of their own, and a shorter one loses the places at the end.

```ahk
a := [1, 2, 3]
FileAppend a.Length, "*"
```

### Map

The class of a table of keys and values. `Map(key, value, ...)` makes one, and the order of the entries is the order they were put in.

- **Parameters:** the pairs of key and value, an even number of them
- **Answers:** the object of the class `Map`
- **Errors:** an odd number of arguments is refused with "Invalid number of parameters."; a key that is not there is refused with "Item has no value.".

```ahk
m := Map("x", 1)
FileAppend m.Count, "*"
```

### Object

The root of the chain of the classes: every object of the runtime is one. `Object()` makes an object with nothing in it, and the literal `{a: 1}` makes one with a property.

- **Parameters:** nothing
- **Answers:** the object of the class `Object`
- **Errors:** nothing; a member that is not there is refused with the type of the value and the name of the member.

```ahk
o := Object()
FileAppend o.__Class, "*"
```

### ObjGetBase

The base of an object: the prototype of its class.

- **Parameters:** the object
- **Answers:** the object of the base
- **Errors:** a value that is not an object is refused with "Expected an object but got ...".

```ahk
FileAppend ObjGetBase({a: 1}).__Class, "*"
```

### Array.Pop

Takes the last value off the array and answers it.

- **Parameters:** nothing
- **Answers:** the value that was at the end, as a text when the place had no value of its own
- **Errors:** an empty array is refused with "Array is empty.".

```ahk
a := [1, 2]
FileAppend a.Pop(), "*"
```

### Array.Push

Puts the values at the end of the array and answers the array, so that the calls can be chained.

- **Parameters:** the values, any number of them
- **Answers:** the array itself
- **Errors:** nothing; the push of no value changes nothing and still answers the array.

```ahk
a := [1]
a.Push(2, 3)
FileAppend a.Length, "*"
```

### Map.Set

Puts the pairs of key and value into the map and answers the map, so that the calls can be chained.

- **Parameters:** the pairs of key and value, an even number of them
- **Answers:** the map itself
- **Errors:** an odd number of arguments is refused with "Invalid number of parameters.".

```ahk
m := Map()
m.Set("x", 1)
FileAppend m.Count, "*"
```
