## What the tree does with it

### A_Cursor

The shape of the cursor of the pointer. The shape belongs to the machine, and this runtime does not read it.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** nothing: the name refuses
- **Errors:** the read refuses with "the shape of the cursor of the machine is not read by this runtime."

```ahk
FileAppend A_Cursor, "*"
```

### A_KeyDelay

The delay between the keystrokes of a `Send`, in milliseconds. It is a setting of the run, and it is ten by default.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the delay, as a number
- **Errors:** the write takes the number of the value, and a text that holds no number is zero.

```ahk
FileAppend A_KeyDelay, "*"
```

### A_SendMode

The method that a `Send` uses: `Input`, `Event`, `Play` or `InputThenPlay`.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the name of the mode, as a text
- **Errors:** the write takes the name of one of the four modes, and any other name is refused with "Invalid value.".

```ahk
FileAppend A_SendMode, "*"
```

### A_ThisHotkey

The name of the hotkey that runs. The hotkeys are the ones of the hotkey system of the runtime, and the name is the empty text when no hotkey runs.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the name of the hotkey, as a text; the empty text when no hotkey runs
- **Errors:** nothing to read; the write is refused.

```ahk
FileAppend A_ThisHotkey, "*"
```

### BlockInput

Turns the input of the whole machine off, and that is all it can do. Turning input off for the whole machine is a privilege this compositor does not give a client, and this tree will not claim it did.

- **Parameters:** Mode
- **Answers:** nothing for 'Off'
- **Errors:** any other mode fails with 'blocking the input of the whole machine is a privilege this compositor does not give a client'.

```ahk
BlockInput "Off"
```

### Click

Clicks with the pointer of the backend, which is an absolute uinput device: it moves to the place, settles, presses and releases.

- **Parameters:** [X, Y] [Button] [Count]
- **Answers:** nothing
- **Errors:** the wheel, the fourth and the fifth buttons, the pressing of a button and the place relative to the pointer are refused as not carried yet; on a host without `grim` the click fails with the reason of the screen, because the pointer needs the size of the screen.

```ahk
Click 100, 200
```

### GetKeyName

The name of the key, the way v2 gives it. The names are the ones of the key list of v2: `Esc`, `Enter`, `CtrlRight`, `Numpad0`, and the `vkXX` and `scXXX` spellings.

- **Parameters:** KeyName
- **Answers:** the name of the key
- **Errors:** a name the tree does not know is the empty text, the way v2 answers a name it does not know.

```ahk
name := GetKeyName("Enter")
```

### GetKeySC

The code of the Linux input event of the key. It is the code the box writes to its own device, and not the scan code of the PC keyboard: the two numberings part company on the extended keys.

- **Parameters:** KeyName
- **Answers:** the input event code, a number
- **Errors:** a name the tree does not know is the empty text, the way v2 answers a name it does not know.

```ahk
sc := GetKeySC("Enter")
```

### GetKeyState

Reads what the hotkey watcher saw: whether a key is down. The second parameter carries only the words 'T' and 'P' of v2.

- **Parameters:** KeyName [, Mode]
- **Answers:** one when the key is down, zero when it is not
- **Errors:** a key name the tree does not know, and a mode that is neither 'T' nor 'P', are refused as invalid parameters; on a host that is not Linux the watcher cannot answer at all.

```ahk
state := GetKeyState("Shift")
```

### Hotkey

Registers a hotkey: the key it watches for and the function it runs. The runtime owns the registry and the machine owns the watcher: the script says which function a hotkey runs, and the machine says which key was pressed.

- **Parameters:** KeyName, Action [, Options]
- **Answers:** nothing
- **Errors:** a hotkey without an action is 'Nonexistent hotkey.'; the watcher reads the physical keyboard of the machine, so on a host that is not Linux the registration fails with 'the hotkeys of this box watch a Linux device; this is not Linux'.

```ahk
Hotkey "^s", SaveTheFile
```
