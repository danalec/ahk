## What the tree does with it

### A_Index

The number of the turn of the loop that runs. It is zero before the first loop, and every loop saves the value it had and gives it back when it ends.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the number of the turn, as a number
- **Errors:** nothing to read; a script may write the name, and the loop goes on from the value that was written.

```ahk
for item in [1, 2, 3]
    FileAppend A_Index, "*"
```

### A_Is64bitOS

Whether the machine is a 64-bit one. The tree answers with the width of its own pointer: 1 on a 64-bit build of the runtime, 0 on a 32-bit one.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** 1 or 0
- **Errors:** nothing to read; the write is refused.

```ahk
FileAppend A_Is64bitOS, "*"
```

### A_IsAdmin

Whether the script runs with the rights of an administrator: the effective user id, and the root is the one that is zero.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** 1 when the script is elevated, 0 when it is not
- **Errors:** the read fails when the machine cannot say; the write is refused.

```ahk
FileAppend A_IsAdmin, "*"
```

### A_OSVersion

The version of the operating system of the machine: the release of the kernel, read from `/proc/sys/kernel/osrelease`.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the version, as a text
- **Errors:** the read fails when the release of the kernel cannot be read; the write is refused.

```ahk
FileAppend A_OSVersion, "*"
```

### A_ScriptDir

The directory where the run started. The script of the runner arrives on the standard input and has no file of its own, so the directory of the script is the directory of the run.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the path of the directory, as a text
- **Errors:** the read fails when the runtime does not keep the directory where the run started; the write is refused.

```ahk
FileAppend A_ScriptDir, "*"
```

### A_ScriptFullPath

The path of the script. The script of the runner comes on the standard input and has no file, so the path is an asterisk.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the text "*"
- **Errors:** the write is refused.

```ahk
FileAppend A_ScriptFullPath, "*"
```

### A_ScriptName

The name of the script. The script of the runner comes on the standard input and has no file, so the name is an asterisk. A script may write the name, and the value written is the one it keeps.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the text "*", or the text that was written
- **Errors:** nothing to read; the write takes any value.

```ahk
FileAppend A_ScriptName, "*"
```

### A_ThisFunc

The name of the function that runs.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the name, as a text; the empty text when no function runs
- **Errors:** nothing to read; the write is refused.

```ahk
FileAppend A_ThisFunc, "*"
```

### CoordMode

The way the coordinates are read. The five targets of v2 are the mouse, the pixels, the caret, the menu and the tooltip; the tree has no windows, so the modes of the caret, the menu and the tooltip are kept all the same and nothing uses them.

- **Parameters:** Target [, Relative]
- **Answers:** the mode that was there before
- **Errors:** a target or a relative that v2 does not know is refused as an invalid parameter.

```ahk
CoordMode "Mouse", "Screen"
```

### Else

The other side of an if. Else if chains the conditions, and the first one that matches runs.

- **Parameters:** a statement or a block
- **Answers:** nothing
- **Errors:** none.

```ahk
if (0)
    MsgBox "no"
else
    MsgBox "yes"
```

### EnvGet

Answers the value of an environment variable of the runner; the environment is the one of the process the script runs in.

- **Parameters:** VariableName
- **Answers:** the value of the variable, or the empty text when the environment does not have it
- **Errors:** nothing; a name that is not there is the empty text and not a failure.

```ahk
home := EnvGet("HOME")
```

### EnvSet

Sets an environment variable of the runner and answers the value; the script runs on one thread, so nothing else reads the environment while the change happens.

- **Parameters:** VariableName, Value
- **Answers:** the value that was set, as text
- **Errors:** an empty name and a name that carries an equal sign are refused with the reason of the machine.

```ahk
EnvSet "MY_VAR", "value"
```

### IsSet

Whether the variable of the caller has a value. The tree carries it besides `IsSetRef`, and it asks for the variable and not for its value.

- **Parameters:** the variable, not its value
- **Answers:** 1 when the variable has a value, 0 when it has none
- **Errors:** an argument that is not a variable is refused with "IsSet requires a variable.".

```ahk
x := 1
FileAppend IsSet(x), "*"
```

### OnError

Registers the function that handles a failure the script did not catch.

- **Parameters:** Callback, [Order]
- **Answers:** the integer 1
- **Errors:** a callback that is not a function object, or a prototype that does not take two parameters, is refused with "Invalid callback function.".

```ahk
OnError((err, mode) => 0)
```

### OnExit

Registers the function that runs when the script ends, whatever ended it: the last statement, a code the script asked to stop with, or a failure that stopped it.

- **Parameters:** Callback, [Order]
- **Answers:** the integer 1
- **Errors:** a callback that is not a function object, or a prototype that does not take two parameters, is refused with "Invalid callback function.".

```ahk
OnExit((reason, code) => 0)
```

### Pause

- **Parameters:** [OnOff]
- **Answers:** the empty text
- **Errors:** a parameter that is not 0, 1 or -1 is an invalid parameter.

```ahk
Pause true
```

### Persistent

Answers 0 and changes nothing. A script of this runtime runs from its first line to its last and has no message loop to stay alive for, so the setting has no meaning here.

- **Parameters:** [OnOff]
- **Answers:** the integer 0
- **Errors:** none.

```ahk
Persistent
```

### SetTimer

Registers a function of the script that runs between the statements. The runtime is one thread, so the timer is not a thread of its own: it runs between the statements and shares the budget of the script.

- **Parameters:** Name, [Period]
- **Answers:** the integer 1
- **Errors:** more than two parameters are refused with "the priority of the timer is not carried yet."

```ahk
SetTimer("Tick", 1000)
```

- **Parameters:** Name, [Period]

- **Errors:** more than two parameters are refused with "the priority of the timer is not carried yet."

```ahk
SetTimer("Tick", 1000)
```

### SetWorkingDir

Sets the working directory of the script. A name that is not absolute is a folder under the working directory, the way the dialect says it.

- **Parameters:** Directory
- **Answers:** the integer 1
- **Errors:** an empty name is refused with "the name of the directory is missing.", and a folder that cannot be entered fails with the reason of the desktop.

```ahk
SetWorkingDir "."
```

### Sleep

Pauses the script for a number of milliseconds.

- **Parameters:** Milliseconds
- **Answers:** the number of milliseconds waited
- **Errors:** none; a wait longer than 60000 milliseconds is cut at that number.

```ahk
Sleep 500
```

### Suspend

Turns the hotkeys of the script off or on. With no parameter it turns them the other way. The state is visible in A_IsSuspended and in the enabled flag of the hotkey table.

- **Parameters:** [OnOff]
- **Answers:** the empty text
- **Errors:** a parameter that is not 0, 1 or -1 is an invalid parameter.

```ahk
Suspend true
```
