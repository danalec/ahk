### Format

A pattern with the values in it. The pattern is the one of the reference dialect: {1} is the first argument, a placeholder with no number takes the next one, and {{ and }} are one brace of their own.

- **Parameters:** Pattern, [Value1], [Value2], ...
- **Answers:** the text of the pattern with the values in it
- **Errors:** a placeholder that names an argument that is not there, or whose spec is not one the dialect reads, is left exactly as it was written; a value of a kind the spec does not want is refused.

```ahk
Format("{1} + {2} = {3}", 1, 2, 3)
```

### GetMethod

The method of an object, as a value that can be called.

- **Parameters:** the object, the name of the method, and the number of parameters it would take
- **Answers:** the method, as a value of the class `Func`
- **Errors:** a method that is not there is refused with the type of the value and the name of the member.

```ahk
o := {a: 1}
FileAppend GetMethod(o, "HasOwnProp").__Class, "*"
```

### HasBase

Whether the base of an object is another object.

- **Parameters:** the object, and the base
- **Answers:** 1 when the base is that one, 0 when it is not
- **Errors:** a base that is not an object is refused before the question of the object is asked.

```ahk
FileAppend HasBase({a: 1}, {}), "*"
```

### HasMethod

Whether an object has a method.

- **Parameters:** the object, the name of the method, and the number of parameters it would take
- **Answers:** 1 when the object has such a method, 0 when it has not
- **Errors:** nothing; a value that is not an object answers zero, and the question with no name asks whether the value is a class.

```ahk
o := {a: 1}
FileAppend HasMethod(o, "a"), "*"
```

### HasProp

Whether an object has a property.

- **Parameters:** the object, and the name of the property
- **Answers:** 1 when the object has such a property, 0 when it has not
- **Errors:** nothing; a value that is not an object has the property `__Class` and no other, so the answer for it is one only for that name.

```ahk
o := {a: 1}
FileAppend HasProp(o, "a"), "*"
```

### InStr

Where a text is in another text. The position counts from one and is zero when the needle is not there at all.

- **Parameters:** Haystack, Needle, [CaseSense], [Start], [Occurrence]
- **Answers:** the position of the match, or 0 when there is none
- **Errors:** a needle that is empty is an invalid parameter; the logical case sense is an invalid parameter; a start or an occurrence of zero is an invalid parameter.

```ahk
InStr("hello", "ll")
```

### IsNumber

