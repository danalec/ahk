## What the tree does with it

### ControlGetExStyle

The extended style of a control of a window: the `WS_EX_*` bits of Windows, the way the extended style of a window is.

- **Parameters:** Control, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **Answers:** the extended style, as a number
- **Errors:** a window that is not there refuses with 'Target window not found.', and a control that is not there with 'Target control not found.'; the text of the window and the two exclusions are not carried yet.

```ahk
FileAppend ControlGetExStyle("Edit1", "ZZZ_NO_WINDOW_ZZZ"), "*"
```

### ControlGetStyle

The style of a control of a window: the number of the bits of Windows, the way the style of a window is. A control is a window of its own, and it is found by its name, its number or its class.

- **Parameters:** Control, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **Answers:** the style, as a number
- **Errors:** a window that is not there refuses with 'Target window not found.', and a control that is not there with 'Target control not found.'; the text of the window and the two exclusions are not carried yet.

```ahk
FileAppend ControlGetStyle("Edit1", "ZZZ_NO_WINDOW_ZZZ"), "*"
```

### ControlSetExStyle

Writes the extended style of a control of a window. The style is absolute, the way the extended style of a window is: the text may carry a `+`, a `-` or a `^` before the number, and the runtime computes the new extended style out of the one that is there.

- **Parameters:** Style, Control, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **Answers:** the empty text
- **Errors:** an empty text refuses with 'Parameter #1 of ControlSetExStyle is invalid.'; a window that is not there refuses with 'Target window not found.', and a control that is not there with 'Target control not found.'.

```ahk
ControlSetExStyle("+0x8", "Edit1", "ZZZ_NO_WINDOW_ZZZ")
```

### ControlSetStyle

Writes the style of a control of a window. The style is absolute, the way the style of a window is: the text may carry a `+`, a `-` or a `^` before the number, and the runtime computes the new style out of the one that is there.

- **Parameters:** Style, Control, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **Answers:** the empty text
- **Errors:** an empty text refuses with 'Parameter #1 of ControlSetStyle is invalid.'; a window that is not there refuses with 'Target window not found.', and a control that is not there with 'Target control not found.'.

```ahk
ControlSetStyle("+0x10", "Edit1", "ZZZ_NO_WINDOW_ZZZ")
```

### Edit

Opens the file of the script in the program that the machine opens a file of that kind with -- the editor of a script.

- **Parameters:** none
- **Answers:** the empty text
- **Errors:** the call fails when the script has no file: a script that comes from the standard input has none, and the reason is "the script of this runtime is read from the standard input, so it has no file for an editor to open".

```ahk
Edit()
```

### InputBox

Asks the user for a text in a dialog of the desktop and answers an object with the text in its Value and the way the dialog was closed in its Result.

- **Parameters:** Prompt, [Title], [Options], [Default]
- **Answers:** an object with the properties Value and Result, where Result is "OK", "Cancel" or "Timeout"
- **Errors:** an option the dialect does not know is refused with "Invalid option.".

```ahk
answer := InputBox("your name?", "hello")
MsgBox answer.Value
```

### MsgBox

Shows a message. The tree has no window of its own, so the text goes into the output of the report instead of onto the screen, and the call answers the same text.

- **Parameters:** Message, [Title], [Options]
- **Answers:** the text of the message
- **Errors:** more than one parameter is refused with "the options, the title and the variable that takes the answer are not carried yet."

```ahk
MsgBox "hello"
```

### ScriptHwnd

The handle of the hidden window of the script, the name the v2 gives it. The window is the one that owns the messages of the session, and the number changes with the run.

- **Parameters:** nothing; it is a variable, not a call
- **Answers:** the handle of the window, as a number
- **Errors:** the read fails with the reason of the desktop when the desktop has no window of the script; the write is refused.

```ahk
FileAppend A_ScriptHwnd, "*"
```

### ToolTip

Shows a small window of text at a place of the screen. Called with no text it takes the window away.

- **Parameters:** Text, [X], [Y], [Options]
- **Answers:** the number that identifies the window, or the empty text when the window is taken away
- **Errors:** the desktop reports the failure of the call.

```ahk
ToolTip "hello", 10, 10
```

### TrayTip

Sends a notification to the desktop with a text and a title. The name is a Windows one -- a balloon in the notification area -- but the tree sends a desktop notification, which reaches the same user with the same words.

- **Parameters:** Text, [Title], [Options]
- **Answers:** the empty text
- **Errors:** the desktop reports the failure of the notification.

```ahk
TrayTip "done", "the script"
```

- **Parameters:** WinTitle
- **Answers:** the empty text
- **Errors:** "Target window not found." when the script has no window of its own, or when the title does not match the one it has.

```ahk
WinRestore "MyWindow"
```

### WinSetExStyle

Writes the extended style of a window. The style is absolute, the way the style of a window is: the text may carry a `+`, a `-` or a `^` before the number, and the runtime computes the new extended style out of the one that is there.

- **Parameters:** Style, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **Answers:** the empty text
- **Errors:** an empty text refuses with 'Parameter #1 of WinSetExStyle is invalid.', and 'empty string' is in the `Extra`; a window that is not there refuses with 'Target window not found.'.

```ahk
WinSetExStyle("+0x8", "ZZZ_NO_WINDOW_ZZZ")
```

### WinSetStyle

Writes the style of a window. The style is absolute: the text may carry a `+`, a `-` or a `^` before the number, and the runtime computes the new style out of the one that is there -- `+0x10` adds the bits, `-0x10` takes them away, `^0x10` turns them around, and a text with no prefix replaces the style. The number is read the way the `ATOU` of the v2 reads it: hexadecimal when the text says "0x", decimal otherwise, and zero when the text holds no number.

- **Parameters:** Style, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **Answers:** the empty text
- **Errors:** an empty text refuses with 'Parameter #1 of WinSetStyle is invalid.', and 'empty string' is in the `Extra`; a text that holds no number is not a refusal -- it is read as zero, and the failure that comes is the one of the window.

```ahk
WinSetStyle("+0x10", "ZZZ_NO_WINDOW_ZZZ")
```

### WinSetTitle

Renames the window the script made; renaming the window of another program is not something a Wayland client can do.

- **Parameters:** NewTitle, WinTitle
- **Answers:** the empty text
- **Errors:** "Target window not found." when the script has no window of its own, or when the title does not match the one it has.

```ahk
WinSetTitle "New Title", "MyWindow"
```

### WinSetTransColor

Writes the colour a window lets through. The colour is the name of one of the seventeen colours of HTML, a hexadecimal number, or the word "Off", which takes the colour key away.

- **Parameters:** Color, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **Answers:** the empty text
- **Errors:** a text that is not a colour refuses with 'Parameter #1 of WinSetTransColor is invalid.', and the text is in the `Extra`; a window that is not there refuses with 'Target window not found.'.

```ahk
WinSetTransColor("Red", "ZZZ_NO_WINDOW_ZZZ")
```

### WinShow

Puts the window of the script back on the screen, after a `WinHide`.

- **Parameters:** [WindowTitle] [, WinText] [, ExcludeTitle] [, ExcludeText]
- **Answers:** nothing
- **Errors:** a window that is not there answers 'Target window not found.'; a window of another program cannot be shown this way.

```ahk
WinShow "Untitled"
```

### WinWait

Waits for a window whose title matches to exist, and answers the identifier of it; the identifier of a Wayland window is a token, so it is text.

- **Parameters:** WinTitle, WinText, [Timeout], [ExcludeTitle], [ExcludeText]
- **Answers:** the identifier of the window as text, or 0 when the timeout ran out
- **Errors:** a session that is not Wayland answers "this desktop waits for the windows of a Wayland session, and this session is not Wayland"; the two exclusions are refused with "the two exclusions are not carried yet."; the wait is capped at sixty seconds when the timeout is left out.

```ahk
WinWait "Calculator", , 5
```

### WinWaitActive
