O mesmo nome nos três dialetos, e o nome que só um deles tem. Um nome do v1 que o v2 escreve de outra maneira aparece na tabela de só-v1, junto com o nome do v2 que o substituiu.

|---|---|
| v1 and v2 | 181 |
| v1 only | 226 |
| KeySharp only | 130 |
