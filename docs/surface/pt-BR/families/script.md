## O que a arvore faz com ele

### A_Index

O número da volta do laço que está rodando. É zero antes do primeiro laço, e cada laço guarda o valor que tinha e o devolve quando termina.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o número da volta, como um número
- **Erros:** nothing to read; a script may write the name, and the loop goes on from the value that was written.

```ahk
for item in [1, 2, 3]
    FileAppend A_Index, "*"
```

### A_Is64bitOS

Se a máquina é de 64 bits. A árvore responde com a largura do próprio ponteiro: 1 numa compilação de 64 bits do runtime, 0 numa de 32 bits.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** 1 ou 0
- **Erros:** nothing to read; the write is refused.

```ahk
FileAppend A_Is64bitOS, "*"
```

### A_IsAdmin

Se o script roda com direitos de administrador: o id de usuário efetivo, e o root é o que é zero.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** 1 quando o script está elevado, 0 quando não está
- **Erros:** the read fails when the machine cannot say; the write is refused.

```ahk
FileAppend A_IsAdmin, "*"
```

### A_OSVersion

A versão do sistema operacional da máquina: a release do kernel, lida de `/proc/sys/kernel/osrelease`.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** a versão, como um texto
- **Erros:** the read fails when the release of the kernel cannot be read; the write is refused.

```ahk
FileAppend A_OSVersion, "*"
```

### A_ScriptDir

O diretório onde a execução começou. O script do runner chega pela entrada padrão e não tem arquivo próprio, então o diretório do script é o diretório da execução.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o caminho do diretório, como um texto
- **Erros:** the read fails when the runtime does not keep the directory where the run started; the write is refused.

```ahk
FileAppend A_ScriptDir, "*"
```

### A_ScriptFullPath

O caminho do script. O script do runner vem pela entrada padrão e não tem arquivo, então o caminho é um asterisco.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o texto "*"
- **Erros:** the write is refused.

```ahk
FileAppend A_ScriptFullPath, "*"
```

### A_ScriptName

O nome do script. O script do runner vem pela entrada padrão e não tem arquivo, então o nome é um asterisco. Um script pode escrever o nome, e o valor escrito é o que ele guarda.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o texto "*", ou o texto que foi escrito
- **Erros:** nothing to read; the write takes any value.

```ahk
FileAppend A_ScriptName, "*"
```

### A_ThisFunc

O nome da função que está rodando.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o nome, como um texto; o texto vazio quando nenhuma função roda
- **Erros:** nothing to read; the write is refused.

```ahk
FileAppend A_ThisFunc, "*"
```

### CoordMode

Diz como as coordenadas são lidas. Os cinco alvos de v2 são o mouse, os pixels, o cursor de texto, o menu e o tooltip; a árvore não tem janelas, então os modos de cursor, menu e tooltip são guardados do mesmo jeito e nada os usa.

- **Parâmetros:** Target [, Relative]
- **Responde:** o modo anterior
- **Erros:** a target or a relative that v2 does not know is refused as an invalid parameter.

```ahk
CoordMode "Mouse", "Screen"
```

### Critical

A árvore recusa este nome: este runtime executa um script numa thread só, e não pode torná-lo crítico.

- **Parâmetros:** [OnOff]
- **Responde:** nada; a chamada falha
- **Erros:** the refusal is "this runtime runs one script in one thread, and it cannot make it critical."

```ahk
Critical
```

### Else

O outro lado de um if. Else if encadeia condições, e a primeira que casar roda.

- **Parâmetros:** a statement or a block
- **Responde:** nada
- **Erros:** none.

```ahk
if (0)
    MsgBox "no"
else
    MsgBox "yes"
```

### EnvGet

Devolve o valor de uma variável de ambiente do runner; o ambiente é o do processo em que o script roda.

- **Parâmetros:** VariableName
- **Responde:** o valor da variável, ou o texto vazio quando o ambiente não a tem
- **Erros:** nothing; a name that is not there is the empty text and not a failure.

```ahk
home := EnvGet("HOME")
```

### EnvSet

Define uma variável de ambiente do runner e devolve o valor; o script roda em uma thread só, e nada mais lê o ambiente durante a mudança.

- **Parâmetros:** VariableName, Value
- **Responde:** o valor que foi definido, como texto
- **Erros:** an empty name and a name that carries an equal sign are refused with the reason of the machine.

```ahk
EnvSet "MY_VAR", "value"
```

### IsSet

Se a variável de quem chama tem valor. A árvore carrega este além de `IsSetRef`, e ele pede a variável e não o valor dela.

- **Parâmetros:** the variable, not its value
- **Responde:** 1 quando a variável tem valor, 0 quando não tem
- **Erros:** an argument that is not a variable is refused with "IsSet requires a variable.".

```ahk
x := 1
FileAppend IsSet(x), "*"
```

### OnError

Registra a função que trata uma falha que o script não capturou.

- **Parâmetros:** Callback, [Order]
- **Responde:** o inteiro 1
- **Erros:** a callback that is not a function object, or a prototype that does not take two parameters, is refused with "Invalid callback function.".

```ahk
OnError((err, mode) => 0)
```

### OnExit

Registra a função que roda quando o script termina, qualquer que seja o motivo: a última instrução, um código pedido pelo script, ou uma falha que o parou.

- **Parâmetros:** Callback, [Order]
- **Responde:** o inteiro 1
- **Erros:** a callback that is not a function object, or a prototype that does not take two parameters, is refused with "Invalid callback function.".

```ahk
OnExit((reason, code) => 0)
```

### Pause

Define o estado de pausa do script. A árvore guarda um estado em vez de esperar uma tecla, o que travaria um script sem teclado. O estado aparece em A_IsPaused.

- **Parâmetros:** [OnOff]
- **Responde:** texto vazio
- **Erros:** a parameter that is not 0, 1 or -1 is an invalid parameter.

```ahk
Pause true
```

- **Parâmetros:** [OnOff]

### SetTimer

Registra uma função do script que roda entre as instruções. O runtime tem uma só thread, então o timer não é uma thread própria: roda entre as instruções e divide o orçamento do script.

- **Parâmetros:** Name, [Period]
- **Responde:** o inteiro 1
- **Erros:** more than two parameters are refused with "the priority of the timer is not carried yet."

```ahk
SetTimer("Tick", 1000)
```
