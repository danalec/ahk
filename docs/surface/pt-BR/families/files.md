## O que a arvore faz com ele

### A_DD

O dia do mês da hora local, com dois dígitos.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o dia, como um texto de dois dígitos
- **Erros:** the read fails when the clock of the runtime does not know the date of the machine; the write is refused.

```ahk
FileAppend A_DD, "*"
```

### A_LoopField

O campo em que o laço de análise está: o trecho do texto entre dois delimitadores.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o campo, como um texto; o texto vazio antes do primeiro laço de análise
- **Erros:** nothing to read; the write is refused.

```ahk
Loop Parse "a,b,c", ","
    FileAppend A_LoopField, "*"
```

### A_LoopFileName

O nome do arquivo em que o laço de arquivos está, sem a sua pasta.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o nome do arquivo, como um texto; o texto vazio antes do primeiro laço de arquivos
- **Erros:** nothing to read; the write is refused.

```ahk
Loop Files "*.txt"
    FileAppend A_LoopFileName, "*"
```

### A_LoopReadLine

A linha do arquivo em que o laço de leitura está.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** a linha, como um texto; o texto vazio antes do primeiro laço de leitura
- **Erros:** nothing to read; the write is refused.

```ahk
Loop Read "notes.txt"
    FileAppend A_LoopReadLine, "*"
```

### File.AtEOF

Se o arquivo está no fim. É uma propriedade e não um método: `f.AtEOF`.

- **Parâmetros:** nothing; it is a property, not a call
- **Responde:** 1 quando o arquivo está no fim, 0 quando não está
- **Erros:** a closed file answers one, for there is nothing more to read; the size of a file the machine cannot measure fails with the reason of the desktop.

```ahk
f := FileOpen("notes.txt", "r")
FileAppend f.AtEOF, "*"
```

### File.Close

Fecha o arquivo e devolve o handle para a máquina.

- **Parâmetros:** nothing
- **Responde:** o texto vazio
- **Erros:** the console is closed with the empty text; a close that the machine refuses fails with the reason of the desktop.

```ahk
f := FileOpen("notes.txt", "w")
f.Close()
```

### DirCopy

Copia um diretório e tudo o que há nele. O que é copiado é o conteúdo do diretório para o destino.

- **Parâmetros:** Source, Dest, [Overwrite]
- **Responde:** nada
- **Erros:** Error `Failed` when the source is not a directory, or when the destination is there and the overwrite is not asked for; a name that holds a wildcard is refused with the reason that the wildcards of v2 are not carried.

```ahk
DirCopy "src", "dst"
```

### DirCreate

Cria um diretório, com as pastas que faltam no caminho.

- **Parâmetros:** DirName
- **Responde:** nada
- **Erros:** OSError when the directory cannot be made.

```ahk
DirCreate "out"
```

### DirDelete

Apaga um diretório. Um diretório que não está vazio permanece, a não ser que a recursão seja pedida.

- **Parâmetros:** DirName, [Recurse]
- **Responde:** o nome do diretório.
- **Erros:** Error `Failed` when the directory is not there, or when it is not empty and the recursion is not asked for.

```ahk
d := DirDelete("out", 1)
```

### DirExist

Devolve os atributos da primeira pasta que o nome ou o padrão encontra.

- **Parâmetros:** DirName
- **Responde:** `D` quando a pasta existe, e o texto vazio quando não existe; um arquivo que casa com o padrão não é uma pasta.
- **Erros:** nothing fails.

```ahk
x := DirExist("out")
```

### DirMove

Move um diretório, com tudo o que há nele. Um destino que já existe é mesclado com o que vem: os arquivos da origem vencem.

- **Parâmetros:** Source, Dest, [Overwrite]
- **Responde:** nada
- **Erros:** Error `Failed` when the source is not a directory; a name that holds a wildcard is refused with the reason that the wildcards of v2 are not carried.

```ahk
DirMove "src", "dst"
```

### Download

Busca um arquivo da rede e o escreve no disco. A caixa faz isso com `curl`; a flag de cache que o v2 escreve na frente da url é aceita e descartada.

- **Parâmetros:** URL, FileName
- **Responde:** nada
- **Erros:** Error when the url cannot be reached at all, or when the machine has no `curl`; a file that is not there on the network is not a failure, and the page of the error of the server is what is written.

```ahk
Download "https://example.com/x", "x.html"
```

### File

A classe de um arquivo aberto da máquina. A classe não é criada: `File(...)` responde "Invalid base."; o arquivo é criado pelo embutido `FileOpen`, e é o único jeito de ter um.

- **Parâmetros:** nothing that makes it; the arguments of `FileOpen` open the file
- **Responde:** o objeto da classe `File`
- **Erros:** the call of the class is refused with "Invalid base.".

```ahk
f := FileOpen("notes.txt", "w")
f.Close()
```

### FileAppend

Acrescenta texto ao fim de um arquivo. O nome do arquivo pode ser `*`, e o texto vai então para a saída do relatório; dentro do corpo de um `Loop Read` o nome pode ser omitido, e o arquivo do laço é o que é escrito.

- **Parâmetros:** Text, FileName, [Options]
- **Responde:** nada
- **Erros:** ValueError when the name of the file is empty or when an option is not one of v2; OSError when the file cannot be opened for writing. The options are the encoding of the file -- `UTF-8`, `UTF-16` and the code page of the machine --, `RAW` and a linefeed; a code page the tree does not carry is refused with the reason.

```ahk
FileAppend "hello`n", "out.txt"
```

### FileGetTime

Devolve quando um arquivo foi criado, quando foi alterado, ou quando foi lido.

- **Parâmetros:** FileName, [Which]
- **Responde:** o carimbo do v2, os catorze dígitos de `YYYYMMDDHH24MISS`, no horário local da máquina.
- **Erros:** ValueError when `Which` is not `M`, `C`, `A` or `CUT`; OSError when the file cannot be read.

```ahk
t := FileGetTime("out.txt", "M")
```

### File.Length

- **Responde:** o tamanho, como um número; um arquivo fechado responde zero
- **Erros:** the write of a size below the size of the file is refused: this desktop cannot make a file shorter, it cannot cut one.

```ahk
f := FileOpen("notes.txt", "r")
FileAppend f.Length, "*"
```

### File.Pos

A posição do arquivo, em bytes. É uma propriedade e não um método: `f.Pos`.

- **Parâmetros:** nothing; it is a property, not a call
- **Responde:** a posição, como um número; um arquivo fechado responde -1

```ahk
f := FileOpen("notes.txt", "r")
```
