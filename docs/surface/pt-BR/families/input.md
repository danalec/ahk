## O que a arvore faz com ele

### A_Cursor

A forma do cursor do ponteiro. A forma pertence à máquina, e este runtime não a lê.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** nada: o nome recusa
- **Erros:** the read refuses with "the shape of the cursor of the machine is not read by this runtime."

```ahk
FileAppend A_Cursor, "*"
```

### A_KeyDelay

O atraso entre as teclas de um `Send`, em milissegundos. É uma configuração da execução, e vale dez por padrão.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o atraso, como um número
- **Erros:** the write takes the number of the value, and a text that holds no number is zero.

```ahk
FileAppend A_KeyDelay, "*"
```

### A_SendMode

O método que um `Send` usa: `Input`, `Event`, `Play` ou `InputThenPlay`.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o nome do modo, como um texto
- **Erros:** the write takes the name of one of the four modes, and any other name is refused with "Invalid value.".

```ahk
FileAppend A_SendMode, "*"
```

### A_ThisHotkey

O nome da hotkey que está rodando. As hotkeys são as do sistema de hotkeys do runtime, e o nome é o texto vazio quando nenhuma hotkey roda.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o nome da hotkey, como um texto; o texto vazio quando nenhuma hotkey roda
- **Erros:** nothing to read; the write is refused.

```ahk
FileAppend A_ThisHotkey, "*"
```

### BlockInput

Só consegue desligar a entrada da máquina inteira. Bloquear a entrada da máquina toda é um privilégio que este compositor não dá a um cliente, e a árvore não vai fingir que deu.

- **Parâmetros:** Mode
- **Responde:** nada para 'Off'
- **Erros:** any other mode fails with 'blocking the input of the whole machine is a privilege this compositor does not give a client'.

```ahk
BlockInput "Off"
```

### Click

Clica com o ponteiro do backend, que é um dispositivo uinput absoluto: move até o lugar, assenta, pressiona e solta.

- **Parâmetros:** [X, Y] [Button] [Count]
- **Responde:** nada
- **Erros:** the wheel, the fourth and the fifth buttons, the pressing of a button and the place relative to the pointer are refused as not carried yet; on a host without `grim` the click fails with the reason of the screen, because the pointer needs the size of the screen.

```ahk
Click 100, 200
```

### GetKeyName

O nome da tecla, como v2 o dá. Os nomes são os da lista de teclas de v2: `Esc`, `Enter`, `CtrlRight`, `Numpad0`, e as grafias `vkXX` e `scXXX`.

- **Parâmetros:** KeyName
- **Responde:** o nome da tecla
- **Erros:** a name the tree does not know is the empty text, the way v2 answers a name it does not know.

```ahk
name := GetKeyName("Enter")
```

### GetKeySC

O código do evento de entrada Linux da tecla. É o código que o backend escreve no seu próprio dispositivo, e não o scan code do teclado de PC: as duas numerações divergem nas teclas estendidas.

- **Parâmetros:** KeyName
- **Responde:** o código de evento de entrada, um número
- **Erros:** a name the tree does not know is the empty text, the way v2 answers a name it does not know.

```ahk
sc := GetKeySC("Enter")
```

### GetKeyState

Lê o que o vigia de hotkeys viu: se uma tecla está pressionada. O segundo parâmetro só aceita 'T' e 'P' de v2.

- **Parâmetros:** KeyName [, Mode]
- **Responde:** 1 quando a tecla está pressionada, 0 quando não está
- **Erros:** a key name the tree does not know, and a mode that is neither 'T' nor 'P', are refused as invalid parameters; on a host that is not Linux the watcher cannot answer at all.

```ahk
state := GetKeyState("Shift")
```


### Hotkey

Registra um hotkey: a tecla vigiada e a função que ela roda. O registro é da árvore e o vigia é da máquina: o script diz qual função o hotkey roda, e a máquina diz qual tecla foi pressionada.

- **Parâmetros:** KeyName, Action [, Options]
- **Responde:** nada
- **Erros:** a hotkey without an action is 'Nonexistent hotkey.'; the watcher reads the physical keyboard of the machine, so on a host that is not Linux the registration fails with 'the hotkeys of this box watch a Linux device; this is not Linux'.

```ahk
Hotkey "^s", SaveTheFile
```
