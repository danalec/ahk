## O que a arvore faz com ele

### A_AppData

A pasta de dados do usuário. Em uma máquina Linux é `$XDG_DATA_HOME`, e `$HOME/.local/share` quando a variável não existe.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o caminho da pasta, como um texto
- **Erros:** the read fails with "the machine has no such folder." when the machine has no such folder; the write is refused.

```ahk
FileAppend A_AppData, "*"
```

### A_ComputerName

O nome do computador, como a rede o vê: o kernel, e o `HOSTNAME` do ambiente quando o kernel não tem nome.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o nome, como um texto
- **Erros:** the read fails when neither the kernel nor the session carries the name; the write is refused.

```ahk
FileAppend A_ComputerName, "*"
```

### A_Desktop

A pasta da área de trabalho do usuário: a pasta que a máquina conhece, e `$HOME/Desktop` quando ela não conhece nenhuma.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o caminho da pasta, como um texto
- **Erros:** the read fails with "the machine has no such folder." when the machine has no such folder; the write is refused.

```ahk
FileAppend A_Desktop, "*"
```

### A_MM

O mês da hora local da máquina, com dois dígitos.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o mês, como um texto de dois dígitos
- **Erros:** the read fails when the clock of the runtime does not know the date of the machine; the write is refused.

```ahk
FileAppend A_MM, "*"
```

### A_Temp

A pasta de arquivos temporários da máquina: `TMPDIR`, e `/tmp` quando a variável não existe.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o caminho da pasta, como um texto
- **Erros:** the read fails with "the machine has no such folder." when the machine has no such folder; the write is refused.

```ahk
FileAppend A_Temp, "*"
```

### A_TickCount

O número de milissegundos que o runtime conta desde uma origem arbitrária. A contagem nunca volta atrás.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o número de milissegundos, como um número
- **Erros:** the write is refused; the name is a built-in variable that the dialect does not let a script write.

```ahk
FileAppend A_TickCount, "*"
```

### A_UserName

O nome do usuário da sessão: o `USER` do ambiente.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o nome, como um texto
- **Erros:** the read fails when the session carries no such name: "the session does not carry the name of the user: the environment has no USER."; the write is refused.

```ahk
FileAppend A_UserName, "*"
```

### ProcessClose

Encerra um processo; a caixa envia SIGTERM, o sinal educado que pede ao processo que termine.

- **Parâmetros:** ProcessNameOrPID
- **Responde:** o pid do processo encerrado, 0 quando ele não estava lá ou não pôde ser encerrado
- **Erros:** a process of another user is a process the script cannot open, and the answer is zero and not a failure.

```ahk
ProcessClose "firefox"
```

### ProcessExist

Responde se existe um processo e com qual pid; os processos da máquina são lidos de /proc.

- **Parâmetros:** [ProcessNameOrPID]
- **Responde:** o pid do processo, ou 0 quando não há nenhum
- **Erros:** a machine without /proc answers "the processes of this machine are read out of /proc, and this machine has none"; a process that is not there is zero and not a failure.

```ahk
if ProcessExist("firefox")
```

### ProcessGetName

Devolve o nome do executável de um processo; o nome é o nome do arquivo de /proc/<pid>/exe, e o nome do kernel é o plano B.

- **Parâmetros:** [ProcessNameOrPID]
- **Responde:** o nome do executável, como texto
- **Erros:** "Target process not found." when the process is not there; a machine without /proc answers "the processes of this machine are read out of /proc, and this machine has none".

```ahk
name := ProcessGetName(1234)
```

### ProcessGetPath

Devolve o caminho inteiro do executável de um processo; o caminho é o alvo da ligação /proc/<pid>/exe, e o " (deleted)" que o kernel acrescenta é cortado.

- **Parâmetros:** [ProcessNameOrPID]
- **Responde:** o caminho do executável, como texto
- **Erros:** "Target process not found." when the process is not there; a machine without /proc answers "the processes of this machine are read out of /proc, and this machine has none".

```ahk
path := ProcessGetPath(1234)
```

### ProcessWait

Espera que um processo exista; a caixa verifica a cada cem milissegundos, como faz o binário do v2.

- **Parâmetros:** ProcessNameOrPID, [Timeout]
- **Responde:** o pid do processo quando ele aparece, 0 no fim do tempo
- **Erros:** a call without a timeout waits for ever; a machine without /proc answers "the processes of this machine are read out of /proc, and this machine has none".

```ahk
ProcessWait "firefox", 10
```

### ProcessWaitClose

Espera que um processo que existe termine; um processo que nunca existiu já sumiu, e a espera acaba na hora.

- **Parâmetros:** ProcessNameOrPID, [Timeout]
- **Responde:** 0 quando o processo sumiu, o pid do processo que ainda está lá no fim do tempo
- **Erros:** a call without a timeout waits for ever; a machine without /proc answers "the processes of this machine are read out of /proc, and this machine has none".

```ahk
ProcessWaitClose "firefox", 10
```

### Run

Executa um comando e espera por ele. O que o comando escreveu na saída vai para a saída do relatório.

- **Parâmetros:** Command, [WorkingDir]
- **Responde:** o código de saída do comando
- **Erros:** more than two parameters are refused with "the options of the window and the pid of the process are not carried yet."

```ahk
Run "ls"
```

### SysGet

Devolve uma métrica do sistema; os números são os de GetSystemMetrics, e só as da tela são carregadas.

- **Parâmetros:** Metric
- **Responde:** a métrica, como inteiro
- **Erros:** a metric of the window manager of Windows is refused with "SysGet(n) is a metric of the window manager of Windows, and this desktop does not have one."; a compositor that published no monitor answers "the compositor published no monitor, so the metric n of SysGet is not known."; a number that is not a metric at all is zero.

```ahk
w := SysGet(0)
```
