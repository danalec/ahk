## O que a arvore faz com ele

### Array

A classe de uma fileira de valores. `Array(...)` cria uma com os valores dados, e o literal `[1, 2, 3]` cria uma também.

- **Parâmetros:** the values of the array, any number of them
- **Responde:** o objeto da classe `Array`
- **Erros:** nothing to make the array; the places count from one, and an index that is not there is refused with "Invalid index.".

```ahk
a := Array(1, 2, 3)
FileAppend a.Length, "*"
```

### Map.Delete

Tira uma chave do mapa e responde o valor que estava sob ela.

- **Parâmetros:** the key
- **Responde:** o valor que estava sob a chave
- **Erros:** a key that is not there is refused with "Item has no value.", and the key is named in the `Extra` of the failure.

```ahk
m := Map("x", 1)
FileAppend m.Delete("x"), "*"
```

### Enumerator

A classe do andarilho de um laço: um enumerador entrega as partes de uma sequência, uma volta por vez. A classe não é criada; o `__Enum` de um valor cria uma, e a chamada dela é a volta da enumeração.

- **Parâmetros:** nothing that makes it
- **Responde:** a classe de um enumerador, como um texto
- **Erros:** the call of the class is refused with "Invalid base.".

```ahk
for item in [1, 2]
    FileAppend Type(item), "*"
```

### Func

A classe de uma função: uma função do script, um método, um lambda ou um embutido. A classe não é criada: `Func(...)` responde "Invalid base."; a classe de um valor de função é `Func`.

- **Parâmetros:** nothing that makes it
- **Responde:** a classe de um valor de função, como um texto
- **Erros:** the call of the class is refused with "Invalid base.".

```ahk
FileAppend Abs.__Class, "*"
```

### Map.Get

O valor que está sob uma chave do mapa.

- **Parâmetros:** the key, and the value to answer when the key is not there
- **Responde:** o valor sob a chave
- **Erros:** a key that is not there is refused with "Item has no value.", and the key is named in the `Extra` of the failure; the second argument is the default of the call, and the `Default` of the map is the last word.

```ahk
m := Map("x", 1)
FileAppend m.Get("x"), "*"
```

### Map.Has

Se o mapa tem uma chave.

- **Parâmetros:** the key
- **Responde:** 1 quando a chave está lá, 0 quando não está
- **Erros:** nothing; a key that is not there is not a failure, the question is answered.

```ahk
m := Map("x", 1)
FileAppend m.Has("x"), "*"
```

### Array.Length

O número de lugares do array. É uma propriedade e não um método: `a.Length`, e não `a.Length()`.

- **Parâmetros:** nothing; it is a property, not a call
- **Responde:** o número de lugares, como um número
- **Erros:** the write of a negative number is refused with "Invalid value."; a longer array gets places that have no value of their own, and a shorter one loses the places at the end.

```ahk
a := [1, 2, 3]
FileAppend a.Length, "*"
```

### Map

A classe de uma tabela de chaves e valores. `Map(key, value, ...)` cria uma, e a ordem das entradas é a ordem em que foram colocadas.

- **Parâmetros:** the pairs of key and value, an even number of them
- **Responde:** o objeto da classe `Map`
- **Erros:** an odd number of arguments is refused with "Invalid number of parameters."; a key that is not there is refused with "Item has no value.".

```ahk
m := Map("x", 1)
FileAppend m.Count, "*"
```

### Object

A raiz da cadeia das classes: todo objeto do runtime é um. `Object()` cria um objeto vazio, e o literal `{a: 1}` cria um com uma propriedade.

- **Parâmetros:** nothing
- **Responde:** o objeto da classe `Object`
- **Erros:** nothing; a member that is not there is refused with the type of the value and the name of the member.

```ahk
o := Object()
FileAppend o.__Class, "*"
```

### ObjGetBase

A base de um objeto: o protótipo da sua classe.

- **Parâmetros:** the object
- **Responde:** o objeto da base
- **Erros:** a value that is not an object is refused with "Expected an object but got ...".

```ahk
FileAppend ObjGetBase({a: 1}).__Class, "*"
```

### Array.Pop

Tira o último valor do array e responde o valor.

- **Parâmetros:** nothing
- **Responde:** o valor que estava no fim, como um texto quando o lugar não tinha valor próprio
- **Erros:** an empty array is refused with "Array is empty.".

```ahk
a := [1, 2]
FileAppend a.Pop(), "*"
```

### Array.Push

Coloca os valores no fim do array e responde o próprio array, para que as chamadas possam ser encadeadas.

- **Parâmetros:** the values, any number of them
- **Responde:** o próprio array
- **Erros:** nothing; the push of no value changes nothing and still answers the array.

```ahk
a := [1]
a.Push(2, 3)
FileAppend a.Length, "*"
```

### Map.Set

Coloca os pares de chave e valor no mapa e responde o próprio mapa, para que as chamadas possam ser encadeadas.

- **Parâmetros:** the pairs of key and value, an even number of them
- **Responde:** o próprio mapa
- **Erros:** an odd number of arguments is refused with "Invalid number of parameters.".

```ahk
m := Map()
m.Set("x", 1)
FileAppend m.Count, "*"
```
