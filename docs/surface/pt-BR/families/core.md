## O que a arvore faz com ele

### Abs

A distância até zero. Um inteiro continua inteiro.

- **Parâmetros:** Number
- **Responde:** o número sem o seu sinal
- **Erros:** a value that is not a number is refused.

```ahk
Abs(-3)
```

### Format

Um padrão com os valores dentro. O padrão é o do dialeto de referência: {1} é o primeiro argumento, um placeholder sem número pega o próximo, e {{ e }} são uma chave cada.

- **Parâmetros:** Pattern, [Value1], [Value2], ...
- **Responde:** o texto do padrão com os valores dentro
- **Erros:** a placeholder that names an argument that is not there, or whose spec is not one the dialect reads, is left exactly as it was written; a value of a kind the spec does not want is refused.

```ahk
Format("{1} + {2} = {3}", 1, 2, 3)
```

### GetMethod

Um método de um objeto, como um valor que pode ser chamado.

- **Parâmetros:** the object, the name of the method, and the number of parameters it would take
- **Responde:** o método, como um valor da classe `Func`
- **Erros:** a method that is not there is refused with the type of the value and the name of the member.

```ahk
o := {a: 1}
FileAppend GetMethod(o, "HasOwnProp").__Class, "*"
```

### HasBase

Se a base de um objeto é outro objeto.

- **Parâmetros:** the object, and the base
- **Responde:** 1 quando a base é aquela, 0 quando não é
- **Erros:** a base that is not an object is refused before the question of the object is asked.

```ahk
FileAppend HasBase({a: 1}, {}), "*"
```

### HasMethod

Se um objeto tem um método.

- **Parâmetros:** the object, the name of the method, and the number of parameters it would take
- **Responde:** 1 quando o objeto tem esse método, 0 quando não tem
- **Erros:** nothing; a value that is not an object answers zero, and the question with no name asks whether the value is a class.

```ahk
o := {a: 1}
FileAppend HasMethod(o, "a"), "*"
```

### HasProp

Se um objeto tem uma propriedade.

- **Parâmetros:** the object, and the name of the property
- **Responde:** 1 quando o objeto tem essa propriedade, 0 quando não tem
- **Erros:** nothing; a value that is not an object has the property `__Class` and no other, so the answer for it is one only for that name.

```ahk
o := {a: 1}
FileAppend HasProp(o, "a"), "*"
```

### InStr

Onde um texto está em outro texto. A posição conta a partir de um e é zero quando o trecho procurado não está lá.

- **Parâmetros:** Haystack, Needle, [CaseSense], [Start], [Occurrence]
- **Responde:** a posição da ocorrência, ou 0 quando não há nenhuma
- **Erros:** a needle that is empty is an invalid parameter; the logical case sense is an invalid parameter; a start or an occurrence of zero is an invalid parameter.

```ahk
InStr("hello", "ll")
```

- **Erros:** a second parameter is refused with "the code page of the text is not carried yet.".

```ahk

```

### IsSet

Se a variável de quem chama tem valor. A árvore carrega este além de `IsSetRef`, e ele pede a variável e não o valor dela.

- **Parâmetros:** the variable, not its value
- **Responde:** 1 quando a variável tem valor, 0 quando não tem
- **Erros:** an argument that is not a variable is refused with "IsSet requires a variable.".

```ahk
x := 1
FileAppend IsSet(x), "*"
```
