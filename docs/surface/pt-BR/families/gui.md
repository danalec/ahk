## O que a arvore faz com ele

### ControlGetExStyle

O estilo estendido de um controle de uma janela: os bits `WS_EX_*` do Windows, do mesmo jeito que o estilo estendido de uma janela.

- **Parâmetros:** Control, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **Responde:** o estilo estendido, como um número
- **Erros:** a window that is not there refuses with 'Target window not found.', and a control that is not there with 'Target control not found.'; the text of the window and the two exclusions are not carried yet.

```ahk
FileAppend ControlGetExStyle("Edit1", "ZZZ_NO_WINDOW_ZZZ"), "*"
```

### ControlGetStyle

O estilo de um controle de uma janela: o número dos bits do Windows, do mesmo jeito que o estilo de uma janela. Um controle é uma janela por si só, e é achado pelo nome, pelo número ou pela classe.

- **Parâmetros:** Control, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **Responde:** o estilo, como um número
- **Erros:** a window that is not there refuses with 'Target window not found.', and a control that is not there with 'Target control not found.'; the text of the window and the two exclusions are not carried yet.

```ahk
FileAppend ControlGetStyle("Edit1", "ZZZ_NO_WINDOW_ZZZ"), "*"
```

### ControlSetExStyle

Escreve o estilo estendido de um controle de uma janela. O estilo é absoluto, do mesmo jeito que o estilo estendido de uma janela: o texto pode trazer um `+`, um `-` ou um `^` antes do número, e o runtime calcula o novo estilo estendido a partir do que já estava lá.

- **Parâmetros:** Style, Control, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **Responde:** texto vazio
- **Erros:** an empty text refuses with 'Parameter #1 of ControlSetExStyle is invalid.'; a window that is not there refuses with 'Target window not found.', and a control that is not there with 'Target control not found.'.

```ahk
ControlSetExStyle("+0x8", "Edit1", "ZZZ_NO_WINDOW_ZZZ")
```

### ControlSetStyle

Escreve o estilo de um controle de uma janela. O estilo é absoluto, do mesmo jeito que o estilo de uma janela: o texto pode trazer um `+`, um `-` ou um `^` antes do número, e o runtime calcula o novo estilo a partir do que já estava lá.

- **Parâmetros:** Style, Control, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]


### Edit

Abre o arquivo do script no programa que a máquina usa para abrir um arquivo desse tipo — o editor de um script.

- **Parâmetros:** none
- **Responde:** o texto vazio
- **Erros:** the call fails when the script has no file: a script that comes from the standard input has none, and the reason is "the script of this runtime is read from the standard input, so it has no file for an editor to open".

```ahk
Edit()
```

### InputBox

Pede um texto ao usuário numa caixa da área de trabalho e devolve um objeto com o texto em Value e o modo de fechamento em Result.

- **Parâmetros:** Prompt, [Title], [Options], [Default]
- **Responde:** um objeto com as propriedades Value e Result, onde Result é "OK", "Cancel" ou "Timeout"
- **Erros:** an option the dialect does not know is refused with "Invalid option.".

```ahk
answer := InputBox("your name?", "hello")
MsgBox answer.Value
```

### MsgBox

Mostra uma mensagem. A árvore não tem janela própria, então o texto vai para a saída do relatório em vez de aparecer na tela, e a chamada devolve o mesmo texto.

- **Parâmetros:** Message, [Title], [Options]
- **Responde:** o texto da mensagem
- **Erros:** more than one parameter is refused with "the options, the title and the variable that takes the answer are not carried yet."

```ahk
MsgBox "hello"
```

### ScriptHwnd

O handle da janela escondida do script, o nome que o v2 dá a ele. A janela é a que dona as mensagens da sessão, e o número muda com a execução.

- **Parâmetros:** nothing; it is a variable, not a call
- **Responde:** o handle da janela, como um número
- **Erros:** the read fails with the reason of the desktop when the desktop has no window of the script; the write is refused.

```ahk
FileAppend A_ScriptHwnd, "*"
```

### ToolTip

Mostra uma pequena janela de texto num ponto da tela. Chamada sem texto, ela remove a janela.

- **Parâmetros:** Text, [X], [Y], [Options]
- **Responde:** o número que identifica a janela, ou texto vazio quando a janela é removida
- **Erros:** the desktop reports the failure of the call.

```ahk
ToolTip "hello", 10, 10
```

### TrayTip

Manda uma notificação à área de trabalho com um texto e um título. O nome é do Windows -- um balão na área de notificação -- mas a árvore manda uma notificação de mesa, que chega ao mesmo usuário com as mesmas palavras.

- **Parâmetros:** Text, [Title], [Options]

- **Erros:** the desktop reports the failure of the notification.

```ahk
TrayTip "done", "the script"
```

### WinActivate

Traz uma janela para a frente. Age na janela do próprio script: a listagem do compositor não publica um jeito de erguer a janela de outro programa.

- **Parâmetros:** [WindowTitle] [, WinText] [, ExcludeTitle] [, ExcludeText]
- **Responde:** nada

```ahk
WinActivate "Untitled"
```

### WinActive

A janela que tem o foco. O backend é uma sessão Wayland, e o compositor é quem sabe das janelas e qual delas está na frente.

- **Responde:** o identificador da janela ativa, zero quando não há nenhuma
- **Erros:** the text of the window and the exclusions are not carried yet; a compositor that does not publish the focus answers with the reason, and not with a guess.

```ahk
id := WinActive()
```

### WinSetExStyle

Escreve o estilo estendido de uma janela. O estilo é absoluto, do mesmo jeito que o estilo de uma janela: o texto pode trazer um `+`, um `-` ou um `^` antes do número, e o runtime calcula o novo estilo estendido a partir do que já estava lá.

- **Parâmetros:** Style, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **Responde:** texto vazio
- **Erros:** an empty text refuses with 'Parameter #1 of WinSetExStyle is invalid.', and 'empty string' is in the `Extra`; a window that is not there refuses with 'Target window not found.'.

```ahk

```

### WinSetStyle

Escreve o estilo de uma janela. O estilo é absoluto: o texto pode trazer um `+`, um `-` ou um `^` antes do número, e o runtime calcula o novo estilo a partir do que já estava lá -- `+0x10` soma os bits, `-0x10` tira eles, `^0x10` os inverte, e um texto sem prefixo substitui o estilo. O número é lido do jeito que o `ATOU` do v2 lê: hexadecimal quando o texto diz "0x", decimal nos outros casos, e zero quando o texto não tem número.

- **Parâmetros:** Style, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **Responde:** texto vazio
- **Erros:** an empty text refuses with 'Parameter #1 of WinSetStyle is invalid.', and 'empty string' is in the `Extra`; a text that holds no number is not a refusal -- it is read as zero, and the failure that comes is the one of the window.

```ahk
WinSetStyle("+0x10", "ZZZ_NO_WINDOW_ZZZ")
```

### WinWait

Espera que exista uma janela cujo título combine, e devolve o identificador dela; o identificador de uma janela Wayland é um token, e portanto texto.

- **Parâmetros:** WinTitle, WinText, [Timeout], [ExcludeTitle], [ExcludeText]
- **Responde:** o identificador da janela como texto, ou 0 quando o tempo acabou
- **Erros:** a session that is not Wayland answers "this desktop waits for the windows of a Wayland session, and this session is not Wayland"; the two exclusions are refused with "the two exclusions are not carried yet."; the wait is capped at sixty seconds when the timeout is left out.

```ahk
WinWait "Calculator", , 5
```
