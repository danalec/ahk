## 这棵树对它做什么

### Abs

与零的距离。整数仍然是整数。

- **参数:** Number
- **返回:** 去掉符号后的数字
- **错误:** a value that is not a number is refused.

```ahk
Abs(-3)
```

### Format

把数值填入模式的文本。模式是参考方言的那一套：{1} 是第一个参数，没有编号的占位符取下一个参数，{{ 和 }} 各代表一个花括号。

- **参数:** Pattern, [Value1], [Value2], ...
- **返回:** 填入数值之后的模式文本
- **错误:** a placeholder that names an argument that is not there, or whose spec is not one the dialect reads, is left exactly as it was written; a value of a kind the spec does not want is refused.

```ahk
Format("{1} + {2} = {3}", 1, 2, 3)
```

### GetMethod

对象的某个方法，作为一个可以调用的值。

- **参数:** the object, the name of the method, and the number of parameters it would take
- **返回:** 该方法，作为类为 `Func` 的值
- **错误:** a method that is not there is refused with the type of the value and the name of the member.

```ahk
o := {a: 1}
FileAppend GetMethod(o, "HasOwnProp").__Class, "*"
```

### HasBase

某个对象的基类是不是另一个对象。

- **参数:** the object, and the base
- **返回:** 基类是它时为 1，否则为 0
- **错误:** a base that is not an object is refused before the question of the object is asked.

```ahk
FileAppend HasBase({a: 1}, {}), "*"
```

### HasMethod

某个对象是否有某个方法。

- **参数:** the object, the name of the method, and the number of parameters it would take
- **返回:** 对象有该方法时为 1，没有时为 0
- **错误:** nothing; a value that is not an object answers zero, and the question with no name asks whether the value is a class.

```ahk
o := {a: 1}
FileAppend HasMethod(o, "a"), "*"
```

### HasProp

某个对象是否有某个属性。

- **参数:** the object, and the name of the property
- **返回:** 对象有该属性时为 1，没有时为 0
- **错误:** nothing; a value that is not an object has the property `__Class` and no other, so the answer for it is one only for that name.

```ahk
o := {a: 1}
FileAppend HasProp(o, "a"), "*"
```

### InStr

一段文本在另一段文本中的位置。位置从 1 开始，找不到时为 0。

- **参数:** Haystack, Needle, [CaseSense], [Start], [Occurrence]
- **返回:** 匹配的位置；没有匹配时为 0
- **错误:** a needle that is empty is an invalid parameter; the logical case sense is an invalid parameter; a start or an occurrence of zero is an invalid parameter.

```ahk
InStr("hello", "ll")
```

### IsNumber

一个值是不是数字：整数、浮点数，或是写着数字的文本。十六进制文本也算数字。

- **参数:** Value
- **返回:** 是数字时为 1，否则为 0
- **错误:** a second parameter is refused with "the code page of the text is not carried yet.".

```ahk

```

### IsSet

调用者的变量是否有值。这个树除 `IsSetRef` 之外也带着它，它要的是变量，而不是变量的值。

- **参数:** the variable, not its value
- **返回:** 变量有值时为 1，没有时为 0
- **错误:** an argument that is not a variable is refused with "IsSet requires a variable.".

```ahk
x := 1
FileAppend IsSet(x), "*"
```

### Ln

一个数的自然对数。
