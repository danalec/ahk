## 这棵树对它做什么

### ControlGetExStyle

窗口中一个控件的扩展样式：Windows 的 `WS_EX_*` 位，与窗口的扩展样式一样。

- **参数:** Control, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **返回:** 扩展样式，作为数字
- **错误:** a window that is not there refuses with 'Target window not found.', and a control that is not there with 'Target control not found.'; the text of the window and the two exclusions are not carried yet.

```ahk
FileAppend ControlGetExStyle("Edit1", "ZZZ_NO_WINDOW_ZZZ"), "*"
```

### ControlGetStyle

窗口中一个控件的样式：Windows 的那些位组成的数字，与窗口的样式一样。控件本身就是窗口，按名称、编号或类找到它。

- **参数:** Control, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **返回:** 样式，作为数字
- **错误:** a window that is not there refuses with 'Target window not found.', and a control that is not there with 'Target control not found.'; the text of the window and the two exclusions are not carried yet.

```ahk
FileAppend ControlGetStyle("Edit1", "ZZZ_NO_WINDOW_ZZZ"), "*"
```

### ControlSetExStyle

写入窗口中一个控件的扩展样式。样式是绝对的，与窗口的扩展样式一样：文本在数字之前可以带 `+`、`-` 或 `^`，运行时就已有的扩展样式算出新的扩展样式。

- **参数:** Style, Control, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **返回:** 空文本
- **错误:** an empty text refuses with 'Parameter #1 of ControlSetExStyle is invalid.'; a window that is not there refuses with 'Target window not found.', and a control that is not there with 'Target control not found.'.

```ahk
ControlSetExStyle("+0x8", "Edit1", "ZZZ_NO_WINDOW_ZZZ")
```

### ControlSetStyle

写入窗口中一个控件的样式。样式是绝对的，与窗口的样式一样：文本在数字之前可以带 `+`、`-` 或 `^`，运行时就已有的样式算出新样式。

- **参数:** Style, Control, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **返回:** 空文本
- **错误:** an empty text refuses with 'Parameter #1 of ControlSetStyle is invalid.'; a window that is not there refuses with 'Target window not found.', and a control that is not there with 'Target control not found.'.

```ahk
ControlSetStyle("+0x10", "Edit1", "ZZZ_NO_WINDOW_ZZZ")
```

### Edit

用机器打开该类文件所用的程序（脚本的编辑器）打开脚本的文件。

- **参数:** none
- **返回:** 空文本
- **错误:** the call fails when the script has no file: a script that comes from the standard input has none, and the reason is "the script of this runtime is read from the standard input, so it has no file for an editor to open".

```ahk
Edit()
```

### InputBox

在桌面的对话框里向用户要一段文本，返回一个对象：Value 是输入的文本，Result 是对话框被关闭的方式。

- **参数:** Prompt, [Title], [Options], [Default]
- **返回:** 带 Value 和 Result 属性的对象，Result 是 "OK"、"Cancel" 或 "Timeout"
- **错误:** an option the dialect does not know is refused with "Invalid option.".

```ahk
answer := InputBox("your name?", "hello")
MsgBox answer.Value
```

### MsgBox

显示一条消息。这棵树没有自己的窗口，因此文本进入报告的输出，而不是显示在屏幕上；调用返回同样的文本。

- **参数:** Message, [Title], [Options]
- **返回:** 消息的文本
- **错误:** more than one parameter is refused with "the options, the title and the variable that takes the answer are not carried yet."

```ahk
MsgBox "hello"
```

### ScriptHwnd

脚本那个隐藏窗口的句柄，即 v2 给它的名字。这个窗口就是拥有本次会话消息的那个，数字随运行而变。

- **参数:** nothing; it is a variable, not a call
- **返回:** 窗口的句柄，作为数字
- **错误:** the read fails with the reason of the desktop when the desktop has no window of the script; the write is refused.

```ahk
FileAppend A_ScriptHwnd, "*"
```

### ToolTip

在屏幕的某个位置显示一个小文本窗口。不带文本调用时会把窗口移除。

- **参数:** Text, [X], [Y], [Options]
- **返回:** 标识该窗口的编号；移除窗口时返回空文本
- **错误:** the desktop reports the failure of the call.

```ahk
ToolTip "hello", 10, 10
```

### TrayTip

向桌面发送一条带文本和标题的通知。这个名字来自 Windows（通知区里的气泡），但这棵树发送的是桌面通知，同样的用户会看到同样的内容。

- **参数:** Text, [Title], [Options]
- **返回:** 空文本
- **错误:** the desktop reports the failure of the notification.

```ahk
TrayTip "done", "the script"
```

### WinActivate

把窗口置于最前。它作用于脚本自己的窗口：合成器的窗口列表没有提供把别的程序的窗口提到前面的办法。

- **参数:** [WindowTitle] [, WinText] [, ExcludeTitle] [, ExcludeText]
- **返回:** 无返回值
- **错误:** a window that is not there answers 'Target window not found.'; a window of another program cannot be activated this way.

```ahk
WinActivate "Untitled"
```

### WinActive

取得拥有焦点的窗口。后端是 Wayland 会话，合成器才知道有哪些窗口以及哪个在前。

- **参数:** [WindowTitle] [, WinText] [, ExcludeTitle] [, ExcludeText]
- **返回:** 活动窗口的标识，没有时为 0
- **错误:** the text of the window and the exclusions are not carried yet; a compositor that does not publish the focus answers with the reason, and not with a guess.

```ahk
id := WinActive()
```

### WinClose

关闭窗口。它关闭的是脚本自己的窗口：合成器的窗口列表没有为别的程序的窗口提供关闭请求。

- **参数:** [WindowTitle] [, WinText] [, ExcludeTitle] [, ExcludeText]
- **返回:** 无返回值
- **错误:** a window that is not there answers 'Target window not found.'; a window of another program cannot be closed this way.

```ahk
WinClose "Untitled"
```

### WinExist

判断是否存在某个标题的窗口。窗口来自合成器，数字标识其中一个。

- **参数:** [WindowTitle] [, WinText] [, ExcludeTitle] [, ExcludeText]
- **返回:** 存在时返回该窗口的标识，不存在时为 0
- **错误:** a window that is not there is an answer and not a failure; a question the compositor cannot answer fails with its reason.

```ahk
if WinExist("Untitled")
```

### WinGetClass

取得与给定标题匹配的窗口的类。

- **参数:** [WindowTitle] [, WinText] [, ExcludeTitle] [, ExcludeText]
- **返回:** 窗口的类
- **错误:** a title that matches no window answers 'Target window not found.'; the text of the window and the exclusions are not carried yet.

```ahk
class := WinGetClass("Untitled")
```

### WinGetClientPos

取得窗口中程序绘制的那一部分的位置与大小。Wayland 客户端不自己画边框——边框由合成器画——因此合成器报告的几何就是用户看到的窗口，两条命令的回答相同。

- **参数:** [WindowTitle] [, WinText, &X, &Y, &Width, &Height, ExcludeTitle, ExcludeText]
- **返回:** 无返回值；位置和大小写入调用者的变量
- **错误:** the text of the window and the exclusions are not carried yet; a window that is not there answers 'Target window not found.'

```ahk
WinGetClientPos "Untitled", , &x, &y, &w, &h
```

### WinGetCount

统计与给定标题匹配的窗口数量。

- **参数:** [WindowTitle] [, WinText] [, ExcludeTitle] [, ExcludeText]
- **返回:** 窗口数量，一个数字
- **错误:** the text of the window and the exclusions are not carried yet; a question the compositor cannot answer fails with its reason.

```ahk
count := WinGetCount("Untitled")
```

### WinGetExStyle

窗口的扩展样式：Windows 的 `WS_EX_*` 位，它们说明窗口如何与其他窗口和屏幕相处。脚本自己的窗口的扩展样式是 256。

- **参数:** WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **返回:** 扩展样式，作为数字
- **错误:** a window that is not there refuses with 'Target window not found.', and the title that was asked about is in the `Extra`; the text of the window and the two exclusions are not carried yet.

```ahk
FileAppend WinGetExStyle("ZZZ_NO_WINDOW_ZZZ"), "*"
```

### WinGetList

取得所有与给定标题匹配的窗口的标识。

- **参数:** [WindowTitle] [, WinText] [, ExcludeTitle] [, ExcludeText]
- **返回:** 标识的数组，没有匹配时为空数组
- **错误:** the text of the window and the exclusions are not carried yet; a question the compositor cannot answer fails with its reason.

```ahk
list := WinGetList("Untitled")
```

### WinGetPID

通过会话的无障碍总线给出窗口所属进程：总线登记应用，窗口是应用的孩子，总线给出它的 PID。

- **参数:** WinTitle
- **返回:** 该进程的 pid（整数）
- **错误:** "Target window not found." when no window has that title; an empty title is refused with "the window is found by its title, and an empty title is not carried yet."; the text of the window and the exclusions are refused with "the text of the window and the exclusions are not carried yet."

```ahk
pid := WinGetPID("Calculator")
```

### WinGetPos

取得窗口的位置和大小，数值来自合成器的报告。

- **参数:** [WindowTitle] [, WinText, &X, &Y, &Width, &Height, ExcludeTitle, ExcludeText]
- **返回:** 无返回值；位置和大小写入调用者的变量
- **错误:** the text of the window and the exclusions are not carried yet; a window that is not there answers 'Target window not found.'

```ahk
WinGetPos "Untitled", , &x, &y, &w, &h
```

### WinGetProcessName

给出窗口所属程序的名称；它沿着 WinGetPID 的链条走：窗口在无障碍总线上找到应用，总线给出进程，进程表给出名称。

- **参数:** WinTitle
- **返回:** 可执行文件的文件名（文本）
- **错误:** "Target window not found." when no window has that title, "Target process not found." when the process is gone by then; an empty title is refused with "the window is found by its title, and an empty title is not carried yet."

```ahk
name := WinGetProcessName("Calculator")
```

### WinGetStyle

窗口的样式：Windows 的那些位（`WS_*`）组成的数字，它们说明窗口如何装饰以及能做什么。脚本自己的窗口的样式是 80674816。

- **参数:** WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **返回:** 样式，作为数字
- **错误:** a window that is not there refuses with 'Target window not found.', and the title that was asked about is in the `Extra`; the text of the window and the two exclusions are not carried yet.

```ahk
FileAppend WinGetStyle("ZZZ_NO_WINDOW_ZZZ"), "*"
```

### WinGetTitle

取得活动窗口的标题，或与给定文本匹配的窗口的标题。

- **参数:** [WindowTitle] [, WinText] [, ExcludeTitle] [, ExcludeText]
- **返回:** 窗口的标题
- **错误:** a window that was named and is not there answers 'Target window not found.'; the text of the window and the exclusions are not carried yet.

```ahk
title := WinGetTitle()
```

### WinGetTransColor

窗口让过去的颜色：分层窗口的颜色键，也就是不被绘制的那个颜色。颜色写作 "0xRRGGBB"，按红、绿、蓝的位的顺序。窗口不是分层的时回答空文本。

- **参数:** WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **返回:** 颜色，格式为 "0xRRGGBB"；窗口不是分层时为空文本
- **错误:** a window that is not there refuses with 'Target window not found.', and the title that was asked about is in the `Extra`; the text of the window and the two exclusions are not carried yet.

```ahk
FileAppend WinGetTransColor("ZZZ_NO_WINDOW_ZZZ"), "*"
```

### WinHide

把脚本自己的窗口从屏幕上收起来。

- **参数:** [WindowTitle] [, WinText] [, ExcludeTitle] [, ExcludeText]
- **返回:** 无返回值
- **错误:** a window that is not there answers 'Target window not found.'; a window of another program cannot be hidden this way.

```ahk
WinHide "Untitled"
```

### WinMaximize

最大化脚本自己创建的窗口，且只有这一个；由盒子里的辅助程序来完成。

- **参数:** WinTitle
- **返回:** 空文本
- **错误:** "Target window not found." when the script has no window of its own, or when the title does not match the one it has.

```ahk
WinMaximize "MyWindow"
```

### WinMinimize

最小化脚本自己创建的窗口，且只有这一个：Wayland 客户端无法最小化别的程序的窗口。

- **参数:** WinTitle
- **返回:** 空文本
- **错误:** "Target window not found." when the script has no window of its own, or when the title does not match the one it has; the reason of the desktop when the helper refuses the state.

```ahk
WinMinimize "MyWindow"
```

### WinMove

移动并调整脚本自己创建的窗口的大小；Wayland 合成器自己摆放窗口，未必会照客户要求的坐标来。

- **参数:** X, Y, Width, Height, WinTitle
- **返回:** 空文本
- **错误:** "Target window not found." when the script has no window of its own, or when the title does not match the one it has.

```ahk
WinMove 100, 100, 800, 600, "MyWindow"
```

### WinRestore

把脚本自己的窗口从最小化状态恢复，且只有这一个窗口。

- **参数:** WinTitle
- **返回:** 空文本
- **错误:** "Target window not found." when the script has no window of its own, or when the title does not match the one it has.

```ahk
WinRestore "MyWindow"
```

### WinSetExStyle

写入窗口的扩展样式。样式是绝对的，与窗口的样式一样：文本在数字之前可以带 `+`、`-` 或 `^`，运行时就已有的扩展样式算出新的扩展样式。

- **参数:** Style, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **返回:** 空文本
- **错误:** an empty text refuses with 'Parameter #1 of WinSetExStyle is invalid.', and 'empty string' is in the `Extra`; a window that is not there refuses with 'Target window not found.'.

```ahk
WinSetExStyle("+0x8", "ZZZ_NO_WINDOW_ZZZ")
```

### WinSetStyle

写入窗口的样式。样式是绝对的：文本在数字之前可以带 `+`、`-` 或 `^`，运行时就已有的样式算出新样式——`+0x10` 加上这些位，`-0x10` 去掉它们，`^0x10` 把它们翻转，没有前缀的文本则替换样式。数字按 v2 的 `ATOU` 读取：文本写着 "0x" 时是十六进制，否则是十进制，文本里没有数字时是零。

- **参数:** Style, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **返回:** 空文本
- **错误:** an empty text refuses with 'Parameter #1 of WinSetStyle is invalid.', and 'empty string' is in the `Extra`; a text that holds no number is not a refusal -- it is read as zero, and the failure that comes is the one of the window.

```ahk
WinSetStyle("+0x10", "ZZZ_NO_WINDOW_ZZZ")
```

### WinSetTitle

给脚本自己的窗口改名；Wayland 客户端无法给别的程序的窗口改名。

- **参数:** NewTitle, WinTitle
- **返回:** 空文本
- **错误:** "Target window not found." when the script has no window of its own, or when the title does not match the one it has.

```ahk
WinSetTitle "New Title", "MyWindow"
```

### WinSetTransColor

写入窗口让过去的颜色。颜色是 HTML 的十七种颜色之一的名称、一个十六进制数字，或者单词 "Off"，它把颜色键去掉。

- **参数:** Color, WinTitle, [WinText], [ExcludeTitle], [ExcludeText]
- **返回:** 空文本
- **错误:** a text that is not a colour refuses with 'Parameter #1 of WinSetTransColor is invalid.', and the text is in the `Extra`; a window that is not there refuses with 'Target window not found.'.

```ahk
WinSetTransColor("Red", "ZZZ_NO_WINDOW_ZZZ")
```

### WinShow

在 `WinHide` 之后，把脚本自己的窗口重新放回屏幕上。

- **参数:** [WindowTitle] [, WinText] [, ExcludeTitle] [, ExcludeText]
- **返回:** 无返回值
- **错误:** a window that is not there answers 'Target window not found.'; a window of another program cannot be shown this way.

```ahk
WinShow "Untitled"
```

### WinWait

等待标题匹配的窗口出现，并给出它的标识符；Wayland 窗口的标识符是一个记号，所以是文本。

- **参数:** WinTitle, WinText, [Timeout], [ExcludeTitle], [ExcludeText]
- **返回:** 窗口标识符（文本），超时则为 0
- **错误:** a session that is not Wayland answers "this desktop waits for the windows of a Wayland session, and this session is not Wayland"; the two exclusions are refused with "the two exclusions are not carried yet."; the wait is capped at sixty seconds when the timeout is left out.

```ahk
WinWait "Calculator", , 5
```

### WinWaitActive

等待标题匹配的窗口获得焦点，并给出它的标识符。

- **参数:** WinTitle, WinText, [Timeout], [ExcludeTitle], [ExcludeText]
- **返回:** 窗口标识符（文本），超时则为 0
- **错误:** a session that is not Wayland answers "this desktop waits for the windows of a Wayland session, and this session is not Wayland"; the two exclusions are refused with "the two exclusions are not carried yet."

```ahk
WinWaitActive "Calculator", , 5
```

### WinWaitClose

等待标题匹配的窗口消失，并回答它是否已经消失。

- **参数:** WinTitle, WinText, [Timeout], [ExcludeTitle], [ExcludeText]
- **返回:** 窗口已消失为 1，超时时它还在则为 0
- **错误:** a session that is not Wayland answers "this desktop waits for the windows of a Wayland session, and this session is not Wayland"; the two exclusions are refused with "the two exclusions are not carried yet."

```ahk
WinWaitClose "Calculator", , 5
```

### WinWaitNotActive

等待没有标题匹配的窗口获得焦点，并回答是否如此。

- **参数:** WinTitle, WinText, [Timeout], [ExcludeTitle], [ExcludeText]
- **返回:** 没有窗口获得焦点为 1，超时时仍有窗口获得焦点则为 0
- **错误:** a session that is not Wayland answers "this desktop waits for the windows of a Wayland session, and this session is not Wayland"; the wait is capped at sixty seconds when the timeout is left out.

```ahk
WinWaitNotActive "Calculator", , 5
```
