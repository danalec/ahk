## 这棵树对它做什么

### A_AppData

用户数据的文件夹。在 Linux 机器上是 `$XDG_DATA_HOME`；该变量不存在时是 `$HOME/.local/share`。

- **参数:** nothing; it is a variable, not a call
- **返回:** 文件夹的路径，作为文本
- **错误:** the read fails with "the machine has no such folder." when the machine has no such folder; the write is refused.

```ahk
FileAppend A_AppData, "*"
```

### A_ComputerName

计算机的名称，按网络看到的：先是内核，内核没有名字时用环境中的 `HOSTNAME`。

- **参数:** nothing; it is a variable, not a call
- **返回:** 名称，作为文本
- **错误:** the read fails when neither the kernel nor the session carries the name; the write is refused.

```ahk
FileAppend A_ComputerName, "*"
```

### A_Desktop

用户桌面的文件夹：机器知道的文件夹；机器不知道时是 `$HOME/Desktop`。

- **参数:** nothing; it is a variable, not a call
- **返回:** 文件夹的路径，作为文本
- **错误:** the read fails with "the machine has no such folder." when the machine has no such folder; the write is refused.

```ahk
FileAppend A_Desktop, "*"
```

### A_MM

机器本地时间的月份，两位数字。

- **参数:** nothing; it is a variable, not a call
- **返回:** 月份，两位数字的文本
- **错误:** the read fails when the clock of the runtime does not know the date of the machine; the write is refused.

```ahk
FileAppend A_MM, "*"
```

### A_Temp

机器的临时文件文件夹：`TMPDIR`；该变量不存在时是 `/tmp`。

- **参数:** nothing; it is a variable, not a call
- **返回:** 文件夹的路径，作为文本
- **错误:** the read fails with "the machine has no such folder." when the machine has no such folder; the write is refused.

```ahk
FileAppend A_Temp, "*"
```

### A_TickCount

运行时从一个任意起点开始计数的毫秒数。计数从不后退。

- **参数:** nothing; it is a variable, not a call
- **返回:** 毫秒数，作为数字
- **错误:** the write is refused; the name is a built-in variable that the dialect does not let a script write.

```ahk
FileAppend A_TickCount, "*"
```

### A_UserName

会话用户的名称：环境中的 `USER`。

- **参数:** nothing; it is a variable, not a call
- **返回:** 名称，作为文本
- **错误:** the read fails when the session carries no such name: "the session does not carry the name of the user: the environment has no USER."; the write is refused.

```ahk
FileAppend A_UserName, "*"
```

### ProcessClose

结束一个进程；盒子发送 SIGTERM，这是请进程自己退出的礼貌信号。

- **参数:** ProcessNameOrPID
- **返回:** 被结束的进程的 pid，不存在或无法结束时为 0
- **错误:** a process of another user is a process the script cannot open, and the answer is zero and not a failure.

```ahk
ProcessClose "firefox"
```

### ProcessExist

回答某个进程是否存在、它的 pid 是多少；机器上的进程是从 /proc 读出来的。

- **参数:** [ProcessNameOrPID]
- **返回:** 该进程的 pid，不存在则为 0
- **错误:** a machine without /proc answers "the processes of this machine are read out of /proc, and this machine has none"; a process that is not there is zero and not a failure.

```ahk
if ProcessExist("firefox")
```

### ProcessGetName

给出进程可执行文件的名称；名称取自 /proc/<pid>/exe 的文件名，内核给出的名字是退路。

- **参数:** [ProcessNameOrPID]
- **返回:** 可执行文件的名称（文本）
- **错误:** "Target process not found." when the process is not there; a machine without /proc answers "the processes of this machine are read out of /proc, and this machine has none".

```ahk
name := ProcessGetName(1234)
```

### ProcessGetPath

给出进程可执行文件的完整路径；路径是 /proc/<pid>/exe 这个链接指向的地方，内核加上的 " (deleted)" 会被截掉。

- **参数:** [ProcessNameOrPID]
- **返回:** 可执行文件的路径（文本）
- **错误:** "Target process not found." when the process is not there; a machine without /proc answers "the processes of this machine are read out of /proc, and this machine has none".

```ahk
path := ProcessGetPath(1234)
```

### ProcessWait

等待某个进程出现；盒子每百毫秒检查一次，和 v2 的二进制一样。

- **参数:** ProcessNameOrPID, [Timeout]
- **返回:** 出现时给出该进程的 pid，超时则为 0
- **错误:** a call without a timeout waits for ever; a machine without /proc answers "the processes of this machine are read out of /proc, and this machine has none".

```ahk
ProcessWait "firefox", 10
```

### ProcessWaitClose

等待一个已经在的进程结束；从未存在过的进程就是已经没了，等待立刻结束。

- **参数:** ProcessNameOrPID, [Timeout]
- **返回:** 进程已消失为 0，超时时它还在则给出它的 pid
- **错误:** a call without a timeout waits for ever; a machine without /proc answers "the processes of this machine are read out of /proc, and this machine has none".

```ahk
ProcessWaitClose "firefox", 10
```

### Run

运行一条命令并等待它结束。命令写到输出上的内容进入报告的输出。

- **参数:** Command, [WorkingDir]
- **返回:** 命令的退出码
- **错误:** more than two parameters are refused with "the options of the window and the pid of the process are not carried yet."

```ahk
Run "ls"
```

### Run

运行一条命令并等待它结束。命令写到输出上的内容进入报告的输出。

- **返回:** 命令的退出码
- **错误:** more than two parameters are refused with "the options of the window and the pid of the process are not carried yet."

```ahk

```

### SysGet

给出系统的一个度量；编号取自 GetSystemMetrics，只有与屏幕有关的那些被承载。

- **参数:** Metric
- **返回:** 该度量（整数）
- **错误:** a metric of the window manager of Windows is refused with "SysGet(n) is a metric of the window manager of Windows, and this desktop does not have one."; a compositor that published no monitor answers "the compositor published no monitor, so the metric n of SysGet is not known."; a number that is not a metric at all is zero.

```ahk
w := SysGet(0)
```
