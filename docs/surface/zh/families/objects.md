## 这棵树对它做什么

### Array

一排值的类。`Array(...)` 用给定的值造出数组，字面量 `[1, 2, 3]` 也一样。

- **参数:** the values of the array, any number of them
- **返回:** 类为 `Array` 的对象
- **错误:** nothing to make the array; the places count from one, and an index that is not there is refused with "Invalid index.".

```ahk
a := Array(1, 2, 3)
FileAppend a.Length, "*"
```

### Map.Delete

把一个键从映射里取走，并回答它下面原本的值。

- **参数:** the key
- **返回:** 该键下面原本的值
- **错误:** a key that is not there is refused with "Item has no value.", and the key is named in the `Extra` of the failure.

```ahk
m := Map("x", 1)
FileAppend m.Delete("x"), "*"
```

### Enumerator

循环的行走者的类：枚举器一次交出一个序列的一段。这个类造不出来；值的 `__Enum` 造出它，对它的调用就是枚举的一轮。

- **参数:** nothing that makes it
- **返回:** 枚举器的类，作为文本
- **错误:** the call of the class is refused with "Invalid base.".

```ahk
for item in [1, 2]
    FileAppend Type(item), "*"
```

### Func

函数的类：脚本里的函数、方法、lambda 或内置函数。这个类造不出来：`Func(...)` 回答“Invalid base.”；函数值的类就是 `Func`。

- **参数:** nothing that makes it
- **返回:** 函数值的类，作为文本
- **错误:** the call of the class is refused with "Invalid base.".

```ahk
FileAppend Abs.__Class, "*"
```

### Func

函数的类：脚本里的函数、方法、lambda 或内置函数。这个类造不出来：`Func(...)` 回答“Invalid base.”；函数值的类就是 `Func`。

- **参数:** nothing that makes it
- **返回:** 函数值的类，作为文本
- **错误:** the call of the class is refused with "Invalid base.".

```ahk
FileAppend Abs.__Class, "*"
```

### Map.Get

映射中某个键下面的值。

- **参数:** the key, and the value to answer when the key is not there
- **返回:** 该键下面的值
- **错误:** a key that is not there is refused with "Item has no value.", and the key is named in the `Extra` of the failure; the second argument is the default of the call, and the `Default` of the map is the last word.

```ahk
m := Map("x", 1)
FileAppend m.Get("x"), "*"
```

### Map.Has

映射中是否有某个键。

- **参数:** the key
- **返回:** 键在时为 1，不在时为 0
- **错误:** nothing; a key that is not there is not a failure, the question is answered.

```ahk
m := Map("x", 1)
FileAppend m.Has("x"), "*"
```

### Array.Length

数组位置的个数。它是属性而不是方法：写 `a.Length`，不写 `a.Length()`。

- **参数:** nothing; it is a property, not a call
- **返回:** 位置的个数，作为数字
- **错误:** the write of a negative number is refused with "Invalid value."; a longer array gets places that have no value of their own, and a shorter one loses the places at the end.

```ahk
a := [1, 2, 3]
FileAppend a.Length, "*"
```

### Map

键和值的表的类。`Map(key, value, ...)` 造出这样一个表，各条目的顺序就是放进去的顺序。

- **参数:** the pairs of key and value, an even number of them
- **返回:** 类为 `Map` 的对象
- **错误:** an odd number of arguments is refused with "Invalid number of parameters."; a key that is not there is refused with "Item has no value.".

```ahk
m := Map("x", 1)
FileAppend m.Count, "*"
```

### Object

类链的根：运行时的每个对象都是它。`Object()` 造出一个空对象，字面量 `{a: 1}` 造出一个带属性的对象。

- **参数:** nothing
- **返回:** 类为 `Object` 的对象
- **错误:** nothing; a member that is not there is refused with the type of the value and the name of the member.

```ahk
o := Object()
FileAppend o.__Class, "*"
```

### ObjGetBase

对象的基类：它那个类的原型。

- **参数:** the object
- **返回:** 基类的对象
- **错误:** a value that is not an object is refused with "Expected an object but got ...".

```ahk
FileAppend ObjGetBase({a: 1}).__Class, "*"
```

### Array.Pop

从数组末尾取走最后一个值并回答它。

- **参数:** nothing
- **返回:** 末尾那个值；该位置没有自己的值时是空文本
- **错误:** an empty array is refused with "Array is empty.".

```ahk
a := [1, 2]
FileAppend a.Pop(), "*"
```

### Array.Push

把值放到数组末尾，并回答这个数组，因此调用可以串起来。

- **参数:** the values, any number of them
- **返回:** 数组本身
- **错误:** nothing; the push of no value changes nothing and still answers the array.

```ahk
a := [1]
a.Push(2, 3)
FileAppend a.Length, "*"
```

### Map.Set

把键和值的对放进映射，并回答这个映射，因此调用可以串起来。

- **参数:** the pairs of key and value, an even number of them
- **返回:** 映射本身
- **错误:** an odd number of arguments is refused with "Invalid number of parameters.".

```ahk
m := Map()
m.Set("x", 1)
FileAppend m.Count, "*"
```
