# The measurement is the probe of `scripts/xp/floor`: a binary of Rust
# without the standard library, for `i686-pc-windows-gnu`, that asks
# the machine for every symbol of the table and for the classes of COM
# that the tree names.  The answer is the answer of the machine, not
# the answer of a document.

#   MISSING <dll>!<symbol>      the machine does not have the symbol
#

# missing.  Nothing that the thirty-two-bit binaries of this tree take
# to the machine is a thing the machine lacks.
#

# The table that was asked
#
# The table is the UNION of the import tables of every binary that goes
# to the machine of the lab, and `scripts/xp/floor/gen_table.py` writes

# gate unable to vouch for the minimal `hello` that is the reproducer of
# the lab, and `hello` imports MORE than `ahk.exe` does, because the
# `--gc-sections` of the tree cuts from `ahk.exe` the sections it never
# references -- the sockets of `ws2_32` and the `userenv` are among
# them.
