`FileAppend(Text, "*")` is the mechanism: real AutoHotkey and Keysharp write it to process stdout, and the Rust runner collects it in its JSON report on stdout under `output`.  The harness compares real = normalized stdout, Keysharp = normalized stdout, Rust = concatenated `report.output` (normalized), with the failure path falling back to stderr/`report.error` so failure wording is compared as data.

### Safety

Every script starts with `#ErrorStdOut` and `#Warn All, StdOut`, registers an `OnError` backstop that suppresses the error dialog, and wraps every probe in `try`/`catch as e`.  Every process is bounded by a timeout (real 15 s, Keysharp 90 s, Rust 25 s) and the process tree is killed on expiry; a timeout is recorded and classified ERROR.  No case timed out or crashed in this run unless the ERROR column says otherwise.

### Normalization (only what is engine plumbing, never a value)

1. `\r\n` -> `\n`; the trailing newline of an answer is trimmed for comparison.
2. Diagnostic warning blocks are removed from stdout: `... (N) : ==> Warning: ...` plus a following `     Specifically: ...` line.  The Rust runner emits such a warning for the `OnError` backstop name and for every `catch as e` variable in every script.
3. Error-location prefixes are removed from stderr answers: `<script> (12) : ==> ` and Keysharp's compile form `<script> 12:3: `.  The script path becomes `<script>`, the per-engine working directory `<cwd>`, the repository root `<root>`.
4. Nothing else: the channel a failure came out of (`STDERR:` vs `ERROR:`) is dropped and the text is compared.

### Verdict rules

| Verdict | Rule |
| --- | --- |
| MATCH | every enabled engine's answer is identical |
| KEYS-DIFFERS | real == Rust, Keysharp differs |
| RUST-DIFFERS | real == Keysharp, Rust differs |
| BOTH-DIFFER | no two engines agree |
| ERROR | a timeout, a crash exit, or an engine that did not answer |
| DIFFERS | two engines were enabled and they disagree |

## Caveats and limitations

1. **Keysharp targets v2.1-alpha.37, not v2.0.19.** A handful of its divergences are expected; `A_AhkVersion` confirms the target (`mi08_version`).
2. **The Rust tree claims v2.0.19 exactly**, so its divergences are not excused by a version target.  A refusal with an honest message is still a script-visible incompatibility: the case exists to make it countable.
3. **No case may open a dialog** (see the safety invariant above), which bounds the exercised surface to the language, the string/number/date built-ins, the object model and file I/O.
4. **Warnings are diagnostics, not output**, and are stripped in every engine; the Rust runner's warning for `OnError`/`catch` variables is recorded here rather than compared.
5. **Error-path comparisons are about message text, not location:** class, message and `Extra` are compared; the file/line prefix is normalized away.
6. **One machine, one run per case.** The scripts are deterministic (fixed date-time stamps, sorted listings, no current time, no random), so a repeat run reproduces `results.tsv`.
7. **Timeout and kill are reported, never ignored:** a hang is classified ERROR with `TIMEOUT(killed)`, a crash exit with `CRASH(exit=..)`.

## Reproduction

```sh
python scripts/differential.py --report scripts/differential/report.md
python scripts/differential.py --only er0
python scripts/differential.py --engines rust   # on a machine without AHK/Keysharp
```

`--only <substring>` runs a subset; `--keep-tmp` keeps the per-engine working directories for inspection; `--baseline <results.tsv>` reports the fixed/regressed cases since a previous run.
